## 关税基础

### 关税法规体系

**中华人民共和国关税法**
- 文号：主席令第27号
- 生效日期：2024年12月1日
- 核心条款：关税纳税人、税则归类、原产地规则、税率运用
- 【实施状态】已正式施行，是关税领域的基本法律；原《进出口关税条例》仍有效，与关税法配套执行

**进出口关税条例**
- 文号：国务院令第392号
- 生效日期：2004年1月1日
- 核心条款：完税价格、原产地、减免税、申诉

### 税则归类

**协调制度（HS编码）**
- 国际通用进出口商品分类体系
- 中国海关采用10位HS编码
- 前6位为国际通用，后4位为中国专用

**归类依据**：
1. 税则归类总规则（一至六）
2. 类注释、章注释、品目注释
3. 子目注释

### 原产地规则

**优惠原产地规则**：
- 适用协定税率的前提条件
- 中国-东盟、中国-韩国、中国-澳大利亚等自贸协定
- 累计原产地、微小加工等概念

**非优惠原产地规则**：
- 适用最惠国税率、一般税率

## 进口环节税

### 进口税则结构

| 税率类型 | 适用范围 | 典型税率 |
|---------|---------|---------|
| 最惠国税率 | WTO成员/最惠国待遇国家 | 大多数商品3%-15% |
| 普通税率 | 非最惠国待遇国家 | 较高（如70%） |
| 协定税率 | 自贸协定成员国 | 低于最惠国税率 |
| 特惠税率 | 特定发展中国家 | 更低或免税 |
| 配额税率 | 关税配额管理商品 | 配额内低税率 |

### 进口环节代征税

**增值税**
- 税率：13%/9%/6%
- 计税依据：关税完税价格+关税+消费税
- 与国内增值税类似，但进口环节有抵扣规则

**消费税**
- 征收范围与国内消费税一致
- 计税依据：关税完税价格+关税+消费税（从价征收部分）

**计算公式**：
```
关税 = 关税完税价格 × 关税税率
消费税 = (关税完税价格+关税)/(1-消费税税率) × 消费税税率
增值税 = (关税完税价格+关税+消费税) × 增值税税率
```

## 行邮税

### 行邮税概述

**行邮税**是对进境物品征收的进口税，包括关税和进口环节增值税、消费税。

**法规依据**：《关于调整进境物品进口税有关问题的通知》（国务院关税税则委员会）

### 税率调整

**现行行邮税税率（2019年4月9日起）**：
| 类别 | 税率 |
|------|------|
| 书报刊物、教育用品、计算机、食品、餐具、药品等 | 13% |
| 纺织品、皮革箱包、鞋靴、化妆品（高档除外）、洗护用品、厨卫用品、家具、运动用品（高档除外）、玩具、医疗器械等 | 20% |
| 烟、酒、贵重首饰及珠宝玉石、高档化妆品、高尔夫球具、高档手表等 | 50% |

### 免税额度

| 渠道 | 免税额度 |
|------|---------|
| 旅客行李物品 | 个人合理自用范围内免税（**港/澳进境居民旅客每次1200元**，其他5000元） |
| 邮递物品 | 单次限值1000元、年度累计限值5000元 |
| 跨境电商 | 单次交易限值5000元、个人年度交易限值26000元 |

### 跨境电商零售进口税收

**税收政策**（财关税〔2016〕18号及后续延续）：
| 项目 | 说明 |
|------|------|
| 纳税义务人 | 跨境电商零售进口商品的购买者 |
| 税率 | 关税税率暂设为0%；进口环节增值税/消费税暂按法定应纳税额的70%征收 |
| 免税额 | 单次交易限值5000元；个人年度交易限值26000元 |
| 优惠 | 超过单次限值但不超过年度限值，且订单仅一件商品，可自跨境电商渠道进境，按行邮税征税 |

## 出口税收

### 出口退（免）税

**基本原则**：
- 对出口货物、劳务和跨境应税行为退还或免征国内已缴纳的增值税和消费税
- "零税率"原则：不征不退

**出口退（免）税适用范围**：
| 类型 | 说明 |
|------|------|
| 出口货物劳务退（免）税 | 生产型企业免抵退、外贸企业免退税 |
| 跨境应税行为零税率 | 境内单位和个人跨境应税行为适用增值税零税率 |

### 出口关税

**征收出口关税的商品**：
- 部分资源性产品（如黄磷、萤石等）
- 高耗能、高污染产品
- 粮、棉等初级产品

**税率**：一般20%-50%，从量定额

### 保税加工

| 方式 | 特点 |
|------|------|
| 加工贸易 | 来料加工、进料加工，料件保税进口，加工成品出口 |
| 保税区 | 区内加工货物免征关税和进口环节税 |
| 出口加工区 | 加工区企业生产性货物免征关税和进口环节税 |

## 与境内税务的衔接

### 进口环节增值税抵扣

| 情形 | 是否可以抵扣 |
|------|-------------|
| 进口环节缴纳的增值税 | 可作为进项税额抵扣（需取得海关完税凭证） |
| 海关进口增值税专用缴款书 | 需与发票比对后抵扣 |
| 进口免税货物 | 不得抵扣进项税额 |

### 出口退（免）税与留抵退税

- 已办理出口退（免）税的进项税额不得再申请留抵退税
- 需准确划分用于出口和内销的进项税额
