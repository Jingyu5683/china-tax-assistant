## 基础法规

### 核心法规

**中华人民共和国契税法**
- 文号：主席令第52号
- 生效日期：2021年9月1日
- 核心条款：纳税人、征税范围、税率、税收优惠

**中华人民共和国契税法实施条例**
- 文号：国务院令第709号
- 生效日期：2021年9月1日

## 征税范围

### 应税行为

| 应税情形 | 说明 |
|---------|------|
| 土地使用权出让 | 出让方不征，受让方征 |
| 土地使用权转让 | 包括出售、赠与、交换 |
| 房屋买卖 | 存量房交易 |
| 房屋赠与 | 非公益性赠与 |
| 房屋交换 | 房屋之间交换 |
| 以作价投资等方式转移 | 以作价投资、抵债等方式 |

### 不征契税情形

| 情形 | 说明 |
|------|------|
| 土地使用权出让 | 出让方（通常为政府）不缴契税 |
| 继承 | 法定继承不征，非法定继承须征 |
| 夫妻变更 | 婚姻关系存续期间夫妻间房屋、土地权属变更 |
| 共有分割 | 共有人之间分割共有不动产 |

## 税率与计税依据

### 税率

| 适用情形 | 税率 |
|---------|------|
| 基本税率 | 3%-5% |
| 优惠税率 | 1%-2%（见优惠政策） |

**【注】** 契税税率由各省市在法定幅度内确定，具体适用税率需查询当地规定。

### 计税依据

| 转让方式 | 计税依据 |
|---------|---------|
| 土地使用权出让 | 成交价格 |
| 土地使用权转让、房屋买卖 | 成交价格或市场价格 |
| 土地使用权交换、房屋交换 | 交换价格差额 |
| 赠与 | 参照市场价格核定 |
| 以作价投资等 | 参照市场价格核定 |

**成交价格明显偏低且无正当理由的**，由税务机关参照市场价格核定。

## 优惠政策

### 法定优惠

| 优惠情形 | 税率 | 文件依据 |
|---------|------|---------|
| 承受荒山、荒地、荒滩土地使用权用于农、林、牧、渔业生产 | 免征 | 契税法第六条 |
| 婚姻关系存续期间夫妻之间变更土地、房屋权属 | 免征 | 契税法第六条 |
| 法定继承人通过继承承受土地、房屋权属 | 免征 | 契税法第六条 |

### 阶段性优惠（至2027年12月31日）

| 优惠情形 | 税率 | 文件依据 |
|---------|------|---------|
| 住宅 | 1%-2%（减半征收） | 财政部 税务总局 住房城乡建设部公告2023年第22号 |
| 非住宅 | 3%（无统一减半优惠） | 【注】非住宅契税无全国统一减半政策，以各省市规定为准 |

### 首套房优惠

| 情形 | 税率 | 条件 |
|------|------|------|
| 首套90平方米以下 | 1% | 家庭唯一住房 |
| 首套90平方米以上 | 1.5% | 家庭唯一住房 |
| 第二套90平方米以下 | 1% | 家庭第二套改善性住房 |
| 第二套90平方米以上 | 2% | 家庭第二套改善性住房 |

**【适用范围】** 仅适用于住宅（22号公告）；非住宅契税由各省市在3%-5%幅度内确定

## 申报与缴纳

### 纳税义务发生时间

契税纳税义务发生时间为纳税人签订土地、房屋权属转移合同的当日，或者纳税人取得其他具有土地、房屋权属转移合同性质凭证的当日。

### 申报缴纳流程

```
签订权属转移合同
    │
    ▼
确定计税依据
    │
    ▼
计算应纳税额
    │
    ▼
向不动产所在地税务机关申报
    │
    ▼
税务机关核定（如需要）
    │
    ▼
缴纳税款
    │
    ▼
取得完税凭证
    │
    ▼
办理不动产登记
```

### 特殊情形

| 情形 | 处理方式 |
|------|---------|
| 承受价格明显偏低 | 由税务机关参照市场价格核定 |
| 减免税申请 | 部分优惠需事前申请认定 |
| 已缴契税后退房 | 可申请退税（需满足条件） |

## 与其他税种衔接

| 关系 | 说明 |
|------|------|
| 与增值税 | 契税计税依据不含增值税 |
| 与土地增值税 | 存量房交易同时涉及两个税种 |
| 与印花税 | 产权转移书据需缴印花税，分别计算 |
| 与房产税 | 购房后需缴纳房产税（试点城市） |

## 时效性说明

**【注】** 契税法于2021年9月1日正式施行，替代原《契税暂行条例》。近年主要是购房优惠政策频繁调整（住宅契税减半等），建议核实最新适用税率。
