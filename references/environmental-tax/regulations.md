## 基础法规

### 核心法规

**中华人民共和国环境保护税法**
- 文号：主席令第61号
- 生效日期：2018年1月1日
- 核心条款：纳税人、征税对象、税目税额、税收减免

**中华人民共和国环境保护税法实施条例**
- 文号：国务院令第693号
- 生效日期：2018年1月1日

**环境保护税税目税额表**
- 文号：财政部 税务总局 生态环境部公告2021年第16号

## 纳税人

### 纳税义务人

在中华人民共和国领域和中华人民共和国管辖的其他海域，直接向环境排放应税污染物的企业事业单位和其他生产经营者为环境保护税的纳税人。

### 不需缴纳的情形

| 情形 | 说明 |
|------|------|
| 单位和个体工商户 | 向依法设立的污水集中处理、生活垃圾集中处理场所排放应税污染物 |
| 事业单位 | 向依法设立并通过环保设施处理的场所排放应税污染物 |
| 其他 | 符合国家和地方环境保护标准的设施 |

## 征税范围

### 应税污染物

| 类别 | 具体污染物 |
|------|----------|
| 大气污染物 | 二氧化硫、氮氧化物、挥发性有机物等 |
| 水污染物 | 化学需氧量、氨氮、总磷等 |
| 固体废物 | 煤矸石、尾矿、危险废物等 |
| 噪声 | 工业噪声（仅限超标部分） |

### 固体废物税目（全国统一定额标准）

| 税目 | 税额标准 | 政策依据 |
|------|---------|---------|
| 煤矸石 | 5元/吨 | 环保税法附表 |
| 尾矿 | 15元/吨 | 环保税法附表 |
| 危险废物 | 1000元/吨 | 环保税法附表 |
| 冶炼渣、粉煤灰、炉渣、其他固体废物 | 25元/吨 | 环保税法附表 |

**【注】** 固体废物税额为全国统一标准，各省市无调整权限。

## 税额标准

### 大气污染物/水污染物税额（各省市差异）

**法定幅度**：大气污染物1.2-12元/污染当量；水污染物1.4-14元/污染当量

| 省份 | 大气污染物税额 | 水污染物税额 | 备注 |
|------|--------------|-------------|------|
| 北京 | 12元/污染当量 | 14元/污染当量 | 最高标准 |
| 上海 | 6.65元/污染当量 | 6.65元/污染当量 | - |
| 广东 | 1.8元/污染当量 | 2.8元/污染当量 | - |
| 河北 | 9.6元/污染当量 | 11.2元/污染当量 | 分区域 |
| 多数省份 | 1.2-3.9元/污染当量 | 1.4-4.2元/污染当量 | 最低标准 |

**【注】** 具体税额由各省市在法定幅度内确定，建议联网检索当地最新税额标准。

## 申报与缴纳

### 计算方法

**污染物排放量计算**：
1. 自动监测法（优先）
2. 监测机构监测法
3. 物料衡算法
4. 抽样测算核定法

**计算公式**：
```
应纳税额 = 污染当量数 × 具体适用税额
```

### 申报缴纳周期

| 纳税人类型 | 申报周期 |
|-----------|---------|
| 重点纳税人 | 季度申报（月度报送监测数据） |
| 一般纳税人 | 季度申报 |

### 申报流程

```
安装监测设备/获取监测数据
    │
    ▼
计算污染物排放量
    │
    ▼
确定适用税额
    │
    ▼
向税务机关申报
    │
    ▼
缴纳税款
```

## 优惠政策

### 法定减免

| 情形 | 优惠内容 | 条件 |
|------|---------|------|
| 农业生产 | 暂予免征 | 排放应税污染物 |
| 机动车等 | 暂予免征 | 铁路机车等 |
| 依法设立的城乡污水集中处理场所 | 暂予免征 | 排放应税污染物 |
| 纳税人综合利用固体废物 | 暂予免征 | 符合国家和地方环保标准 |

### 减征优惠

| 情形 | 减征幅度 | 条件 |
|------|---------|------|
| 排放浓度低于标准30% | 减按75%征收 | 大气或水污染物 |
| 排放浓度低于标准50% | 减按50%征收 | 大气或水污染物 |

### 延续性政策

| 政策内容 | 有效期 | 说明 |
|---------|--------|------|
| 环保税减免政策 | 现行有效 | 法定减免长期有效 |

## 与其他税种衔接

| 关系 | 说明 |
|------|------|
| 与增值税 | 环保税不涉及增值税抵扣 |
| 与企业所得税 | 环保税准予税前扣除 |
| 与资源税 | 两者针对不同环节（开采 vs 污染排放） |
| 与排污费 | 环保税替代原排污费，不再另行征收 |

## 时效性说明

**【注】** 环境保护税法自2018年1月1日施行，2017年排污费停征。税额标准由各省市在法定幅度内确定，建议核实当地最新税额标准。
