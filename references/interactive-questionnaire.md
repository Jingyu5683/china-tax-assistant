# 问卷式交互决策树

【知识库更新日期】2026-05-26

> 本文件定义了 tax-query 技能在用户提问模糊时的逐步追问协议。
> Agent 应优先根据用户描述的详细程度判断是否需要启动追问，而不是对所有问题都强制走完决策树。

---

## 一、通用追问协议（所有税种适用）

### 第零步：详细程度评估

在回答前，先判断用户描述的信息充分度：

| 信息充分度 | 判断标准 | 处理方式 |
|-----------|---------|---------|
| **充分** | 用户已明确说明：税种、业务场景、主体性质、涉及金额/比例、时间段 | 直接查询知识库并联网验证后回答，无需追问 |
| **基本充分** | 已知主要情形，仅缺少1项非关键信息 | 作出有限假设后回答，在回答中标注假设前提 |
| **模糊** | 只说了税种或场景名，缺少关键定性/定量信息 | 启动追问协议，按以下三层依次追问 |

> **原则**：追问不超过3轮；若第3轮仍未获得关键信息，则基于最合理假设给出"初步判断"，同时列明假设前提和不确定点。

---

### 第一层：业务地域确认

**触发条件**：用户未说明业务发生地，或提到"境外""海外""香港""外资"等关键词时。

```
请先确认一下这笔业务的地域范围：

  □ 纯境内业务（交易各方和业务都在中国内地）
  □ 涉及香港、澳门、台湾（需适用专项安排）
  □ 跨境业务（一方在境外，或涉及进出口/境外支付）
  □ 纯境外业务（在中国境外发生，你是中国境内的税务居民/企业）
```

→ **纯境内** → 进入第二层（时效）  
→ **涉港澳台** → 提示适用相关安排（内地-香港安排/CEPA等），进入第二层  
→ **跨境/纯境外** → 触发跨境税务决策树（见第六节）

---

### 第二层：时效确认

**触发条件**：用户问题涉及特定时间节点，或税种近两年有重大变化（如增值税2026年立法）时。

```
这个问题是关于哪个时间段的？

  □ 当前正在发生（适用现行有效法规）
  □ 未来规划（预判税负、提前合规）
  □ 追溯历史问题（已发生的业务补查或应对稽查）→ 请告诉我发生年份
```

→ **历史年份** → 查询对应年份有效法规，并在结论中对比现行规定差异  
→ **未来规划** → 回答时标注"基于现行法规预测，如有新政策发布需重新评估"  
→ **当前** → 直接使用最新法规

---

### 第三层：具体场景追问

根据第一层识别的税种/业务方向，进入对应的专项决策树（见第二至五节）。

---

## 二、进项税额抵扣判定决策树

**触发词**：进项能不能抵、进项抵扣、发票能不能抵、这张票、抵税、进项税

### Step 1：支出类型确认

```
这笔进项对应的支出是什么类型？

  A. 购买货物 / 原材料 / 商品
  B. 接受应税服务（如咨询、设计、运输、广告）
  C. 购买固定资产（设备、车辆、不动产）
  D. 集体福利或个人消费（员工福利、聚餐、团建）
  E. 非正常损失相关支出（盗窃、丢失、管理不善）
  F. 用于免税项目 / 简易计税项目的支出
  G. 餐饮、居民日常服务、娱乐服务（直接消费）
  H. 贷款服务利息
```

| 选项 | 直接结论 | 依据 |
|------|---------|------|
| D | ❌ **不得抵扣** | 增值税法第二十二条第(四)项 |
| E | ❌ **不得抵扣** | 增值税法第二十二条第(三)项 |
| F | ❌ **不得抵扣** | 增值税法第二十二条第(一)(二)项 |
| G | ❌ **不得抵扣** | 增值税法第二十二条第(五)项 |
| H | ❌ **不得抵扣** | 增值税法第二十二条第(六)项 |
| A / B / C | → 继续 **Step 2** | |

> **特殊提示**：购入不动产（含建筑物）按规定在取得当期一次性全额抵扣，不再分两年抵扣（2026年增值税法新规）。

---

### Step 2：凭证类型确认

```
取得了什么凭证？

  A. 增值税专用发票（含数电专票）
  B. 旅客运输凭证（铁路电子客票 / 航空运输电子客票行程单 / 公路水路客票）
  C. 收费公路通行费发票（高速公路/一级/二级）
  D. 农产品收购发票 / 农产品销售发票（适用核定扣除）
  E. 海关进口增值税专用缴款书
  F. 完税凭证（境外购进服务/无形资产/不动产扣缴完税）
  G. 增值税普通发票 / 收据（非上述类型）
  H. 没有发票（白条、转账凭证）
```

| 选项 | 结论 | 备注 |
|------|------|------|
| G / H | ❌ **通常不得抵扣** | 无法凭普通发票抵扣进项，需取得专用发票 |
| A | → 继续 **Step 3** | 主流凭证，须经发票查验平台验真 |
| B（旅客运输） | → 继续 **Step 3** | 凭票注明税额抵扣（铁路/航空/公路客票均适用，依据：2026年第13号公告） |
| C | → **可以抵扣**，按发票注明税率计算（高速6%、一级公路3%、二级公路3%） | 需取得合规通行费电子发票 |
| D | → **核定扣除**，按农产品买价×扣除率（9%或13%）计算 | 不看票面税额，适用核定扣除法 |
| E / F | → 继续 **Step 3** | 同专票处理逻辑 |

---

### Step 3：用途确认（可多选）

```
这笔支出用于什么项目？（可多选）

  □ 仅用于一般计税项目（适用13%/9%/6%税率的销售）
  □ 仅用于简易计税项目（适用3%征收率）
  □ 仅用于免税项目
  □ 同时用于一般计税 + 简易计税/免税（兼用）
  □ 直接计入成本/费用，难以区分（如管理费用、水电费）
```

| 选项组合 | 结论 |
|---------|------|
| 仅一般计税 | ✅ **全额抵扣** |
| 仅简易计税 / 仅免税 | ❌ **不得抵扣** |
| 兼用 / 难以区分 | → **需按比例分摊**，继续 **Step 4** |

---

### Step 4：分摊比例计算

```
如需分摊，请提供以下数据（任选其一方法）：

  方法①（按销售额比例）：
    - 当期一般计税项目销售额（不含税）：______
    - 当期全部销售额（不含税）：______

  方法②（不动产按面积比例）：
    - 用于一般计税项目的建筑面积：______
    - 全部建筑面积：______
```

**计算公式**：
```
可抵扣进项税额 = 全部进项税额 × (一般计税项目销售额 ÷ 全部销售额)
不得抵扣进项税额 = 全部进项税额 × (1 - 分摊比例)
```

> **时效提醒**：分摊方法的具体规定见《增值税法实施条例》第三十四条及财政部税务总局公告2026年第13号，建议联网核实最新口径。

---

### 进项抵扣结论模板

```
【进项抵扣判定结果】

支出类型：[用户输入]
凭证类型：[用户输入]
用   途：[仅一般计税 / 兼用（一般计税占比 XX%）/ 不得抵扣情形]

[结论标识] [可全额抵扣 / 可部分抵扣 / 不得抵扣]

[如部分抵扣]
  可抵扣进项税额 = 票面税额 × XX%
  不得抵扣金额 = 票面税额 × XX%

法规依据：《中华人民共和国增值税法》第二十二条 / 实施条例第三十四条
          [如适用] 财政部 税务总局公告2026年第13号

【时效提示】以上依据增值税法（2026年1月1日施行）现行规定，建议通过
chinatax.gov.cn 或 12366 确认最新执行口径。
```

## 三、个人所得税决策树

**触发词**：个税、个人所得税、税后工资、年终奖、劳务费、稿酬、股权激励、经营所得

### Step 1：所得类型确认

```
这笔收入属于哪种类型？

  A. 工资薪金（劳动合同，含年终奖）
  B. 劳务报酬（无劳动合同，如讲课费、咨询费）
  C. 稿酬（书稿、音乐作品等）
  D. 特许权使用费（专利、版权授权）
  E. 经营所得（个体工商户、合伙企业合伙人）
  F. 财产转让（股权、房产、其他财产）
  G. 股息红利
  H. 偶然所得（奖品、中奖）
```

| 类型 | 适用税目 | 关键规则 |
|------|---------|---------|
| A | 综合所得（累进税率3%-45%） | 预扣预缴+年度汇算；年终奖可选单独计税至2027年底 |
| B | 综合所得（含预扣20%-40%） | 劳务报酬：收入≤4万减800，>4万减20%，再按预扣率 |
| C | 综合所得（70%计入） | 稿酬所得按70%计入综合所得 |
| D | 综合所得（按比例预扣） | 预扣率20%，年度汇算并入综合所得 |
| E | 经营所得（累进税率5%-35%） | 独立汇算，不并入综合所得 |
| F | 财产转让所得（20%） | 股权转让=（转让价-取得成本）×20%；房产转让有免征条件 |
| G | 利息股息红利（20%） | 上市公司股息持股≥1年免税 |
| H | 偶然所得（20%） | 无费用扣除 |

---

### Step 2（工资薪金）：个税计算追问

```
请提供以下信息（用于计算月度预扣税额）：

  - 月收入（税前）：______元
  - 五险一金个人缴纳部分：______元（可不填，系统自动按标准估算）
  - 专项附加扣除项目（可多选）：
      □ 子女教育（每孩每月2000元）
      □ 继续教育（每月400元 / 学历每月400元）
      □ 住房贷款利息（每月1000元）
      □ 住房租金（按城市：甲类1500/乙类1100/丙类800元/月）
      □ 赡养老人（独生子女3000/非独生子女分摊）
      □ 大病医疗（年度据实扣除，上限80000元）
      □ 婴幼儿照护（每孩每月2000元）
  - 本年已预扣税额（累计）：______元（用于精确计算）
```

**计算逻辑**：
```
应纳税所得额 = 累计收入 - 累计减除费用(每月5000) - 累计五险一金 - 累计专项附加扣除
预扣税额 = 应纳税所得额 × 适用税率 - 速算扣除数 - 本年已预扣税额
```

---

### Step 3（劳务报酬）：预扣税计算

```
单次劳务报酬金额：______元（含税 / 不含税？）
是否为全年累计已超过6万元的同一支付方：□是 □否
```

**计算公式**：
```
收入 ≤ 4000元：应纳税所得额 = 收入 - 800
收入 > 4000元：应纳税所得额 = 收入 × (1 - 20%)

预扣税额 = 应纳税所得额 × 预扣率 - 速算扣除数

预扣率表：
  ≤ 20000元    → 20%，速算扣除数0
  20001-50000  → 30%，速算扣除数2000
  > 50000      → 40%，速算扣除数7000
```

---


## 四、企业所得税优惠判定决策树

**触发词**：企业所得税、所得税、小微企业、高新技术、研发加计扣除、减免税、优惠税率

### Step 1：企业类型确认

```
企业基本情况：

  □ 居民企业（在中国境内登记注册，或实际管理机构在境内）
  □ 非居民企业（境外注册，在境内设有机构场所）
  □ 非居民企业（境外注册，在境内无机构场所，仅有境内来源所得）

企业规模（可选，用于判断小微资格）：
  - 上年度应纳税所得额：______万元
  - 从业人数：______人
  - 资产总额：______万元
```

---

### Step 2：优惠类型确认

```
想咨询哪类优惠？

  A. 小型微利企业低税率优惠（5% / 25%减半）
  B. 高新技术企业15%税率
  C. 技术先进型服务企业15%税率
  D. 研发费用加计扣除（100%）
  E. 重点区域优惠（海南、前海、横琴、中西部等）
  F. 特定行业优惠（软件、集成电路等）
  G. 亏损结转
  H. 资产重组特殊性税务处理
```

| 优惠类型 | 关键条件 | 当前政策 |
|---------|---------|---------|
| A：小型微利 | 年应纳税所得额≤300万元，从业人数≤300人，资产总额≤5000万元 | 300万以内5%（实际25%×20%减半×50%=2.5%），执行至2027年12月31日 |
| B：高新 | 四项指标（知识产权/科研人员比/研发费比/高新收入比）均满足，每三年重新认定 | 15%，需保持资质有效 |
| C：技服 | 认定为技术先进型服务企业 | 15%，限认定地区 |
| D：研发加计 | 费用归集符合规定，按政策年度执行 | 100%加计扣除（2023年起制度化），含委托研发80% |
| E：区域 | 注册在特定区域、符合主业要求 | 15%（海南自贸港等），适用条件严格 |

---

### Step 3（小微优惠）：资格逐项核验

```
请逐项确认：

  ① 上年度应纳税所得额：______万元
     → ≤300万元 ✅  >300万元 → 不满足小微条件

  ② 从业人数（含外包人员）：______人
     → ≤300人 ✅  >300人 → 不满足

  ③ 资产总额（年初+年末平均）：______万元
     → ≤5000万元 ✅  >5000万元 → 不满足

  ④ 是否属于限制类/禁止类行业：□ 是（不适用）  □ 否 ✅
```

**计算公式（满足全部条件时）**：
```
应纳所得税额 = 年应纳税所得额 × 25% × 20% × 50%
             = 年应纳税所得额 × 2.5%

（适用至2027年12月31日）
```

## 五、合同印花税判定决策树

**触发词**：印花税、合同要不要缴税、这份合同、协议、合同金额

### Step 1：合同/文件类型确认

```
这份文件属于哪类合同？

  A. 借款合同（金融机构贷款 / 民间借贷）
  B. 买卖合同（货物买卖、不动产买卖）
  C. 加工承揽合同
  D. 建设工程合同（勘察、设计、施工）
  E. 租赁合同（不动产、动产）
  F. 技术合同（开发、转让、咨询、服务）
  G. 产权转移书据（股权转让、不动产权转移）
  H. 营业账簿（企业注册资本）
  I. 证券交易（A股、B股买卖）
  J. 不在上述列表的合同
```

| 合同类型 | 税率 | 备注 |
|---------|------|------|
| A：借款合同 | 0.05‰ | 金融机构与非金融企业对贷款合同免征（2029年12月31日前） |
| B：买卖合同（货物） | 0.3‰ | 不动产买卖按产权转移书据1‰ |
| C：加工承揽 | 0.3‰ | |
| D：建设工程 | 0.3‰ | |
| E：租赁合同 | 1‰ | |
| F：技术合同 | 0.3‰ | |
| G：产权转移书据 | 1‰ | 不动产1‰，A股/B股交易1‰（每方） |
| H：营业账簿 | 0.25‰ | 按实收资本+资本公积合计贴花 |
| I：证券交易 | 1‰（出让方） | 2023年8月起0.5‰→1‰，单边征收（出让方），买方免 |
| J | 不在列举范围 | **不征印花税** |

## 七、追问规则总则

1. **不超过3轮追问**：每轮追问收集1-2个关键信息，不堆砌所有问题。
2. **给出选项而不是开放式问题**：用勾选框代替"请描述你的情况"。
3. **每轮追问后给出预期**：告知"根据您的回答，下一步将为您[判断XX/计算XX/提供XX]"。
4. **详细问题跳过追问**：若用户在首次提问中已涵盖关键信息，直接给出结论，无需走决策树。
5. **计算类问题必须说明假设**：回答时明确"以下计算基于您提供的数据，如有变化请重新计算"。
6. **兜底说明**：每个结论末尾均附【时效提示】，引导用户通过官方渠道最终确认。
