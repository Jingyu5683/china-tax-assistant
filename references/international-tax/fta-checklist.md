## 检查表概述

本检查表用于判定非居民企业或个人是否有权享受中国对外签署的税收协定待遇。

### 使用说明

1. 按顺序完成各步骤检查
2. 所有检查项均满足方可享受协定待遇
3. 任一检查项不满足，需进一步评估或放弃协定申请
4. 保留完整的证明材料

## 适用条件检查

### 第一步：确认协定关系

| 检查项 | 检查内容 | 结果 |
|-------|---------|------|
| 对方国家/地区 | 确认所在国家（地区）与中国签有税收协定 | □ 是 □ 否 |
| 协定生效时间 | 确认协定已生效实施 | □ 是 □ 否 |
| 协定适用范围 | 确认所得类型在协定覆盖范围内 | □ 是 □ 否 |

**说明**：
- 中国已与107个国家（地区）签署税收协定
- 部分协定可能仅涵盖特定所得类型
- 香港、澳门属于"安排"而非"协定"

### 第二步：确认居民身份

| 检查项 | 检查内容 | 结果 |
|-------|---------|------|
| 税收居民定义 | 在对方国家（地区）是否满足税收居民定义 | □ 是 □ 否 |
| 居住时间 | 停留/注册时间是否满足居民认定条件 | □ 是 □ 否 |
| 居所测试 | 是否有永久性住所/习惯性居住地 | □ 是 □ 否 |
| 居民证明 | 是否能提供有效的税收居民身份证明 | □ 是 □ 否 |

**法规依据**：协定第二条（人）/相关条款

**证明材料**：
- 税收居民身份证明（Form/Certificate）
- 企业注册证明
- 实际管理机构证明
- 完税证明

### 第三步：确认所得类型

| 检查项 | 检查内容 | 结果 |
|-------|---------|------|
| 所得分类 | 股息/利息/特许权使用费/其他 |  |
| 协定条款 | 该所得类型是否在协定中有专门条款 | □ 是 □ 否 |
| 特别规定 | 是否满足协定中的特别规定 | □ 是 □ 否 |

**协定条款对照**：
| 所得类型 | 协定条款 | 税率限制 |
|---------|---------|---------|
| 股息 | 股息条款 | 通常5%-15% |
| 利息 | 利息条款 | 通常10%-15% |
| 特许权使用费 | 特许权使用费条款 | 通常10%-15% |
| 营业利润 | 营业利润条款 | 无常设机构不征税 |
| 财产收益 | 财产收益条款 | 视情形而定 |

## 受益所有人判定

### 第四步：受益所有人身份

| 检查项 | 检查内容 | 结果 |
|-------|---------|------|
| 直接受益人 | 所得的实际受益人是谁 |  |
| 中间层 | 是否有中间层公司/个人 | □ 是 □ 否 |
| 受益所有人认定 | 最终受益人是否为"受益所有人" | □ 是 □ 否 |

**受益所有人定义**：
- 对所得具有所有权和支配权的人
- 通常是最终享有所得经济利益的人
- 需评估是否存在导管公司安排

### 第五步：导管公司排除

| 检查项 | 检查内容 | 结果 |
|-------|---------|------|
| 设立目的 | 公司是否仅为获取协定待遇而设立 | □ 是 □ 否 |
| 营业实质 | 公司是否有真实的经营业务 | □ 是 □ 否 |
| 人员配置 | 公司是否有足够的员工和办公场所 | □ 是 □ 否 |
| 利润水平 | 公司利润是否与经营实质相匹配 | □ 是 □ 否 |
| 合同签订 | 公司是否独立签订合同 | □ 是 □ 否 |

**导管公司典型特征**：
- 设立时间短，无实际经营
- 注册于低税地或无实质经营地
- 仅为过境资金/所得设立
- 利润水平显著低于行业平均

## 协定滥用排除

### 第六步：主要目的测试（PPT）

| 检查项 | 检查内容 | 结果 |
|-------|---------|------|
| 交易实质 | 交易是否有合理商业目的 | □ 是 □ 否 |
| 利润水平 | 利润安排是否符合独立交易原则 | □ 是 □ 否 |
| 时间因素 | 架构调整是否在协定签署/修订后 | □ 是 □ 否 |
| 综合判断 | 取得协定利益是否为主要目的之一 | □ 是 □ 否 |

**BEPS第6项行动计划**：
- 主要目的测试（Principal Purpose Test, PPT）
- 如果取得协定待遇是某安排的"主要目的之一"，则不得享受协定待遇

### 第七步：其他反滥用规则

| 检查项 | 检查内容 | 结果 |
|-------|---------|------|
| 参股豁免例外 | 是否满足参股豁免的持股/时间条件 | □ 是 □ 否 |
| 背靠背安排 | 是否存在资金来源/去向的背靠背安排 | □ 是 □ 否 |
| 利益限制 | 是否受到协定中利益限制条款约束 | □ 是 □ 否 |

## 申请流程

### 源泉扣缴场景

```
付款方扣缴税款前
    │
    ▼
┌─────────────────┐
│ 提交申请材料    │ → 税收居民身份证明、合同、收款人信息等
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 付款方审核      │ → 审核协定待遇申请材料
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 适用协定税率    │ → 确认符合条件后适用协定限制税率
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 申报缴纳        │ → 向主管税务机关申报缴纳
└─────────────────┘
```

### 自行申报场景

| 步骤 | 说明 |
|------|------|
| 1. 确认身份 | 取得税收居民身份证明 |
| 2. 准备材料 | 合同、付款证明、企业信息等 |
| 3. 提交申请 | 向主管税务机关提交协定待遇申请 |
| 4. 税务机关审核 | 税务机关审核后出具确认文件 |
| 5. 办理退税 | 预缴税款后申请退税 |

## 典型问题

### Q1：境外公司能否享受协定待遇？

**判断标准**：
1. 公司是否为协定对方国的税收居民
2. 公司是否为所得的"受益所有人"
3. 是否存在协定滥用情形

### Q2：多层持股架构如何享受协定待遇？

**评估要点**：
- 每一层持股公司是否均为税收居民
- 每一层是否都具有实质性经营
- 最终受益人是否满足持股比例要求

### Q3：税收居民身份证明有时效吗？

**通常要求**：
- 税收居民身份证明通常有有效期（如1年内有效）
- 跨越年度的所得可能需要更新证明
- 部分协定要求证明"当年"或"相关年度"的居民身份

### Q4：享受协定待遇后是否需要持续符合条件？

**是的**，需持续满足以下条件：
- 保持协定对方国税收居民身份
- 保持受益所有人地位
- 不发生导致协定滥用的事项
- 保留完整的证明材料备查
