# 香港税务法规参考

**来源**：香港税务局 (www.ird.gov.hk)  
**生效日期**：各税种按章节标注  
**最后更新**：2026-05-25  
**【时效提示】** 香港税制以年度财政预算案为重要调整节点，以下内容基于2026年5月官网数据，建议以最新课税年度为准。

## 一、香港税制概述

香港实行**地域来源征税原则**：
- 仅对「于香港产生或得自香港」的利润/收入征税
- 源自香港以外的利润/收入，一般无须在香港课税
- 此原则同时适用于居民和非居民纳税人

**主要税种**：
| 税种 | 法规依据 | 征税对象 |
|------|---------|---------|
| 利得税 | 《税务条例》(第112章) | 在香港经营行业/专业/业务的利润 |
| 薪俸税 | 《税务条例》(第112章) | 在香港受雇/出任职位/领取退休金的入息 |
| 物业税 | 《税务条例》(第112章) | 香港物业出租的应评税净值 |
| 印花税 | 《印花税条例》(第117章) | 不动产转让/股票转让/租约等文书 |
| 博彩税 | 《博彩税条例》 | 赛马/足球博彩/彩票收入 |
| 酒店房租税 | 《酒店房租税条例》 | 酒店/宾馆房租收入 |
| 汽车首次登记税 | 《汽车首次登记税条例》 | 首次登记的汽车 |

## 二、利得税（Profits Tax）

### 2.1 征税范围

**纳税人**：任何人士，包括法团、合伙业务、受托人或团体。

**地域来源原则**：
- 仅在香港经营行业、专业或业务，并从该业务中获得**于香港产生或得自香港**的应评税利润（售卖资本资产所得利润除外），均须缴纳利得税
- 居港人士得自海外的利润可毋须在香港纳税
- 非居港人士如赚取于香港产生的利润，则须纳税

**视作营业收入的项目**：
1. 在香港使用电影/电视片胶卷、纪录带、录音等获得的款项
2. 在香港使用或授权使用专利、设计、商标、版权、集成电路布图设计、表演者权利、植物品种权利、秘密工序或方程式而收取的款项
3. 在香港以外使用上述知识产权，且该款项在利得税计算中可予扣除的，亦须课税
4. 因转让表演者权利而支付给表演者或筹办人的费用（与2018年6月29日或之后在香港作出的表演有关）
5. 因在香港经营业务而收取的补助金、津贴或类似资助（资本开支相关者除外）
6. 因容许或授权在香港使用动产而以租赁费、租金等形式收取的款项

### 2.2 两级制税率（2018/19及其后）

| 纳税人类型 | 首200万港元应评税利润 | 超出200万港元部分 |
|-------------|---------------------------|----------------------|
| **法团** | **8.25%**（16.5%的一半） | **16.5%** |
| **法团以外人士**（非法团业务） | **7.5%**（15%的一半） | **15%** |

**有关连实体规则**（重要限制）：
- 同一组有关连实体在**同一课税年度内，只能提名其中1家实体适用两级制税率**
- 「有关连实体」定义：一方控制另一方，或两方均受同一实体控制
- 「控制」标准：拥有超过50%已发行股本 / 控制超过50%表决权 / 享有超过50%资本或利润

**不可同时适用的优惠**：
- 若某法团已就合资格保险业务、企业财资中心、飞机出租/管理、船舶出租/管理、专业再保险等选择特惠税率，则不可同时适用两级制

### 2.3 特惠税率（部分项目）

| 项目 | 税率 | 条件 |
|------|------|------|
| 合资格企业财资中心/飞机出租商等 | 8.25%（16.5%的一半） | 须符合特定条件 |
| 合资格船舶出租商 | 0% 或 8.25% | 视具体情况 |
| 具资格知识产权的合资格收入（专利盒） | **5%** | 2023年4月1日起，须符合关联法要求 |
| 长期债务票据（2018.4.1后发行） | 豁免 | — |
| 家族投资控权工具（合资格部分） | 0% | 须符合特定条件 |

### 2.4 可扣除开支与不可扣除项目

**可扣除原则**：为赚取应评税利润而付出的各项开支费用，一般均可扣除。

**不可扣除的开支**：
- 家庭或私人开支
- 资本亏损、改进成本或资本性质开支
- 可根据保险或弥偿合约收回的款项
- 非为产生应评税利润而使用楼宇的租金或有关开支
- 根据《税务条例》缴纳的各种税款（已缴付的薪俸税除外）
- 支付予东主/配偶、合伙人/配偶的薪酬、资本利息、贷款利息或超出条例规定的强制性公积金供款

**专项扣除**：
| 项目 | 扣除规则 |
|------|---------|
| 建筑物翻修开支 | 可分5年等额扣除 |
| 制造业机械及工业装置、电脑硬件及软件 | 可在招致开支的评税基期内**整笔扣除** |
| 环保设施开支（环保机器/装置/车辆） | 整笔扣除 |
| 认可慈善捐款 | 不少于100港元，上限为未扣捐款前应评税利润的**35%**（2003/04-2007/08年度为25%） |

### 2.5 折旧免税额

**商业或工业建筑物/构筑物**：
- 商业建筑物：每年免税额为建造成本的**4%**，使用期上限25年
- 工业建筑物：初期免税额20%（仅限建造者）；每年免税额4%

**机械及工业装置**：
- 初期免税额：资产成本的**60%**
- 每年免税额：按资产递减价值计算，折旧率分别为10%/20%/30%

### 2.6 亏损处理

- 某一课税年度蒙受的亏损，可**结转**抵销随后年度的该行业利润
- 经营多于一种行业的法团，可用**一行业的亏损抵销另一行业的利润**
- 选择**个人入息课税**的人士，可在入息总额内扣除营业亏损

### 2.7 豁免项目

**应评税利润不包括**：
- 已缴付香港利得税的法团所分派的股息
- 从其他应课利得税人士收取的已课税利润
- 储税券利息
- 根据《借款条例》或《借款（政府债券）条例》发行的债券所派发的利息及利润
- 长期债务票据利息收入及利润（2018年4月1日或之后发行）
- 就指明投资计划（如认可集体投资计划）收取或应累算的款项

**任何人士可获豁免缴付利得税的项目**：
- 在香港认可机构存款所赚取的利息（1998年6月22日或之后累算，但不包括财务机构收取的）
- 2009/10课税年度起，人民币国债的利息和利润

## 三、薪俸税（Salaries Tax）

### 3.1 征税范围

**纳税人**：在香港受雇、出任职位或领取退休金的人士（包括董事）。

**入息定义**：
- 任何因受雇工作而于香港产生或得自香港的入息，均须缴纳薪俸税
- 「香港受雇」与「非香港受雇」的区分：香港受雇的入息全部须缴纳薪俸税；非香港受雇只就香港部分工作所对应的入息课税

### 3.2 税率结构

**标准税率**：**15%**

**累进税率**（按应评税入息净额计算）：

| 应评税入息净额 | 税率 |
|---------------|------|
| 不超过50,000港元 | 2% |
| 50,001 – 100,000港元 | 6% |
| 100,001 – 150,000港元 | 10% |
| 150,001 – 200,000港元 | 14% |
| 超过200,000港元部分 | 17% |

**税款计算方式**：按累进税率和标准税率**分别计算，取较低者**。

### 3.3 免税额（2024/25课税年度，HKSAR）

| 免税额类别 | 金额（港元） |
|------------|------------|
| **基本免税额** | **132,000** |
| 已婚人士免税额 | 264,000 |
| 子女免税额（每名） | 130,000 |
| └ 首名出生子女额外免税额 | 130,000（即合计260,000） |
| 供养父母/祖父母/外祖父母（60-69岁） | 50,000（每名） |
| 供养父母/祖父母/外祖父母（70岁或以上） | 100,000（每名） |
| 单亲免税额 | 132,000 |
| 伤残人士免税额 | 75,000 |
| 伤残受养人免税额（每名） | 75,000 |

> **注**：以上金额为2024/25年度数据，课税年度每年可能调整，建议查阅最新税率表。

### 3.4 税项扣除（2024/25课税年度）

| 扣除项目 | 上限（港元） |
|------------|------------|
| 认可慈善捐款 | 应评税入息的35% |
| 强制性公积金（MPF）供款 | 18,000 |
| 居所贷款利息 | 100,000（2024/25年度） |
| 住宅租金税项扣除 | 100,000（2024/25年度） |
| 自愿医保计划保费（每名受保人） | 8,000 |
| 合资格年金保费 / 可扣税强积金自愿性供款 | 60,000（合计上限） |
| 辅助生育服务开支 | 100,000 |

> **注**：居所贷款利息和住宅租金扣除限额已提高，具体金额按年度财政预算案调整。

### 3.5 个人入息课税（Personal Assessment）

**适用条件**：纳税人同时有薪俸税、利得税、物业税其中两类或以上收入，可申请选择个人入息课税。

**优点**：
- 可将各类收入合计，统一适用累进税率（最高17%）
- 可扣除利息支出、捐赠等个人开支
- 亏损可抵销其他类别收入

## 四、物业税（Property Tax）

### 4.1 征税范围

物业税是就香港物业的租金收入征收的税项。

**课税范围**：
- 业主从香港物业收取的租金收入（包括预付租金、租赁定金等）
- 业主若选择个人入息课税，物业税可并入个人入息一并评税

### 4.2 税率

**标准税率**：**15%**

### 4.3 应评税净值计算

| 计算步骤 | 说明 |
|----------|------|
| 第一步：应评税值 | = 课税年度出租总收入 - 该年度不能追回的租金 |
| 第二步：扣除业主缴付的差饷 | 仅业主实际支付的差饷可扣除 |
| 第三步：扣除修葺及支出标准免税额 | =（应评税值 - 差饷）× **20%**（法定标准扣除，无需凭证）|
| 第四步：应评税净值 | =（应评税值 - 差饷 - 修葺免税额）|
| **物业税** | = 应评税净值 × 15% |

**示例**：
- 月租30,000港元，全年租金270,000港元
- 业主全年缴差饷12,000港元
- 应评税值：270,000港元
- 扣除差饷后：270,000 - 12,000 = 258,000港元
- 修葺免税额：258,000 × 20% = 51,600港元
- 应评税净值：258,000 - 51,600 = 206,400港元
- 物业税：206,400 × 15% = **30,960港元**

## 五、印花税（Stamp Duty）

### 5.1 物业买卖印花税

#### 从价印花税（AVD）

**第2标准税率**（适用于非住宅物业及2024年2月28日后的住宅物业，2025年2月26日起生效）：

| 代价款额或价值（较高者） | 税率 |
|--------------------------|------|
| 不超逾4,000,000港元 | **100港元** |
| 4,000,000 – 4,323,780港元 | 100港元 + 超逾4,000,000部分的20% |
| 4,323,780 – 4,500,000港元 | **1.5%** |
| 4,500,000 – 4,935,480港元 | 67,500港元 + 超逾4,500,000部分的10% |
| 4,935,480 – 6,000,000港元 | **2.25%** |
| 6,000,000 – 6,642,860港元 | 135,000港元 + 超逾6,000,000部分的10% |
| 6,642,860 – 9,000,000港元 | **3%** |
| 9,000,000 – 10,080,000港元 | 270,000港元 + 超逾9,000,000部分的10% |
| 10,080,000 – 20,000,000港元 | **3.75%** |
| 20,000,000 – 21,739,120港元 | 750,000港元 + 超逾20,000,000部分的10% |
| 21,739,120港元以上 | **4.25%** |

**2026-27财政预算案建议**（尚未立法通过）：
- 价值1亿港元以上住宅物业：税率调高至最高**6.5%**
- 非住宅物业维持最高4.25%不变

#### 买家印花税（BSD）

- **适用期间**：2012年10月27日至2024年2月27日
- **税率**：**15%**（按代价款额或市值较高者计算）
- **现状**：2024年2月28日起**不再征收**买家印花税

#### 额外印花税（SSD）

- **适用期间**：持有住宅物业短期内转售须缴额外印花税
- **现状**：2024年2月28日起**不再适用**额外印花税

### 5.2 股票转让印花税

**由2023年11月17日起**：

| 文件性质 | 收费 |
|----------|------|
| 售卖或购买香港证券的成交单据 | 代价款额或价值的 **0.1%**（每张单据，不足1港元按1港元计）|
| 无偿产权处置转让书 | 5港元 + 转让证券价值的 **0.2%** |
| 其他转让书 | **5港元**（定额）|

### 5.3 租约印花税

| 租期 | 收费 |
|------|------|
| 不确定或租期不固定 | 年租或平均年租的 **0.25%** |
| 不超过1年 | 租金总额的 **0.25%** |
| 超过1年但不超过3年 | 年租或平均年租的 **0.5%** |
| 超过3年 | 年租或平均年租的 **1%** |

### 5.4 印花税宽免

主要宽免类别：
1. **集团内部转让宽免**：相联法人团体之间转移不动产或股票，符合《印花税条例》第45条条件者可获宽免；2026-27财政预算案建议将关联门槛由90%下调至75%
2. **证券借贷宽免**：根据证券借用及借出交易进行的股票转移可豁免印花税
3. **伊斯兰债券计划宽免**：符合指明条件的伊斯兰债券计划下发行的债券及相关文书可获豁免
4. **强制性公积金计划单位转让文书豁免**

## 六、外地收入豁免征税机制（FSIE）

### 6.1 机制概述

为符合欧盟《外地收入豁免征税机制的指引》，香港于2023年1月1日起实施新的外地收入豁免征税机制。

**涵盖的收入类型**（2023年1月1日起）：
1. **利息**
2. **股息**
3. **合资格知识产权收入**（特许权使用费等）
4. **股权权益处置收益**（2023年1月1日起）；**处置收益**（扩大至所有财产，2024年1月1日起）

**推定规则**：符合以下情况的指明外地收入视作来源自香港并应课缴利得税：
- 该收入由在香港经营行业/专业/业务的跨国企业实体在香港收取
- 且该实体未能符合相关例外要求

### 6.2 例外情况（免征条件）

| 例外要求 | 适用收入类型 |
|----------|-------------|
| **经济实质要求** | 利息、股息、非知识产权处置收益 |
| **关联要求**（Nexus Approach） | 合资格一般知识产权收入、合资格知识产权处置收益 |
| **持股要求** | 股息、股权权益处置收益 |
| **集团内部转让宽免** | 处置收益（2024年1月1日起）|

#### 经济实质要求

**纯股权持有实体**：
- 须遵从香港公司注册及商业登记规定
- 在香港有足够的人力资源及处所，以进行持有和管理股权权益的指明经济活动

**非纯股权持有实体**：
- 在香港雇用足够数量且具有进行指明经济活动所需资格的员工
- 为进行指明经济活动而在香港招致足够的营运开支总额
- 指明经济活动：就其取得、持有或处置的任何资产作出所需的策略决定，以及就该资产管理及承担主要风险

**外判安排**：可将部分指明经济活动外判，但须履行充分监管及控制，外判实体须在香港有足够资源和合资格员工。

#### 关联要求（专利盒机制）

- 只有来自**合资格知识产权**的收入，才能按关联比例享受5%优惠税率
- **合资格知识产权**：香港批予的专利、香港专利申请、软件版权、香港以外地方的同等知识产权
- **研发分数** = 合资格研发开支(QE) × 130% / (QE + 不合资格开支(NE))，上限100%
- **过渡安排**：2023/24至2025/26课税年度可采用3年滚动平均比率

#### 持股要求

须同时满足：
1. 该跨国企业实体属香港居民人士，或有关收入可归因于其在香港设有的常设机构
2. 在紧接有关收入累算之前的不少于**12个月**的期间，持续持有获投资实体不少于**5%**的股权权益
3. **切换规则（应税条件）**：有关收入须在外地税务管辖区被征收合资格类似税项，且适用税率至少**15%**

### 6.3 受规管财务实体豁除

指明外地收入不包括累算归于以下实体的利息、股息或非知识产权处置收益：
- 根据《保险业条例》获授权的保险人
- 《银行业条例》所界定的认可机构（银行、有限制牌照银行、接受存款公司）
- 根据《证券及期货条例》获发牌经营受规管活动的实体

## 八、专利盒机制（Patent Box）

### 8.1 合资格知识产权收入

1. 因在香港或境外展示/使用合资格知识产权，或授予他人使用该权利而产生的收入
2. 因传授与该知识产权使用有关的知识而产生的收入
3. 出售合资格知识产权取得的处置收益
4. 产品或服务价格中可归因于该合资格知识产权的价值部分
5. 就该合资格知识产权取得的保险赔付、损害赔偿或补偿款额

### 8.2 优惠税率

- 合资格知识产权收入的**特惠部分**按 **5%** 缴纳利得税
- **特惠部分** = 合资格知识产权收入 × 研发分数（上限100%）
- 选择专利盒机制的税务宽减后，**不可同时适用两级制利得税率**

### 8.3 合资格条件

**合资格知识产权**：
- 香港《专利条例》（第514章）批予的专利，或香港专利申请
- 香港以外地方的法律批予的同等专利或专利申请
- 根据香港《版权条例》（第528章）存在于软件中的版权

**研发分数计算**：
- 公式：`F = QE × 130% / (QE + NE)`
  - QE = 合资格研发开支
  - NE = 不合资格开支
- 上限：**100%**

## 九、其他重要税务措施

### 9.1 家族投资控权工具（FIHV）税务宽减

- 合资格的家族投资控权工具及其母实体，从合资格交易和附带权益获得的应评税利润的**合资格部分**，可按 **0%** 税率缴纳利得税
- 须符合经济实质要求及家族中央管理和控制的香港管辖要求

### 9.2 处置股权权益的税务明确性优化计划

- 明确香港对处置股权权益所得收益（资本性质）**不征收利得税**的立场
- 适用于2024年1月1日或之后处置的股权权益

### 9.3 全球最低税（BEPS 2.0 支柱二）

- 跨国企业集团年度合并收入≥7.5亿欧元的，须在香港缴纳**香港最低补足税**（HKMTT）
- 适用范围：2025年1月1日或之后开始的课税年度

## 十、申报要求

### 10.1 利得税报税表（BIR51 / BIR52 / BIR54）

- 通常在4月1日发出，须在1个月内提交（可申延至7/8月）
- 须同时提交经审计的财务报表及税务计算表
- 自2023年起，较大规模集团须以iXBRL格式电子提交

### 10.2 薪俸税报税表（BIR60）

- 通常在5月1日发出，须在1个月内提交
- 可选择个人入息课税（须于报税表中声明）

### 10.3 物业税报税表（BIR57 / BIR58）

- 业主如未收到报税表但有大额租金收入，须主动通知税务局

### 10.4 罚款及违规后果

- 迟交报税表：最高罚款10,000港元 + 3倍漏报税款
- 递交不正确报税表：最高罚款10,000港元 + 3倍漏报税款 + 监禁6个月
- 蓄意逃税：最高罚款50,000港元 + 3倍漏报税款 + 监禁3年
