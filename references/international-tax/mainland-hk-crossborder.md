# 内地与香港跨境税务专题

**来源**：内地-香港安排（1998/2006/2008/2010/2015/2019议定书）+ 香港税务局官网  
**最后更新**：2026-05-25  
**【时效提示】** 内地与香港安排历经6次修订，当前以2019年第五议定书为最新；以下信息基于2026年5月官网数据，建议以最新协议文本为准。

## 专题一：内地与香港避免双重征税安排

### 1.1 适用税种

| 管辖区 | 适用税种 |
|---------|---------|
| **内地** | 个人所得税、企业所得税 |
| **香港** | 利得税、薪俸税、物业税 |

### 1.2 常设机构（Permanent Establishment, PE）

**定义**：
- 建筑工地、建筑、装配或安装工程，或者与其有关的监督管理活动，持续时间**12个月以上**的，构成常设机构
- 为勘探、开采或开发自然资源所提供的劳务，持续时间12个月以上的，构成常设机构
- 企业通过代理人（非独立代理人）在另一方从事营业活动，有权以企业名义签订合同并经常行使该权利的，构成常设机构

**重要影响**：
- 利润归属：常设机构利润应仅在该常设机构所在方征税
- 独立交易原则：将常设机构视为独立分设企业，完全独立地与其所属企业及关联企业进行交易
- 费用扣除：计算常设机构利润时，允许扣除其进行营业发生的各项费用（包括管理/一般行政费用）

### 1.3 股息预提税率

| 条件 | 预提税率 |
|------|---------|
| 直接持股≥25% | **5%** |
| 其他情况 | **10%** |

**持股免税安排（香港FSIE机制下）**：
- 香港居民人士在紧接股息累算前不少于12个月的期间，持续持有获投资实体不少于5%的股权权益
- 须符合「应税条件」：股息或基础利润在外地税务管辖区被征收合资格类似税项，且适用税率至少**15%**

### 1.4 利息预提税率

| 收款人身份 | 预提税率 |
|-----------|---------|
| 香港政府、地方当局、中央银行、完全为政府拥有的金融机构 | ≤ **7%** |
| 其他香港居民收款人 | **7%** |

### 1.5 特许权使用费与技术费

| 收入类型 | 预提税率 |
|-----------|---------|
| 特许权使用费 | ≤ **7%** |
| 技术费 | ≤ **7%** |

### 1.6 财产收益（股权转让收益）

| 情形 | 征税权 | 税率上限 |
|------|---------|---------|
| 股份50%以上价值来自香港不动产 | 香港有权征税 | — |
| 转让常设机构营业财产部分股份（含无形资产） | 常设机构所在方有权征税 | — |
| 转让前12个月内曾经直接/间接拥有该公司≥25%股份 | 转让方居民所在方有权征税 | **10%** |
| 转让其他类型财产 | 按财产所在国或实际管理机构所在国国内法 | — |

### 1.7 海运与空运

- 缔约国一方企业以船舶或飞机经营**国际运输业务**所取得的利润，应仅在该缔约国征税
- 附属于国际运输业务的利润（特别包括以光租形式出租船舶/飞机、集装箱及相关设备）应仅在该缔约国征税
- 缔约国另一方应免征增值税、营业税等相关流转税

### 1.8 独立/非独立个人劳务

**独立个人劳务**：
- 般应仅在居民所在方征税
- 如在另一方设有**经常使用的固定基地**，或在该另一方有关会计年度内停留**连续或累计达到或超过183天**，可在该另一方征税

**非独立个人劳务（受雇）**：
- 般应仅在居民所在方征税
- 如在另一方从事受雇活动，取得的报酬可在该另一方征税
- 跨境通勤、董事费、演艺人员/运动员报酬适用特殊规则

### 1.9 消除双重征税方法

**内地方面**：
- 内地居民从香港取得的所得，按照本安排规定在香港缴纳的税额，允许在对该居民征收的内地税收中**抵免**
- 抵免额不超过按内地税法规定计算的应纳税额

**香港方面**：
- 香港居民从内地取得的所得，按照本安排规定在内地缴纳的税额，允许在对该居民征收的香港税收中**抵免**
- 抵免额不超过按香港税法规定计算的应纳税额

### 1.10 相互协商程序（MAP）

- 纳税人认为缔约国一方或双方的措施导致或将导致对其征税不符合本安排规定的，可**不考虑国内法规定的救济措施**，将案情提交给其为其居民的缔约国主管当局
- 主管当局如认为所提意见合理且不能单方面圆满解决时，应设法同缔约国另一方主管当局相互协商解决
- 双方主管当局可直接相互联系以达成相关协议

### 1.11 信息交换

- 双方主管当局应交换可以预见的、与执行本安排规定相关的信息
- 收到的任何信息应作密件处理，仅告知与执行本安排相关的人员或当局
- **不得**要求交换可能泄露贸易、经营、工业、商业或专业秘密的信息，或公开后会违反公共政策的信息

## 专题二：内地企业/个人在港税务实务

### 2.1 内地企业在香港设立机构

**税务影响**：
- 如构成**常设机构**（建筑工地持续12个月以上 / 有固定营业场所），该常设机构利润须在香港缴纳利得税
- 香港利得税两级制：法团首200万港元利润按**8.25%**，超出部分**16.5%**
- 地域来源原则：仅「于香港产生或得自香港」的利润须在香港课税

**常设机构利润归属注意事项**：
- 须按**独立交易原则**将常设机构视为独立分设企业
- 与内地总机构之间的交易（管理费分摊、技术服务费等）须有合理商业实质，否则可能被税务局调整
- 常设机构亏损可结转抵销随后年度利润

### 2.2 内地个人在香港工作

**薪俸税影响**：
- 「香港受雇」：所有入息均须缴纳香港薪俸税
- 「非香港受雇」：仅就香港工作部分对应的入息课税（按停留天数分摊）
- **183天规则**：在一个课税年度内（4月1日至次年3月31日）在香港停留不超过60天通常无需缴纳薪俸税；如超过60天则可能须课税

**内地个税与香港薪俸税双重征税处理**：
- 适用内地-香港安排，已在香港缴纳的薪俸税可在内地个税中抵免
- 抵免上限为按内地税法计算的应纳税额中对应于该收入的部分

### 2.3 内地与香港跨境股息/利息/特许权使用费

**内地企业收取香港子公司股息**：
- 如内地企业直接持股香港子公司≥25%，香港预提税率：**5%**
- 其他情况：香港预提税率：**10%**
- 内地方面：该股息须计入内地企业所得税应纳税所得额，但已在香港缴纳的利润税可抵免

**香港企业收取内地子公司股息**：
- 内地预提税率：香港居民直接持股≥25%为**5%**，其他为**10%**
- 香港方面：如该股息属「于香港产生或得自香港」，须缴纳香港利得税；如属外地收入且在香港收取，须符合FSIE机制下的例外要求（经济实质要求/持股要求）方可豁免

### 2.4 内地企业在香港上市/发行债券

**H股上市**：
- H股公司向境外股东支付的股息，须按10%税率（或5%，如符合条件）扣缴企业所得税
- 非居民企业取得H股股息，内地预提税纳税义务由H股公司代扣代缴

**中资美元债/点心债**：
- 香港投资者持有内地企业在境外发行的债券，利息收入在香港不征税（地域来源原则，利息为外地收入）
- 但须注意FSIE机制：如利息收入在香港收取且不符合经济实质要求/持股要求，可能须缴付利得税

## 专题三：香港居民在内地税务实务

### 3.1 香港居民企业在内地设立外商投资企业（FIE）

**企业所得税**：
-  standard税率：**25%**
- 如符合**高新技术企业**条件：减按**15%**
- 如符合**小型微利企业**条件：减按**20%**（实际税负更低，详见内地税法）

**利润汇回香港**：
- 外商投资企业向香港母公司分配股息，内地须扣缴预提所得税
- 适用内地-香港安排：直接持股≥25%为**5%**，其他为**10%**
- 香港母公司收取股息后在香港的税务处理：如属外地收入且在香港收取，须符合FSIE机制例外要求

### 3.2 香港居民个人在内地工作

**内地个人所得税**：
- 在内地居住**满183天**即为内地税务居民，须就全球收入在内地缴纳个人所得税
- 在内地居住不满183天为非居民，仅就内地来源收入缴纳个税
- 香港居民在内地工作，可适用内地-香港安排，已在内地缴纳的个税可在香港薪俸税中抵免

**大湾区个人所得税优惠**：
- 在粤港澳大湾区工作的香港居民，其在内地缴纳的个人所得税税负超过香港税负的部分，由地方政府给予**补贴**（实质上是税负差额返还）
- 适用条件：在9个城市（广州、深圳、珠海、佛山、惠州、东莞、中山、江门、肇庆）工作并于内地缴纳个人所得税的香港居民

### 3.3 香港居民在内地购置物业

**契税**：
- 个人购买住房：首套房90㎡以下按**1%**，90㎡以上按**1.5%**
- 二套房：90㎡以下按**1%**，90㎡以上按**2%**
- 香港居民在内地购房适用与内地居民相同税率

**房产税（自住用途通常免征或减征）**：
- 个人自住住房通常免征房产税
- 出租用途：按租金收入的**4%**（个人出租住房减按4%）

## 专题四：内地-香港跨境重组与并购税务

### 4.1 跨境股权重组

**适用内地特殊性税务处理的条件**（59号文）：
- 收购方、被收购方须为**居民企业**（香港公司通常不适用，除非满足「境外—境外」特殊规则）
- 如香港公司作为收购方收购内地居民企业股权，通常须按**一般性税务处理**：股权转让收益按10%预提税（如适用安排则为5%）

**香港公司转让内地子公司股权**：
- 如该内地子公司股份50%以上价值来自内地不动产，内地有权征税
- 如转让前12个月内香港公司曾经直接/间接拥有该内地子公司≥25%股份，内地有权征税，预提税率不超过**10%**

### 4.2 内地企业赴港上市重组

**典型重组路径**：
1. 内地企业股东设立香港控股公司（SPV）
2. 香港控股公司收购内地企业股权（「红筹架构」）
3. 内地企业变更为外商独资企业（WFOE）或保持中外合资企业（EJV）结构

**重组环节税务要点**：
- 内地企业股东向香港SPV转让股权：适用内地-香港安排，如直接持股≥25%预提税率**5%**
- 如符合特殊性税务处理条件，可递延纳税

## 专题五：内地与香港税收协定待遇申请实务

### 5.1 香港居民身分证明书（CoR）

**用途**：申请享受内地-香港安排下的优惠预提税率（5%股息/7%利息/7%特许权使用费）的必要文件。

**申请条件**：
- 申请人须为香港居民（公司或个人）
- 须在相关收入累算的课税年度之前或之后提出申请

**申请程序**：
1. 填写税务局指表格（公司：IR1313A；个人：IR1313B）
2. 附上证明文件（公司注册证书、商业登记证、实际管理控制中心在港的证明等）
3. 递交香港税务局「税收协定组」
4. 税务局审批后发出CoR（通常需时4-6周）

### 5.2 内地方面享受安排待遇的程序

**自行判断 + 申报享受**：
- 非居民纳税人可自行判断是否符合享受安排待遇的条件
- 在纳税申报时填报《非居民纳税人享受协定待遇信息报告表》
- 留存备查相关证明文件（包括香港CoR）

**主要留存文件**：
- 香港居民身分证明书（CoR）
- 持股证明（适用于5%股息税率）
- 收款人身分证明

## 专题六：CEPA与税务

### 6.1 CEPA概述

**《关于建立更紧密经贸关系的安排》（CEPA）**：
- 2003年签署，是内地与香港之间全面的自由贸易协议
- 涵盖货物贸易、服务贸易、投资便利化三大领域

### 6.2 CEPA下的税务相关措施

**服务贸易开放**：
- 香港服务提供者在内地享有准入前国民待遇
- 部分服务行业（法律、会计、税务、建筑等）获得更宽松的准入条件

**海关关税优惠**：
- 香港原产货物进入内地**免征进口关税**（须符合CEPA原产地规则）
- 香港原产货物定义：在香港完全获得或完成实质性加工（税则号列前4位改变 + 30%增值标准）

## 专题七：FSIE机制对内地-香港跨境业务的影响

### 7.1 外地收入豁免征税（FSIE）机制概述

香港自2023年1月1日起实施新的FSIE机制，2024年1月1日起扩大至所有处置收益。

**对内地-香港跨境企业的影响**：

| 收入类型 | 在港收取时的税务处理 |
|-----------|----------------|
| 内地子公司股息 | 如不符合经济实质要求/持股要求，视同香港来源利润征收利得税（8.25%/16.5%） |
| 内地子公司利息 | 同上 |
| 内地知识产权特许权使用费 | 须符合关联要求（研发分数），合资格部分按5%征税 |
| 处置内地子公司股权收益 | 如不符合持股要求，视同香港来源利润征收利得税 |

### 7.2 应对策略

**持股要求路径**（适用于股息及股权处置收益）：
- 香港公司须在紧接股息/处置收益累算前不少于12个月期间，持续持有内地子公司不少于**5%**的股权权益
- 内地子公司利润须已在内地被征收企业所得税（税率至少**15%**）

**经济实质要求路径**（适用于利息、股息、非知识产权处置收益）：
- 在香港雇用足够数量的合资格员工
- 在香港招致足够的营运开支总额
- 在香港作出有关资产管理的策略决定，并承担主要风险

**关联要求路径**（适用于知识产权收入）：
- 计算「研发分数」= 合资格研发开支 × 130% / (合资格研发开支 + 不合资格开支）
- 仅合资格部分的收入可按**5%**优惠税率征税
