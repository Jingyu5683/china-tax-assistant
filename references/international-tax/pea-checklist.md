## 判定原则

常设机构（Permanent Establishment，PEA）是税收协定中的核心概念，用于判定非居民企业在另一国是否构成纳税义务。

### 核心判定标准

| 标准 | 说明 |
|------|------|
| 固定性 | 营业场所在地理上和时间上具有相对固定性 |
| 营业性 | 场所用于进行企业的营业活动 |
| 全面性 | 场所用于进行全部或部分营业 |

### 注意事项

- 常设机构的判定应综合考虑所有相关因素
- 临时性活动一般不构成常设机构
- 准备性、辅助性活动一般不构成常设机构
- 需结合具体协定条款判断

## 常设机构类型

### 1. 固定场所型常设机构

**基本特征**：
- 有固定的营业场所
- 场所在时间上具有持续性
- 场所全部或部分用于企业营业

**判定要点**：
| 问题 | 回答要点 |
|------|---------|
| 是否存在物理空间？ | 办公室、工厂、施工现场等 |
| 空间是否相对固定？ | 位置不随项目频繁变动 |
| 是否用于营业目的？ | 非单纯的仓储、保管、展示 |
| 时间是否达到协定门槛？ | 注意协定中的时间要求 |

### 2. 工程型常设机构

**协定通常规定**：
- 建筑工地、建筑、装配或安装工程
- 或与其有关的监督管理活动
- 连续超过特定天数

**中国协定中的时间标准**：
| 协定类型 | 典型时间标准 | 说明 |
|---------|-------------|------|
| 联合国范本倾向 | 6个月 | 中国与多数发展中国家协定 |
| OECD范本倾向 | 12个月 | 中国与部分发达国家协定 |
| 少数协定 | 18个月 | 仅见于个别早期协定 |

**【注】** 中国协定中无统一18个月标准，需按具体协定判断。建议查询国家税务总局协定条款。

**时间计算规则**：
| 计算方式 | 说明 |
|---------|------|
| 连续计算 | 中断时间是否重置 |
| 累计计算 | 在一定期间内的累计天数 |
| 起始日期 | 认定起算点 |

### 3. 劳务型常设机构

**协定通常规定**：
- 缔约国一方居民公司在缔约国另一方提供劳务
- 在任何12个月中连续或累计超过183天
- 注意：主体是"公司"而非个人

### 4. 代理型常设机构

**独立代理 vs 非独立代理**：

| 类型 | 非独立代理（常设机构） | 独立代理 |
|------|----------------------|---------|
| 身份 | 固定惯常地代表企业签订合同 | 以独立身份从事活动 |
| 活动范围 | 全部或主要为企业工作 | 为多个客户工作 |
| 合同权利 | 经常签订合同 | 签订合同需特别授权 |
| 风险承担 | 企业承担风险 | 自己承担风险 |


## 典型场景分析

### 场景1：跨境承包工程

**情形**：中国A公司在越南承包一项建筑工程，合同金额5000万元，预计工期18个月。

**判定**：
| 要素 | 分析 |
|------|------|
| 工程类型 | 属于"建筑、装配或安装工程" |
| 时间判定 | 需判断是否连续超过协定规定天数（多数协定为12个月） |
| 结果 | 如超过天数，则构成越南常设机构 |

**注意**：
- 工期可能因客观原因延长
- 多个关联项目需合并计算
- 设备出口不等于工程承包

### 场景2：跨境提供劳务

**情形**：中国B公司派遣5名员工到新加坡客户现场提供技术服务，合同期6个月。

**判定**：
| 要素 | 分析 |
|------|------|
| 主体 | B公司（企业）派遣员工 |
| 劳务类型 | 技术服务 |
| 时间判定 | 6个月内累计天数是否超过183天 |
| 结果 | 如超过183天，构成新加坡常设机构 |

**注意**：
- 需统计所有提供同类劳务的人员天数
- 派遣人员为本公司员工
- 12个月滚动计算

### 场景3：境外设立办事处

**情形**：中国C公司在香港设立办事处，负责市场调研、客户联络，不签订合同。

**判定**：
| 要素 | 分析 |
|------|------|
| 场所类型 | 办公室（固定场所） |
| 活动性质 | 市场调研、客户联络 |
| 合同权利 | 不签订合同 |
| 结果 | 可能构成常设机构（固定场所型） |

**注意**：
- 办事处虽不签合同，但实际从事营业活动
- 准备性/辅助性活动除外
- 需结合香港与内地税收安排具体判断

### 场景4：跨境电子商务

**情形**：境外D公司通过网站向中国境内用户销售数字产品。

**判定**：
| 要素 | 分析 |
|------|------|
| 场所类型 | 无实体场所，通过网站运营 |
| 合同形式 | 通过网站自动签订 |
| 结果 | 通常不构成中国常设机构 |

**注意**：
- 数字经济带来的税收挑战（BEPS第1项）
- 中国可能通过国内法对数字服务征税
- 需关注OECD数字经济税收框架发展

## 境内法规衔接

### 与企业所得税法衔接

**《企业所得税法》第二条**：非居民企业，是指依照外国（地区）法律成立且实际管理机构不在中国境内，但在中国境内设立机构、场所的，或者在中国境内未设立机构、场所，但有来源于中国境内所得的企业。

**《企业所得税法实施条例》第五条**：条例第二条所称机构、场所，是指在中国境内从事生产经营活动的机构、场所，包括：
- 管理机构、营业机构、办事机构
- 工厂、农场、开采自然资源的场所
- 提供劳务的场所
- 承包建筑、安装、装配工程作业的场所
- 其他机构、场所

### 与增值税衔接

**《增值税暂行条例》及36号文**：
- 非居民企业在境内发生应税行为，需按规定缴纳增值税
- 工程承包、提供劳务等情形可能涉及增值税

### 与个人所得税衔接

**《个人所得税法》**：
- 非居民个人在中国境内提供劳务，需缴纳个人所得税
- 有住所/无住所个人的判定规则不同
