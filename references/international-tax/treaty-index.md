## 协定概览

### 中国税收协定网络

截至2024年，中国已与107个国家（地区）正式签署避免双重征税协定（含安排、协议），其中生效实施的有99个。

**【注】** 此数据为动态变化数据，建议通过国家税务总局官网"税收条约"栏目核实最新签署和生效数量。

### 协定来源优先级

| 层级 | 说明 |
|------|------|
| P0 | 协定条款原文（税收协定高于国内法） |
| P1 | 国家税务总局协定条款解释公告 |
| P2 | 四大税务解读、学术研究 |
| P3 | 其他来源 |

### 协定适用原则

1. **税收协定优先原则** — 协定待遇优先于国内法
2. **受益所有人原则** — 享受协定优惠的主体须为受益所有人
3. **导管公司排除** — 中间层公司通常不能享受协定待遇
4. **主要目的测试（PPT）** — BEPS第6项行动计划，防止协定滥用

## 协定核心条款

### 常设机构条款（PEA）

**固定场所型常设机构**
- 缔约国企业通过设在另一国的营业场所构成的常设机构
- 需具备"营业场所"和"固定性"两个要件

**工程型常设机构**
- 建筑工地、建筑、装配或安装工程，或与其有关的监督管理活动
- 【适用范围】连续超过6个月/12个月（视协定而定）
- 【与境内衔接】国内法下，非居民企业在中国境内承包工程作业的常设机构判定参照协定

**劳务型常设机构**
- 缔约国一方居民公司向另一方提供劳务
- 【适用范围】在任何12个月中连续或累计超过183天（多数协定）

### 营业利润条款

- 缔约国企业的营业利润仅在该企业为居民企业的缔约国征税
- 前提：该企业在另一国无常设机构
- 【与境内衔接】《企业所得税法》第三条，非居民企业在中国境内未设立机构、场所的所得，按10%税率源泉扣缴

### 股息、利息、特许权使用费条款

| 所得类型 | 协定限制税率 | 常见条件 |
|---------|-------------|---------|
| 股息 | **5%（持股≥25%）**；10%（其他） | 受益所有人持股比例（通常25%以上） |
| 利息 | 10%-15%或更优惠 | 受益所有人为金融机构等条件 |
| 特许权使用费 | 10%-15% | 受益所有人为相关企业或个人 |

### 财产收益条款

- 缔约国一方居民转让位于缔约国另一方的不动产取得的收益，可在另一国征税
- 转让公司股份取得的收益，原则上仅在居民国征税（特定情形除外）
- 【与境内衔接】《个人所得税法》第八条，财产转让所得以转让财产的收入额减除财产原值和合理费用后的余额为应纳税所得额

### 无协定地区处理策略

对于开曼群岛、英属维尔京群岛（BVI）等未与中国签署税收协定的国家/地区：

1. **股息/利息/特许权使用费**：来源地按国内法税率全额征税，无法享受协定优惠税率
2. **企业所得税**：非居民企业在中国境内未设立机构、场所的，其中国来源所得（股息、利息、特许权使用费等）按《企业所得税法》第三条第三款及实施条例第九十一条适用 **10% 预提所得税**；设立机构、场所且所得与该机构场所有实际联系的，按 25% 基本税率（或符合条件的小微/高新优惠税率）
3. **个人所得税**：按《个人所得税法》分类所得适用税率，无协定减免
4. **实际税负优化路径**：
   - 考虑通过有协定的中间控股地（如香港、新加坡）搭建架构，但需满足**受益所有人**条件和**主要目的测试（PPT）**，防范导管公司认定风险
   - 利用国内法下的区域性税收优惠（如海南自贸港、横琴等）
5. **信息透明度风险**：无协定地区通常也是低税/零税管辖区，CRS 信息交换覆盖开曼和 BVI（均为 CRS 参与辖区），架构透明度较高，需注意合规申报

## 协定与国内法衔接

### 协定待遇执行框架

1. **身份确认** — 确认申请人是否为协定对方国税收居民
2. **受益所有人判定** — 确认申请人是否为股息、利息、特许权使用费的受益所有人
3. **协定待遇申请** — 通过源泉扣缴或自行申报享受协定待遇
4. **后续管理** — 保持协定条件，持续满足受益所有人要求

### 国内法优先适用情形

| 情形 | 说明 |
|------|------|
| 导管公司 | 中间层公司不具有实质性经营活动 |
| 不符合受益所有人条件 | 申请人仅为税收利益而设立 |
| 协定滥用 | 不符合协定目的 |
| 主要目的测试 | 取得所得的主要目的之一是获取协定利益 |

### 国别报告与情报交换

- 中国已签署《金融账户涉税信息自动交换多边主管当局间协议》（CRS）
- 中国与美国签署双边政府间协定实现FATCA信息交换
- 【适用范围】中国税收居民在境外的金融账户信息将被交换
