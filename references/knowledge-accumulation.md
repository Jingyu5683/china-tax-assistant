# 知识积累机制

> 本文件定义 tax-query 技能的两套机制：  
> **（A）用户话题积累** — 记录用户高频查询，沉淀为个性化知识库  
> **（B）定期政策巡检报告** — 定期扫描 P0/P1 来源政策更新，生成可订阅报告

---

## A. 用户话题积累机制

### A1. 话题热词追踪规则

每次对话结束后，Agent 按以下规则在 `knowledge-log.md`（用户自定义路径）中累积记录：

#### 触发条件
以下任意一项触发记录：
- 用户完成一轮完整问答（至少包含一个确定性结论）
- 用户明确提到某税种、特定业务场景、或政策名称
- 用户使用问卷式交互决策树并完成到结论输出

#### 记录格式（追加到 knowledge-log.md）

```markdown
## [YYYY-MM-DD HH:MM] 查询记录

**主税种**: [增值税 / 企业所得税 / 个人所得税 / 印花税 / 其他]
**业务场景**: [进项抵扣 / 税收优惠 / 合同税务 / 跨境 / 其他]
**用户身份**: [企业财务 / 企业主 / 个体 / 税务师 / 学生 / 未知]
**核心问题摘要**: [一句话概括用户的核心问题]
**知识库命中**: [规则名/条款/Q&A编号，若无则填"联网检索"]
**用户加标记**: [ ] 是否加入个人知识库（用户主动确认后打√）
```

#### 热词统计
每满 5 条记录，Agent 自动汇总高频税种/场景统计，供「周报」制作使用：

```markdown
## 累计热词统计（截至 YYYY-MM-DD）
| 税种/专题 | 查询次数 | 典型问题 |
|---------|---------|---------|
| 增值税（进项抵扣） | 8次 | 旅客运输凭证抵扣、集体福利不得抵扣 |
| 企业所得税优惠 | 5次 | 小微企业适用条件、研发加计扣除申报 |
| ...    | ...    | ...   |
```

### A2. 个人知识库沉淀规则

当用户说以下任意一种话时，触发知识沉淀流程：

**触发语**：
- "记住这个"、"加到知识库"、"这个重要，保存一下"
- "以后遇到类似问题直接用这个结论"
- "更新你的知识"

**沉淀流程**：

**Step 1 — 确认沉淀内容**  
Agent 摘要当前对话的核心结论：
```
【知识沉淀确认】
准备记录以下内容到您的个人知识库：

核心结论：[结论一句话]
适用条件：[主体/时效/业务范围]
法规依据：[法规文号+条款]
来源时间：[YYYY-MM-DD]

请确认：(1) 确认沉淀 (2) 修改后沉淀 (3) 不沉淀
```

**Step 2 — 写入知识卡片**  
用户确认后，自动追加到 `personal-knowledge.md`（用户自定义路径）：

```markdown
## [知识卡片编号] [标题]

**更新日期**: YYYY-MM-DD  
**税种/专题**: [标签]  
**适用范围**: [主体/地域/时效]  
**核心结论**: [结论正文]  
**法规依据**: [文号+条款]  
**时效标注**: 知识库截至[日期]版本，[建议核实频率：半年/1年]  
**来源对话**: [话题摘要]  

---
```

**Step 3 — 定期有效性提醒**  
每次对话启动时，Agent 检查 `personal-knowledge.md`：
- 若有距今超 **6个月** 的知识卡片（建议核实频率≤6个月），主动提示：
  ```
  ⚠️ 您的个人知识库中有 [N] 条记录可能已超时效（最早：YYYY-MM-DD），建议本次对话中顺带核实：
  [列出超时条目标题]
  ```

## B. 定期政策巡检 & 报告机制

### B1. 巡检来源表

| 来源级别 | 巡检来源 | 巡检内容 |
|---------|---------|---------|
| **P0** | chinatax.gov.cn/新政速递 | 财政部令、国家税务总局公告、国税发、国税函 |
| **P0** | mof.gov.cn/政策/税收 | 财政部令、财税规范性文件 |
| **P0** | ird.gov.hk/chs/ | 中国香港税务局公告、新规 |
| **P1** | 德勤中国税务快讯 | 政策解读文章 |
| **P1** | 普华永道中国税务快讯 | 政策解读文章 |
| **P1** | 安永中国税务快讯 | 政策解读文章 |
| **P1** | 毕马威中国税务快讯 | 政策解读文章 |

---

### B2. 巡检频率与触发税种

按用户高频税种优先巡检，基础频率如下：

| 报告类型 | 巡检频率 | 内容范围 | 触发阈值 |
|---------|---------|---------|---------|
| **日报**（轻量）| 每日 | 仅 P0 新公告标题列表，判断是否涉及用户常问税种 | 手动订阅（不建议默认开启） |
| **周报**（标准）| 每周一 | P0 新公告全文摘要 + P1 解读要点 + 与用户高频税种匹配度 | 默认推荐 |
| **月报**（深度）| 每月1日 | P0/P1 月度政策汇总 + 知识库需更新条目清单 + 年度政策预告 | 默认推荐 |

---

### B3. 报告生成规则

#### 报告生成流程

```
Step 1. 巡检 P0 来源（国家税务总局新政速递 + 财政部）
        → 提取最近[N]天内新增的公告标题、文号、生效日期

Step 2. 与用户高频税种对比
        → 标记「相关」（与高频税种匹配）/ 「一般」（未匹配）

Step 3. 获取 P1 解读
        → 检索四大税务快讯中对以上相关公告的解读文章

Step 4. 与现有知识库对比
        → 判断是否影响现有条目（指出需更新的知识库文件/知识卡片编号）

Step 5. 生成报告（格式见 B4）
```

#### 报告标题格式

- 日报：`🔔 tax-query 税务日报 YYYY-MM-DD`
- 周报：`📋 tax-query 税务周报 YYYY-WXX（YYYY-MM-DD ~ YYYY-MM-DD）`
- 月报：`📊 tax-query 税务月报 YYYY年MM月`

---

## C. 订阅管理规则

### 启动/停止订阅

| 用户指令 | Agent 行为 |
|---------|-----------|
| "订阅税务周报" / "开启周报" | 确认开始自动周报，记录用户高频税种作为过滤条件 |
| "订阅税务月报" | 确认开始自动月报 |
| "日报" / "每日税务更新" | 确认开启日报（提示内容较轻量），记录偏好 |
| "取消订阅" / "停止周报" | 确认停止报告推送 |
| "调整报告频率" | 询问新频率并更新设置 |

### 个性化设置

用户可指定关注税种（默认用高频记录推断），例如：
- "只关注增值税和企业所得税的更新"
- "只看香港税制的变化"
- "我主要关注小微企业优惠政策"

---

## D. 知识库更新确认流程

当 Agent 建议更新知识库时，用户的每次确认都遵循以下步骤：

```
Step 1. Agent 展示「新政要点 vs 现有知识库条目」对比表

Step 2. 用户选择：
  (a) 全部更新到知识库
  (b) 选择更新 [条目编号]
  (c) 暂不更新

Step 3. 若选 (a)/(b)，Agent 执行：
  - 更新对应 references/ 文件
  - 在知识卡片末尾追加「[YYYY-MM-DD] 依据[文号]更新」
  - 在 CHANGELOG.md 中记录本次自动更新

Step 4. Agent 提示：「本次更新已记录到知识库，共更新 [N] 条。建议您复核以下关键修改：[列表]」
```

## E. 使用场景示例

### 场景一：用户主动订阅

> 用户：「帮我订阅税务周报，重点关注增值税和企业所得税」

Agent 响应：
```
已为您开启税务周报订阅：
- 巡检频率：每周一自动生成
- 重点税种：增值税 + 企业所得税
- 报告将包含：本周 P0 新公告摘要 + P1 解读 + 知识库维护建议

下次报告将于 [下周一日期] 推送。您可随时说「停止周报」取消订阅。
```

### 场景二：月报中发现政策更新

> 月报显示：「2026年X号公告调整了小规模纳税人免税额标准」

用户回复「更新条目1」，Agent：
- 自动修改 `references/vat/regulations.md` 对应条目
- 追加更新记录到 CHANGELOG.md
- 若有对应知识卡片，同步更新时效标注

### 场景三：高频话题自动建议

Agent 累积 10 次查询后，主动提示：
```
📌 过去 30 天您最常查询「研发加计扣除」（7次），建议：
1. 是否需要我为您整理一份「研发加计扣除实操手册」？
2. 是否要将现有问答记录沉淀为个人知识卡片？
3. 是否订阅「企业所得税优惠」专项更新推送？
```
