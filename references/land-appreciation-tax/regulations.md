## 基础法规

### 核心法规

**中华人民共和国土地增值税暂行条例**
- 文号：国务院令第138号（1993年发布，历次修订）
- 核心条款：纳税人、征税范围、税率、扣除项目

**中华人民共和国土地增值税暂行条例实施细则**
- 文号：财法字〔1995〕6号
- 核心条款：扣除项目金额计算、减免税等

## 征税范围与税率

### 征税范围

| 应税行为 | 说明 |
|---------|------|
| 转让国有土地使用权 | 转让地上的建筑物及其附着物 |
| 地上建筑物及其附着物转让 | 包括出售、交换、赠与 |
| 存量房地产转让 | 买卖存量房 |

**【适用范围】个人住房暂免征收土地增值税**

| 情形 | 土地增值税处理 | 政策依据 |
|------|--------------|---------|
| 个人销售住房 | **暂免征收土地增值税** | 财税〔2008〕137号 |
| 单位销售住房 | 正常征税 | 按超率累进税率计算 |

**【注】"满5年免征，未满5年按差额征税"为误解，正确的规则是：个人销售住房暂免征收土地增值税，现行有效。**

### 税率（超率累进）

| 级距 | 增值额/扣除项目金额 | 税率 | 速算扣除系数 |
|------|-------------------|------|-------------|
| 1 | 未超过50%的部分 | 30% | 0 |
| 2 | 50%-100%的部分 | 40% | 5% |
| 3 | 100%-200%的部分 | 50% | 15% |
| 4 | 超过200%的部分 | 60% | 35% |

**计算公式**：
```
土地增值税 = 增值额 × 税率 - 扣除项目金额 × 速算扣除系数
增值额 = 转让收入 - 扣除项目金额
```

## 扣除项目

### 新建房地产扣除项目

| 扣除项目 | 内容 |
|---------|------|
| 取得土地使用权所支付的金额 | 地价款 + 相关税费 |
| 开发土地的成本、费用 | 土地征用费、拆迁补偿费等 |
| 新建房及配套设施的成本、费用 | 建筑安装费、基础设施费等 |
| 旧房及建筑物的评估价格 | 评估重置成本 × 成新率 |
| 与转让房地产有关的税金 | 城建税、教育费附加等 |

**【加计扣除】** 房地产开发企业可按取得土地使用权所支付的金额和开发土地、新建房及配套设施成本两项金额之和，加计扣除20%：
```
扣除项目金额合计 = (地价款+开发成本) × 120%
```

### 存量房地产扣除项目

| 扣除项目 | 内容 |
|---------|------|
| 房屋及建筑物的评估价格 | 重置成本价 × 成新度折扣率 |
| 取得土地使用权所支付的地价款 | 按国家统一规定缴纳的有关费用 |
| 按国家统一规定缴纳的有关费用 | 登记过户手续费等 |
| 与转让房地产有关的税金 | 城建税、教育费附加、印花税 |

## 清算管理

### 清算条件

**必须清算**（达到以下条件之一）：
1. 房地产开发项目全部竣工、完成销售
2. 整体转让未竣工决算房地产开发项目
3. 直接转让土地使用权

**主管税务机关可要求清算**：
1. 已竣工验收的房地产开发项目
2. 已转让的房地产建筑面积占整个项目可售建筑面积的比例在85%以上
3. 取得销售（预售）许可证满3年仍未销售完毕

### 清算流程

```
项目完成销售
    │
    ▼
满足清算条件
    │
    ├── 必须清算 → 企业向税务机关申请清算
    │
    └── 可要求清算 → 税务机关书面通知清算
    │
    ▼
税务机关审核
    │
    ▼
多退少补
```

## 优惠政策

### 普通标准住宅优惠

| 条件 | 优惠内容 |
|------|---------|
| 增值额未超过扣除项目金额20% | 免征土地增值税 |

**【适用范围】** 普通标准住宅须同时满足：住宅小区建筑容积率在1.0以上、单套建筑面积在120平方米（或144平方米）以下、实际成交价格低于同级别土地上住房平均交易价格1.2倍（各省市标准可能不同）

### 其他优惠

| 情形 | 政策内容 | 文件依据 |
|------|---------|---------|
| 个人销售住房 | **暂免征收土地增值税** | 财税〔2008〕137号 |
| 合作建房 | 一方出地一方出资建成后按比例分房自用 | 暂免征 |
| 兼并重组 | 企业兼并重组转让房地产 | 暂免征 |
| 国家建设依法征用 | 因城市实施规划、国家建设需要 | 免征 |

### 延续性政策

| 政策内容 | 有效期 |
|---------|--------|
| 企业和改制重组土地增值税政策 | 至2027年12月31日（财税〔2023〕51号） |

## 与境内其他税种衔接

| 关系 | 说明 |
|------|------|
| 与增值税 | 转让不动产涉及增值税，增值税不含在土地增值税扣除项目中 |
| 与所得税 | 土地增值税清算后的净损益影响企业所得税 |
| 与契税 | 购房时已缴契税可在土地增值税扣除项目中扣除 |
| 与印花税 | 转让合同需缴纳印花税，可计入扣除项目 |

## 时效性说明

**【注】** 土地增值税条例自1993年发布以来基本框架未变，近年主要是针对企业重组、改制等出台阶段性优惠政策。建议核实最新延续政策（可通过国家税务总局官网检索）。
