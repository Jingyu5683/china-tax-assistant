## 概览

本技能的知识库遵循严格的来源优先级体系，确保税务信息的权威性与时效性。国内法规以官方口径为准，国际税收参考权威机构发布内容。

## 国内来源

### P0：官方法规（首选）

**国家税务总局**
- 官网：https://www.chinatax.gov.cn/
- 法规政策司栏目发布最新税收法规
- 纳税服务司栏目发布办税指南
- 实时性最强，具有法律效力

**财政部**
- 官网：http://www.mof.gov.cn/
- 发布税收条例、实施细则、优惠政策等
- 国务院关税税则委员会（发布关税调整）

**国务院关税税则委员会**
- 官网：http://gts.ccchina.org.cn/
- 发布进出口税则、关税调整

**各省市税务局**
- 各省税务局官网（如国家税务总局北京市税务局）
- 发布地方性税收征管规定、办税流程
- 【适用范围】注意区分全国性政策与地方性规定

**海关总署**
- 官网：http://www.customs.gov.cn/
- 发布关税征收、进出口监管规定
- 海关归类、原产地规则

**消费税/印花税来源**：
- 消费税由财政部、国家税务总局主管，海关代征进口环节
- 印花税由税务机关主管，海关监管凭证进出口环节

## 使用原则

### 来源选择优先级
1. 涉及中国税务法规 → 优先 P0 官方来源
2. 涉及政策解读/实操 → 参考 P1 权威解读
3. 涉及学术探讨 → 引用 P2/P3 来源并标注
4. 跨境场景 → P0（官方）+ P1（国际机构）组合使用

### 引用标注要求
- 法规引用：标注文号、发布机关、发布日期
- 政策解读：标注来源机构、发布时间
- 国际税收：标注来源国家/机构、语言版本

### 时效性管理
- P0 来源实时性最强，优先使用
- P1/P2 来源可能存在滞后，需交叉验证
- 引用时标注检索日期
