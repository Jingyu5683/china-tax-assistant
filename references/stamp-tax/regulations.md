## 基础法规

### 印花税法

**中华人民共和国印花税法**
- 文号：主席令第89号
- 生效日期：2022年7月1日
- 核心条款：纳税人、税目税率、计税依据、征收管理

**印花税法实施条例**
- 文号：国务院令第746号
- 生效日期：2022年7月1日
- 核心条款：税目税率表、纳税方法、减免税优惠

### 主要变化（2022年7月1日起）

| 变化点 | 原规定 | 新规定 |
|--------|--------|--------|
| 税目结构 | 13个税目 | 4大门类（合同、产权转移、营业账簿、证券交易）+若干子目，结构更清晰 |
| 税率 | 多数下调 | 整体降低，最高税率从1‰降至0.5‰ |
| 申报方式 | 按月或按季 | 简化为按季或按次 |
| 核定征收 | 取消 | 对部分应税凭证可采用核定方式 |

| 方式 | 说明 | 适用纳税人 |
|------|------|---------|

### 申报渠道

- 电子税务局（主要渠道）
- 办税服务厅（补充渠道）

### 印花税凭证管理

| 要点 | 说明 |
|------|------|
| 贴花位置 | 凭证的书立显眼处 |
| 汇总缴纳 | 同一类凭证需汇总后贴花，不可分贴 |
| 多税率处理 | 按最高税率贴花 |
| 资金账簿 | 实收资本和资本公积合计金额的0.25‰贴花，以后年度增加额部分贴花 |

### 常见问题

**Q：股权转让合同是否需要缴纳印花税？**
A：需要。按"产权转移书据"缴纳印花税，税率为0.5‰。若为上市公司股票转让，则按证券交易缴纳1‰印花税。

**Q：企业之间签订的借款合同是否需要缴纳印花税？**
A：仅限于金融机构与借款人签订的借款合同需要缴纳。企业之间的借款合同（包括民间借贷）不征印花税。

**Q：电子合同是否需要缴纳印花税？**
A：需要。印花税对应税凭证的形式无特殊要求，无论纸质还是电子形式，只要属于印花税征税范围，均需缴纳。
