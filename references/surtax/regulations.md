## 基础法规

### 城市维护建设税法

**中华人民共和国城市维护建设税法**
- 文号：主席令第51号
- 生效日期：2021年9月1日
- 核心条款：纳税人、计税依据、税率、税收优惠

### 教育费附加/地方教育附加

| 费种 | 法规依据 | 说明 |
|------|---------|------|
| 教育费附加 | 《征收教育费附加的暂行规定》（国务院令第60号） | 由税务机关统一征收 |
| 地方教育附加 | 各省市地方性法规/规章 | 各地征收标准不同 |

## 纳税人

### 纳税义务人

缴纳增值税、消费税的单位和个人，包括：
- 企业、事业单位
- 机关、团体、部队
- 个体工商户
- 其他个人

**【注】** 城市维护建设税和教育费附加以实际缴纳的增值税、消费税为计税依据，随同增值税、消费税一并征收。

## 计税依据

### 计税依据构成

| 项目 | 是否计入计税依据 |
|------|----------------|
| 实际缴纳的增值税 | 是 |
| 实际缴纳的消费税 | 是 |
| 出口货物免抵增值税额 | 是 |
| 被查补的增值税、消费税 | 是 |
| 滞纳金、罚款 | 否 |

**【重要补充】留抵退税与附加税费计税依据**：
- 对实行增值税期末留抵退税的纳税人，允许其从城市维护建设税、教育费附加和地方教育附加的计税依据中**扣除退还的增值税税额**
- 文件依据：财税〔2018〕80号
- 【衔接说明】即留抵退税不影响当期城建税及附加的计算基数，减少企业税负

**教育费附加/地方教育附加计税依据相同**。

## 税率与计算

### 城市维护建设税税率

| 地区 | 税率 |
|------|------|
| 市区 | 7% |
| 县城、镇 | 5% |
| 不在市区、县城或镇的 | 1% |
| 经批准享受地区同等待遇的区域 | 按所在地税率 |

**【适用范围】** 税率适用以纳税人所在地为准。代扣代缴、代收代缴的，以代扣代缴、代收代缴单位所在地为准。

### 计算公式

**城市维护建设税**：
```
应纳税额 = （实缴增值税 + 实缴消费税）× 税率
```

**教育费附加**：
```
应纳税额 = （实缴增值税 + 实缴消费税）× 3%
```

**地方教育附加**：
```
应纳税额 = （实缴增值税 + 实缴消费税）× 2%
```

### 综合示例

| 项目 | 金额/税率 |
|------|----------|
| 实缴增值税 | 100万元（市区） |
| 城建税 | 100 × 7% = 7万元 |
| 教育费附加 | 100 × 3% = 3万元 |
| 地方教育附加 | 100 × 2% = 2万元 |
| 合计附加 | 12万元 |

## 优惠政策

### 法定减免

| 情形 | 优惠内容 | 文件依据 |
|------|---------|---------|
| 进口货物 | 不征 | 城建税法 |
| 出口货物 | 不征 | 城建税法 |
| 增值税/消费税先征后返 | 不征 | 城建税法 |

### 阶段性优惠

| 优惠内容 | 优惠幅度 | 有效期 | 文件依据 |
|---------|---------|--------|---------|
| 增值税小规模纳税人 | 城建税减半征收 | 至2027年12月31日 | 财税〔2023〕37号 |
| 增值税小规模纳税人 | 教育费附加、地方教育附加减半 | 至2027年12月31日 | 财税〔2023〕37号 |
| 小型微利企业 | 城建税等减半征收 | 至2027年12月31日 | 财税〔2023〕12号 |

### 特殊情况

| 情形 | 处理方式 |
|------|---------|
| 当期未实际缴纳增值税/消费税 | 不征附加税费 |
| 留抵退税 | 退还的增值税不影响附加计算 |
| 即征即退/先征后退 | 附加以实际入库增值税计算 |

## 申报与缴纳

### 申报缴纳周期

与增值税、消费税申报周期一致：
- 一般纳税人：月度申报
- 小规模纳税人：季度申报（也可月度申报）

### 申报流程

```
计算应纳增值税、消费税
    │
    ▼
计算城建税及附加
    │
    ▼
一并申报缴纳
    │
    ▼
取得完税凭证
```

### 与主税关系

| 特点 | 说明 |
|------|------|
| 附加性质 | 随主税附征，不单独申报（部分地区已合并申报） |
| 税前列支 | 准予企业所得税税前扣除 |
| 发票关系 | 不通过发票体现，是申报缴纳的款项 |

## 与其他税种衔接

| 关系 | 说明 |
|------|------|
| 与增值税 | 以实缴增值税为计税依据 |
| 与消费税 | 以实缴消费税为计税依据 |
| 与所得税 | 附加税费准予税前扣除 |
| 与海关关税 | 进口货物不征城建税及附加 |

## 时效性说明

**【注】** 城市维护建设税法于2021年9月1日施行，替代原《城市维护建设税暂行条例》。近年主要是小规模纳税人减征政策频繁延续，建议核实最新优惠政策。
