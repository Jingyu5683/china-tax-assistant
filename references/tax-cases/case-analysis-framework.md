> 来源：国家税务总局官网税案通报
> 更新日期：2026-05-30

## 一、案件分析框架

### 1.1 核心要素提炼模板

```
一、案件核心要素提炼
1. 案件类型
   - 稽查领域：[虚开发票/偷税/骗取优惠/逃避税等]
   - 行政/刑事：[行政违法/刑事犯罪]
   - 案件特征：[主体造假/业务造假/申报造假等]

2. 违规手段
   主体造假：[具体手段]
   业务造假：[具体手段]
   申报造假：[具体手段]

3. 涉及税种
   明确涉案：[税种1、税种2]
   关联涉案：[附加税等]

4. 适用法规依据
   实体规则依据：[具体法规条款]
   程序规则依据：[具体法规条款]
   处罚规则依据：[具体法规条款]
```

### 1.2 案例分析维度

| 分析维度 | 分析要点 |
|---------|---------|
| **违法行为定性** | 是否符合法定构成要件（主观故意、客观行为、损害结果） |
| **政策适用规则** | 是否符合优惠政策适用前提条件 |
| **监管技术手段** | 税务部门如何发现线索（大数据分析、举报、实地核查等） |
| **证据链构建** | 如何形成完整证据链（资金流、发票流、货物流） |
| **处罚幅度判定** | 罚款比例选择依据（0.5倍-5倍） |
| **合规启示** | 纳税人应吸取的教训和防范建议 |

### 1.3 常见违规手段分类

| 类型 | 典型手段 | 涉及税种 |
|------|---------|---------|
| **收入隐匿** | 个人账户收款、公账私账组合、高卖低开 | 增值税、企业所得税、个人所得税 |
| **主体拆分** | 空壳企业、借用他人身份注册、分拆收入 | 增值税、个人所得税 |
| **虚开发票** | 虚构交易、虚增成本、农产品收购发票虚开 | 增值税、企业所得税 |
| **政策滥用** | 骗取小规模减免、虚假申报、违规享受优惠 | 增值税、个人所得税 |
| **成本造假** | 不合规凭证列支、虚列成本、虚构业务 | 企业所得税、增值税 |
| **视同销售漏报** | 对外捐赠未视同销售、关联定价转移 | 增值税、企业所得税 |

## 二、典型案例库

### 案例1：网络主播余洋虚假申报偷税案

**来源**：国家税务总局泸州市税务局稽查局
**时间**：2024年11月
**案号**：泸州市税稽罚〔2024〕XX号

#### 一、案件核心要素提炼

**1. 案件类型**
- 税务稽查领域虚假申报偷税案件
- 行政违法案件
- "假主体、假业务、假申报"类典型涉税违法案件

**2. 违规手段**

| 类型 | 具体操作 |
|------|---------|
| **主体造假** | 通过本人及亲属身份注册6个个体工商户，在平台开展直播销售，实际控制人均为余洋 |
| **业务造假** | 货源来自广州、武汉两地，消费者线上下单后由厂商直发，私对私转账购货，购销两端体外循环 |
| **收入隐匿** | 仅申报开具发票的390余万元销售收入，隐匿未开票收入约3.4亿元 |

**3. 涉及税种**
- 明确涉案：个人所得税、增值税
- 关联涉案：城市维护建设税、教育费附加、地方教育附加

**4. 适用法规依据**
- 实体规则：《中华人民共和国个人所得税法》《个体工商户个人所得税计税办法》（国家税务总局令第35号）
- 处罚规则：《中华人民共和国税收征收管理法》第六十三条第一款

#### 二、案例分析

**（一）违法行为定性**

| 构成要件 | 本案情况 |
|---------|---------|
| 主观故意 | 利用多个主体拆分收入、隐瞒真实经营规模，明知需申报而故意隐匿 |
| 客观行为 | 虚假纳税申报，将3.4亿元收入不申报纳税 |
| 损害结果 | 少缴个人所得税、增值税等805万元 |

**（二）主体拆分避税风险**

根据《个体工商户个人所得税计税办法》第二条规定，个体工商户从两处以上取得经营所得，需在年度汇总纳税申报时合并计算。本案中余洋通过6个主体拆分收入，试图规避汇总申报义务，但实质上仍构成偷税。

**（三）平台经济税收监管趋势**

| 监管技术 | 本案应用 |
|---------|---------|
| 税收大数据比对 | 平台推广费620万 vs 申报收入160万，差异达3.8倍 |
| 资金流分析 | 19个银行账户分散销售收入 |
| 第三方数据共享 | 平台交易数据与申报数据交叉验证 |

**（四）合规启示**

1. 平台经济从业者应据实申报全部收入，包括未开票收入
2. 从多处取得经营所得应在年度终了后办理汇总申报
3. 不得通过拆分主体方式规避纳税义务
4. 购货时应主动索取发票，避免上游发票异常

### 案例2：网络主播王子柏偷税案

**来源**：国家税务总局上海市税务局第三稽查局
**时间**：2024年12月
**案号**：沪税稽罚〔2024〕XX号

#### 一、案件核心要素提炼

**1. 案件类型**
- 税务稽查领域偷税案件
- 行政违法案件
- 高收入人群隐匿收入类案件

**2. 违规手段**

| 类型 | 具体操作 |
|------|---------|
| **收入隐匿** | 通过近亲属个人账户收款，隐匿直播带货佣金收入 |
| **申报造假** | 未依法办理纳税申报，少缴应纳税款 |

**3. 涉及税种**
- 明确涉案：个人所得税、增值税
- 关联涉案：城市维护建设税、教育费附加、地方教育附加

**4. 处罚结果**
- 追缴税费款：749万元
- 加收滞纳金
- 处罚款：约581万元
- 合计：1330万元

#### 二、案例分析

**（一）高收入人群税收风险点**

| 风险类型 | 具体表现 |
|---------|---------|
| 收入多元化 | 带货佣金、坑位费、粉丝打赏等多类收入 |
| 收款渠道分散 | 个人账户、近亲属账户、第三方平台 |
| 税收居民身份 | 跨境直播涉及境内外所得申报 |

**（二）粉丝量与隐匿收入的关联**

| 粉丝量 | 隐匿收入规模 |
|-------|-------------|
| 292万 | 749万元 |
| 500万（程虎案） | 121万元 |

注：粉丝量越大不代表隐匿金额越高，需结合具体业务模式和变现能力判断。

**（三）处罚幅度分析**

| 违法情节 | 处罚比例 |
|---------|---------|
| 隐匿收入 | 749万元 |
| 处罚幅度 | 约77%（581/749） |
| 最终合计 | 1330万元 |

注：在0.5-5倍罚款区间内，实际处罚比例取决于配合调查态度、违法持续时间等因素。

### 案例3：网络主播程虎偷税案

**来源**：国家税务总局厦门市税务局第一稽查局
**时间**：2024年12月
**案号**：厦税稽罚〔2024〕XX号

#### 一、案件核心要素提炼

**1. 案件类型**
- 税务稽查领域偷税案件
- 行政违法案件
- 复合主体身份隐匿收入

**2. 违规手段**

| 类型 | 具体操作 |
|------|---------|
| **主体复合** | 个人身份取得佣金收入 + 个体工商户取得经营收入 |
| **收入隐匿** | 通过个人账户收款，未依法申报 |
| **申报造假** | 未据实办理税务登记和申报 |

**3. 涉及税种**
- 明确涉案：个人所得税（经营所得+劳务报酬所得）、增值税
- 关联涉案：城市维护建设税、教育费附加

**4. 处罚结果**
- 追缴税费款：121万元
- 加收滞纳金
- 处罚款：约78万元
- 合计：199万元

#### 二、案例分析

**（一）复合主体身份税务处理**

| 收入类型 | 适用税目 | 计税方式 |
|---------|---------|---------|
| 个人直播代销佣金 | 劳务报酬所得 | 按次或按月计税，合并年度汇算 |
| 个体工商户经营收入 | 经营所得 | 按年计税，5%-35%超额累进 |

**（二）与王子柏案对比**

| 对比维度 | 王子柏案 | 程虎案 |
|---------|---------|--------|
| 粉丝量 | 292万 | 500万 |
| 隐匿金额 | 749万 | 121万 |
| 处罚合计 | 1330万 | 199万 |
| 主体形式 | 个人+亲属账户 | 个人+个体工商户 |

### 案例4：兴顺煤矿"公账私账拆分戏法"偷税案

**来源**：国家税务总局黔西南州税务局第二稽查局
**时间**：2025年11月（查处），违法行为2018-2022年
**案号**：黔西南税稽罚〔2024〕XX号

#### 一、案件核心要素提炼

**1. 案件类型**
- 税务稽查领域偷税案件
- 行政违法案件
- 煤炭行业典型隐匿收入案件

**2. 违规手段**

| 类型 | 具体操作 |
|------|---------|
| **公账私账组合** | 部分销售款60%走公账开票申报，40%走个人账户隐匿 |
| **高卖低开** | 对下游企业高售价，但仅就公账部分开具发票 |
| **捐赠未视同销售** | 对外捐赠煤炭未视同销售处理 |
| **不合规凭证列支** | 使用未合法有效的凭证列支成本 |

**3. 涉及税种**
- 明确涉案：增值税、企业所得税、资源税
- 关联涉案：城市维护建设税、教育费附加

**4. 违法行为金额**

| 违法行为 | 少缴金额 |
|---------|---------|
| 隐匿收入、虚假申报 | 597.76万元 |
| 捐赠未视同销售、不合规凭证 | 324.52万元 |
| **合计** | **922.28万元** |

#### 二、案例分析

**（一）资金流穿透技术**

| 证据类型 | 本案应用 |
|---------|---------|
| 银行流水分析 | 李文云三个私人账户大量"煤款""货款"转账 |
| 资金链路还原 | 下游公账付款前后，法人同步转账至李文云私账 |
| 第三方印证 | 下游企业主动供述40%款项走私账 |

**（二）货物流与申报数据比对**

| 数据来源 | 2018-2022年数据 |
|---------|----------------|
| 煤炭开采数量 | 与开采量比对，销售比开采少16万吨 |
| 行业合理损耗 | 远低于16万吨差额 |
| 异常指向 | 存在隐匿销售收入嫌疑 |

**（三）"高卖低开"法律风险**

"高卖低开"实质是将部分销售款通过非公账渠道收取，对应部分不开发票、不申报纳税，构成隐匿收入行为。同时可能涉及虚开增值税专用发票风险。

**（四）合规启示**

1. 煤炭等大宗商品交易应确保资金流、发票流、货物流"三流一致"
2. 对外捐赠应按规定视同销售处理
3. 成本列支必须取得合法有效的凭证
4. 个人账户收取经营款项存在重大税务风险

### 案例5：盛特公司虚开农产品收购发票案

**来源**：国家税务总局黔西南州税务局第一稽查局
**时间**：2025年11月（查处），违法行为2021-2022年
**案号**：黔西南税稽罚〔2024〕XX号

#### 一、案件核心要素提炼

**1. 案件类型**
- 税务稽查领域虚开发票案件
- 行政违法 + 刑事犯罪（已移送）
- 中介身份便利虚开

**2. 违规手段**

| 类型 | 具体操作 |
|------|---------|
| **虚开进项** | 利用掌握的农户信息，虚开农产品收购发票120份，金额413.65万元 |
| **非法取得** | 虚构"以木材抵设备款"交易，非法取得设备增值税专用发票17份，金额120万元 |
| **虚开销项** | 虚构销售业务，对外虚开增值税专用发票50份，金额483万元 |

**3. 涉及税种**
- 明确涉案：增值税（虚开抵扣）
- 关联涉案：企业所得税（虚列成本）

**4. 处罚结果**
- 对盛特公司：定性虚开，罚款40万元
- 已证实虚开通知单：发送下游受票企业所在税务机关
- 刑事判决：韦艳有期徒刑两年零六个月，缓刑三年，罚金6万元

#### 二、案例分析

**（一）中介身份作案特点**

| 中介便利 | 本案应用 |
|---------|---------|
| 代理记账客户信息 | 掌握近20家木材加工企业开票信息 |
| 农户林木采伐信息 | 利用采伐许可证和身份信息虚开 |
| 上下游企业资源 | 虚构交易链条 |

**（二）虚开发票"三步走"模式**

```
第一步：虚构进项
    └─ 利用农户身份虚开农产品收购发票
    └─ 虚构设备交易取得进项发票

第二步：税负平衡
    └─ 通过进销比对刻意控制税负持平
    └─ 避免引起税务机关注意

第三步：对外虚开
    └─ 虚构销售业务对外开具销项发票
    └─ 收取开票费获利
```

**（三）空壳企业识别特征**

| 识别维度 | 本案异常 |
|---------|---------|
| 生产经营地址 | 实际由其他企业租用 |
| 供水供电记录 | 无任何用水用电开户信息 |
| 税负波动 | 进项销项长期精准持平 |
| 人员设备 | 无任何生产经营证明材料 |

**（四）刑事风险警示**

| 虚开税额 | 刑事风险 |
|---------|---------|
| 虚开增值税专用发票罪 | 税额较大或情节严重 |
| 移送标准 | 涉嫌构成犯罪，依法移送公安机关 |

**（五）合规启示**

1. 农产品收购发票应确保与真实收购业务一致
2. 不得利用中介身份便利虚构交易
3. 企业应核实上游供应商和下游客户的真实业务背景
4. 异常税负波动是重要风险信号，应及时自查

### 案例6：荣峰再生资源回收站骗享小规模减免偷税案

**来源**：国家税务总局池州市税务局稽查局
**时间**：2024年
**案号**：池州市税稽罚〔2024〕XX号

#### 一、案件核心要素提炼

**1. 案件类型**
- 税务稽查领域骗取税费减免偷税案件
- 行政违法案件
- "假主体、假业务、假申报"类典型涉税违法案件

**2. 违规手段**

| 类型 | 具体操作 |
|------|---------|
| **主体造假** | 借用85名他人身份证件，设立85户空壳个体工商户 |
| **业务造假** | 将实际经营收入拆分至85户空壳主体 |
| **申报造假** | 虚构各主体符合小规模减免条件，虚假纳税申报 |

**3. 涉及税种**
- 明确涉案：增值税、个人所得税
- 关联涉案：城市维护建设税、教育费附加、地方教育附加

**4. 处罚结果**
- 少缴税费：215.84万元
- 合计追缴（含滞纳金、罚款）：339.74万元

#### 二、案例分析

**（一）小规模纳税人减免适用规则**

| 条件 | 要求 |
|------|------|
| 主体资格 | 真实开展经营的独立市场主体 |
| 销售额标准 | 年应税销售额未超过500万元 |
| 申报真实 | 据实申报销售额和减免适用条件 |

本案中85户主体均为无实际经营的空壳企业，不符合减免适用前提。

**（二）拆分主体避税的法律后果**

| 行为 | 法律后果 |
|------|---------|
| 借用他人身份设立主体 | 主体不真实，申报无效 |
| 拆分收入规避标准 | 不影响实质纳税义务认定 |
| 虚假申报享受减免 | 构成偷税，补税+滞纳金+罚款 |

**（三）处罚幅度分析**

| 项目 | 金额 |
|------|------|
| 少缴税费 | 215.84万元 |
| 合计追缴 | 339.74万元 |
| 罚款比例 | 约57% |

## 三、案件高发领域与风险提示

### 3.1 高发领域分布

| 领域 | 典型手段 | 风险等级 |
|------|---------|---------|
| 平台经济（直播电商） | 隐匿收入、拆分主体 | 高 |
| 资源型企业（煤炭） | 公账私账组合、高卖低开 | 高 |
| 中介服务机构 | 虚开发票、虚构业务 | 高 |
| 再生资源回收 | 空壳主体骗享减免 | 中高 |
| 高收入人群 | 隐匿境外收入、多渠道收款 | 中 |

### 3.2 常见风险点清单

## 四、合规建议

### 4.1 基础合规要求

1. **据实申报**：确保全部收入依法申报，包括未开票收入
2. **凭证合规**：确保取得和开具的发票与真实业务一致
3. **资金规范**：经营款项通过企业对公账户收付
4. **档案留存**：妥善保存合同、付款凭证、业务资料备查

### 4.2 重点领域合规要点

| 领域 | 合规要点 |
|------|---------|
| 平台经济 | 如实申报平台全部收入；多主体经营需汇总申报 |
| 跨境业务 | 了解跨境所得申报要求；关注税收协定待遇 |
| 关联交易 | 遵循独立交易原则；准备同期资料 |
| 优惠政策 | 确保符合适用条件；留存备查资料 |

### 4.3 风险自查清单

- [ ] 是否存在通过个人账户收取经营款项的情况
- [ ] 是否存在隐匿未开票收入的情况
- [ ] 是否存在拆分主体规避纳税义务的情况
- [ ] 取得的发票是否与真实业务相符
- [ ] 成本费用是否有合法有效的凭证支持
- [ ] 是否按规定办理了全部税种的纳税申报
- [ ] 享受的税收优惠是否符合适用条件
