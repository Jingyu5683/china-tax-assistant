## 适用法规分类索引

### 实体法规

| 法规 | 适用情形 |
|------|---------|
| 《个人所得税法》 | 经营所得、劳务报酬所得计税 |
| 《中华人民共和国增值税法》（2026年1月1日起施行） | 视同销售、减免适用 |
| 《个体工商户个税计税办法》 | 多处经营所得汇总申报 |

### 程序法规

| 法规 | 适用情形 |
|------|---------|
| 《税收征收管理法》第63条 | 偷税认定与处罚（0.5-5倍罚款） |
| 《发票管理办法》第21条 | 虚开发票认定 |
| 《发票管理办法》第35条 | 虚开处罚标准 |

## 案件分析框架速查

| 分析维度 | 核心问题 |
|---------|---------|
| 违法定性 | 主观故意+客观行为+损害结果 |
| 政策适用 | 是否符合减免/优惠前提条件 |
| 监管技术 | 如何发现线索（大数据/举报/实地） |
| 证据链 | 资金流+发票流+货物流 |
| 处罚幅度 | 0.5-5倍罚款的选择依据 |
