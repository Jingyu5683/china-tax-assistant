## 基础法规

### 核心法规

**中华人民共和国税收征收管理法**
- 文号：主席令第49号（2015年第三次修订）
- 生效日期：2015年4月24日
- 核心条款：征纳双方权利义务、征收管理程序

**中华人民共和国税收征收管理法实施细则**
- 文号：国务院令第362号（2016年修订）
- 生效日期：2016年2月6日

### 数字化相关法规

**电子发票**
- 《会计档案管理办法》（财政部令第79号）
- 国家税务总局公告2020年第22号（区块链电子发票）
- 《关于全面数字化电子发票开具有关事项的公告》

## 税务登记

### 税务登记类型

| 登记类型 | 适用范围 | 时限要求 |
|---------|---------|---------|
| 设立登记 | 首次办理税务登记 | 取得营业执照之日起30日内 |
| 变更登记 | 登记信息发生变化 | 发生变化之日起30日内 |
| 注销登记 | 终止纳税义务 | 终止之日起15日内或清算结束后45日内 |
| 跨区域涉税事项报告 | 外出经营 | 外出前或达到前办理 |

### "多证合一"改革

自2015年起，税务登记已纳入"多证合一"改革，企业通过工商登记即完成税务登记信息采集，无需单独办理税务登记。

### 实名办税

| 要求 | 说明 |
|------|------|
| 采集范围 | 法定代表人、财务负责人、办税人员等 |
| 采集内容 | 身份证件、人像信息、联系方式 |
| 生效要求 | 实名采集后方可办理涉税事项 |

## 申报与缴纳

### 申报方式

| 申报方式 | 说明 |
|---------|------|
| 网上申报 | 通过电子税务局在线申报（主流方式） |
| 邮寄申报 | 通过邮寄方式提交申报表 |
| 上门申报 | 到办税服务厅现场申报 |
| 简易申报 | 适用于定期定额征收的个体户 |

### 申报周期

| 纳税人类型 | 申报周期 | 税种 |
|-----------|---------|------|
| 一般纳税人 | 月度申报 | 增值税、消费税（按月） |
| 小规模纳税人 | 季度申报 | 增值税（主流）、企业所得税 |
| 企业所得税纳税人 | 年度申报 | 企业所得税汇算清缴 |
| 个人所得税纳税人 | 代扣代缴/年度汇算 | 个人所得税 |

### 申报期限

| 税种 | 申报期限 |
|------|---------|
| 增值税 | 月度：15日；季度：15日（遇节假日顺延） |
| 企业所得税 | 月度/季度：15日；年度：5月31日 |
| 个人所得税 | 代扣代缴：7日；综合所得汇算：次年3月1日-6月30日 |
| 消费税 | 月度/季度：15日 |

### 延期申报与缴纳

| 情形 | 条件 | 申请时限 |
|------|------|---------|
| 延期申报 | 因特殊困难不能按期申报 | 申报期限届满前 |
| 延期缴纳 | 因特殊困难不能按期缴纳税款 | 缴纳税款期限届满前 |

## 发票管理

### 发票类型

| 发票类型 | 适用范围 | 管理方式 |
|---------|---------|---------|
| 增值税专用发票 | 一般纳税人开具 | 勾选认证 |
| 增值税普通发票 | 所有纳税人开具 | 不可抵扣 |
| 增值税电子发票 | 所有纳税人开具 | 与纸质同等效力 |
| 数电票（全面数字化电子发票） | 试点纳税人开具 | 全流程电子化 |

### 发票认证/抵扣

| 发票类型 | 认证方式 | 抵扣期限 |
|---------|---------|---------|
| 增值税专用发票 | 勾选认证 | **2019年后已取消360天认证期限限制，纳税人可随时勾选认证** |
| 机动车销售统一发票 | 勾选认证 | 同上 |
| 海关缴款书 | 采集比对 | 同上 |

### 数电票

**全面数字化电子发票**（数电票）：
- 2021年12月起在广东、上海、内蒙古试点
- 2023年起全国推广
- 特点：无需领用、无需介质（电票平台开具）、全流程电子化

**与传统发票对比**：
| 维度 | 传统发票 | 数电票 |
|------|---------|--------|
| 领用 | 需领用 | 无需领用 |
| 介质 | 纸质/电子文件 | 原生数字化 |
| 交付 | 邮寄/现场 | 自动交付 |
| 版式 | PDF/OFD | XML（无固定版式） |

## 税务稽查

### 稽查程序

```
选案 → 立案 → 检查 → 审理 → 执行
```

### 稽查权限

| 权限 | 说明 |
|------|------|
| 查账权 | 检查账簿、凭证、报表 |
| 场地检查权 | 检查经营场所 |
| 询问权 | 询问相关人员 |
| 函查权 | 发函异地调查取证 |
| 查询权 | 查询存款账户、储蓄存款 |
| 冻结/扣押权 | 税款保全、强制执行 |

### 稽查处理

| 处理结果 | 说明 |
|---------|------|
| 正常 | 无问题 |
| 补税+滞纳金 | 少缴税款+按日加收万分之五滞纳金 |
| 罚款 | 0.5-5倍罚款（偷税） |
| 移送司法 | 涉嫌犯罪的移送公安机关 |

## 法律责任

### 税务违法责任

| 违法行为 | 责任 |
|---------|------|
| 偷税 | 补税+50%-5倍罚款+滞纳金 |
| 欠税 | 滞纳金+可能阻止出境/阻止高消费 |
| 骗税 | 补税+1-5倍罚款+滞纳金 |
| 抗税 | 罚款+滞纳金；构成犯罪的追究刑事责任 |

### 重大税收违法失信

| 标准 | 惩戒措施 |
|------|---------|
| 重大偷税/骗税 | 公布+联合惩戒（出行、融资、高消费限制等） |

## 救济途径

### 救济层级

```
税务稽查/评估 → 行政复议 → 行政诉讼
                ↓
            相互协商程序（MAP，适用于跨境税务）
```

### 行政复议

| 要点 | 说明 |
|------|------|
| 受理机关 | 作出决定的税务机关的上一级 |
| 申请期限 | 60日（自知道具体行政行为之日起） |
| 审理期限 | 60日（复杂情况可延长30日） |
| 法规依据 | 《税务行政复议规则》（国家税务总局令第44号，2018年修订） |

### 行政诉讼

| 要点 | 说明 |
|------|------|
| 管辖法院 | 基层人民法院或中级人民法院 |
| 起诉期限 | 6个月（直接起诉）或15日（复议后起诉） |
| 审理期限 | 一审6个月，二审3个月 |

### 风险防范建议

| 风险点 | 防范措施 |
|--------|---------|
| 申报错误 | 及时自查发现后主动更正申报 |
| 发票风险 | 严格审核发票真实性、合法性 |
| 关联交易 | 提前进行转让定价规划 |
| 跨境业务 | 关注常设机构、协定待遇风险 |

## 时效性说明

**【注】** 税收征管法及实施细则近年来主要修订集中在信息化、电子化方向。2024年关税法已施行，征管法修订也在推进中，建议关注最新修订动态。
