# 单体利润及各项税费 · 估算框架

> 估算模板 v1.0 | 场景：单一纳税主体的利润表 + 各税种计算，用于项目投资测算或年度预算
> 用途：①从收入到净利润的全链路计算 ②各税种应纳税额估算 ③税负结构分析

---

## 一、适用场景与政策依据

### 适用主体

| 主体类型 | 说明 |
|---------|------|
| 居民企业（一般纳税人） | 本模板默认一般纳税人，小规模纳税人需调整增值税部分 |
| 居民企业（小规模纳税人） | 增值税部分按简易计税调整 |
| 非居民企业 | 不适用，需另行设计 |

> ⚠️ 本模板为**估算框架**，各税种的税率/征收率/优惠政策需用户根据企业实际情况确认填写。

### 涉及税种

| 税种 | 计税依据 | 缴纳时点 |
|------|---------|---------|
| 增值税 | 增值额（销项−进项） | 按月/季预缴 |
| 城市维护建设税 | 实缴增值税+消费税额 | 同增值税 |
| 教育费附加 | 实缴增值税+消费税额 | 同增值税 |
| 地方教育附加 | 实缴增值税+消费税额 | 同增值税 |
| 企业所得税 | 应纳税所得额 | 按季预缴，年度汇算 |
| 印花税 | 应税凭证金额 | 书立/领受时 |
| 房产税 | 房产原值/租金收入 | 按年计算分期缴纳 |
| 城镇土地使用税 | 实际占用土地面积 | 按年计算分期缴纳 |

## 二、符号约定

| 规则 | 说明 |
|------|------|
| 金额 | 均填**正数**，公式中通过 ± 号处理方向 |
| 税率/征收率 | 由用户根据企业实际情况填写，不提供默认值 |
| 年度 | 按自然年度计算，跨年项目需逐年拆分 |

### 3-3. 税金及附加明细

| 税费 | 计算公式 | 金额 |
|------|---------|------|
| ① 城市维护建设税 | 实缴增值税额 × 城建税率（7%/5%/1%） | |
| ② 教育费附加 | 实缴增值税额 × 3% | |
| ③ 地方教育附加 | 实缴增值税额 × 2% | |
| ④ 印花税 | 各应税凭证分别计算后合计 | |
| ⑤ 房产税 | 自用：原值×(1−扣除率)×1.2%；出租：租金×12% | |
| ⑥ 城镇土地使用税 | 实际占用面积 × 单位税额 | |
| ⑦ 车船税 | 按车辆/船舶类型和吨位 | |
| ⑧ 环保税 | （如适用） | |
| **税金及附加合计** | ①+②+③+④+⑤+⑥+⑦+⑧ | |

### 3-4. 增值税计算

| 项目 | 计算公式 | 金额 |
|------|---------|------|
| ① 销项税额 | 销售额 × 适用税率 | |
| ② 进项税额 | 取得合规抵扣凭证的进项 | |
| ③ 进项税额转出 | 不得抵扣的进项需转出 | |
| ④ 上期留抵税额 | | |
| ⑤ 应纳增值税额 | ①−(②−③)−④ | |
| ⑥ 简易计税应纳税额 | （如适用）销售额 × 征收率 | |
| ⑦ **本期应交增值税** | ⑤+⑥ | |

## 八、实务提醒

1. **增值税留抵**：期末留抵税额可结转下期，符合条件的可申请留抵退税
2. **小型微利企业**：年应纳税所得额≤300万、从业人数≤300人、资产总额≤5000万，享受优惠税率
3. **税金及附加**：均为利润表项目，在计算营业利润前扣除（不影响应纳税所得额计算，但影响利润总额）
4. **印花税**：不同合同适用不同税率，需逐项计算
5. **房产税从租/从需**：同一房产只能选一种计税方式
6. **预缴vs汇算**：各税种预缴金额与汇算金额可能有差异，本模板按年度汇算口径
7. **关联交易**：如有关联方交易，需关注转让定价调整和资本弱化限制
