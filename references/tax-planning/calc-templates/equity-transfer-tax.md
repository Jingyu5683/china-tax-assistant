# CT-008 股权转让税负测算

> 版本：v1.0 | 更新日期：2026-06-08
> 估算模板 — 给框架不给数值，具体税率/政策有效期由用户自行确认

---

## 一、适用场景

转让方（居民企业/非居民企业/个人/合伙企业）将其持有的标的企业股权转让给受让方，需测算各税种税负及总税负。

**常见触发**：股东退出、并购重组、关联方转让、跨境股权转让、对赌协议

---

## 二、核心计算框架

### 2-1. 股权转让所得

```
股权转让所得 = 转让收入 - 计税基础
```

| 项目 | 说明 | 政策依据 |
|------|------|---------|
| 转让收入 | 包括现金+非现金资产+权益+承担债务 | 总局公告2010年第19号 |
| 计税基础 | 历史成本原则，不得调整评估增值 | 企税法实施条例第56条 |

### 2-2. 各转让方适用税种

| 转让方类型 | 企税 | 个税 | 预提税 | 印花税 | 增值税 |
|-----------|------|------|--------|--------|--------|
| 居民企业 | 25%（高新15%） | - | - | 0.05% | 上市公司股票：金融商品转让 |
| 非居民企业（直接转让） | 10%（协定税率可能更低） | - | 同左 | 0.05% | - |
| 非居民企业（间接转让，7号公告穿透） | 10% | - | 同左 | - | - |
| 个人 | - | 20%（财产转让所得） | - | 0.05% | 上市公司股票：免征 |
| 合伙企业 | 合伙人各自纳税 | 同左 | - | 0.05% | 视合伙人类型 |

### 2-3. 居民企业转让

```
应纳企业所得税 = 股权转让所得 × 适用税率（25%或15%）
```

### 2-4. 个人转让

```
应纳个人所得税 = 股权转让所得 × 20%
```

**67号公告核定征收风险**（计税价格偏低且无正当理由时）：

| 核定方法 | 适用情形 | 政策依据 |
|---------|---------|---------|
| 净资产核定法 | 申报价格低于对应净资产份额 | 67号公告第14条 |
| 类比法 | 参照同类/类似股权转让价格 | 67号公告第14条 |
| 其他合理方法 | 以上均不适用时 | 67号公告第14条 |

### 2-5. 非居民企业转让

```
应纳预提所得税 = 股权转让所得 × 10%（或协定税率）
```

**37号公告源泉扣缴**：支付人代扣代缴

**7号公告间接转让穿透**：通过境外SPV间接转让境内企业股权，若不具有合理商业目的，可能被穿透征税

### 2-6. 特殊性税务处理（59号文）

| 条件 | 要求 |
|------|------|
| ① 合理商业目的 | 具有合理的商业目的 |
| ② 股权收购比例 | 收购股权≥50% |
| ③ 股权支付比例 | 股权支付≥85% |
| ④ 经营连续性 | 重组后12个月内不改变实质性经营 |
| ⑤ 权益连续性 | 原主要股东12个月内不转让所获股权 |

**满足五条件**：可暂不确认转让所得，取得股权按原计税基础确定

### 2-7. 总税负计算

```
总税负 = 企税/个税/预提税 + 印花税 + 增值税（如适用）
税负率 = 总税负 ÷ 转让收入 × 100%
```

---

## 三、决策判断

### 何时选择特殊性税务处理
- 股权支付比例高（≥85%）
- 暂时不需要现金退出
- 转让增值额大，递延纳税的现金流价值显著

### 何时慎用/不适用
- 现金对价为主（股权支付<85%）
- 收购比例<50%
- 12个月内可能再转让所获股权
- 关联方转让但定价偏离公允价值较大（核定风险）

### 关联方特别关注
- 必须符合独立交易原则（企税法第41条）
- 低价转让可能被核定征收
- 需准备同期资料（达到门槛时）
