# 固定资产投资一次性税前扣除 · 估算框架

> 估算模板 v1.0 | 场景：单位价值≤500万元的设备、器具，选择是否适用一次性税前扣除政策
> 用途：对比"正常折旧"与"一次性扣除"两种方案下的项目净现金流，辅助决策

---

## 一、适用场景与政策依据

### 适用条件

| 条件 | 说明 |
|------|------|
| 资产类别 | 设备、器具（不含建筑物、构筑物） |
| 单位价值 | ≤ 500万元（单台/单件/单组，非项目总投资） |
| 取得方式 | 新购进（含以融资租赁方式租入，租入时点为租赁合同约定付款日/首笔付款日） |
| 取得时点 | 以发票开具时间/到货时间确认（参考现行公告） |
| 享受方式 | 企业自行选择，可部分享受（部分资产选一次性扣除，部分不选） |

### 核心政策（需核实现行有效性）

| 政策文号 | 内容要点 | 状态 |
|---------|---------|------|
| 财税〔2018〕54号 | 首次规定单位价值≤500万设备器具一次性税前扣除 | 需核实延续 |
| 财政部 税务总局公告2023年第37号 | 延续至2027年12月31日 | 需核实是否再延续 |
| 总局公告2018年第46号 | 申报表填写及留存备查资料规定 | 现行 |

> ⚠️ 政策有到期日，使用前必须确认政策是否延续。到期后购入的资产不再适用。

## 二、符号约定

| 规则 | 说明 |
|------|------|
| 金额 | 均填**正数**（绝对值），公式中通过 ± 号处理方向 |
| 年份 | 第1年起算 = 资产投入使用的纳税年度 |
| 折旧 | 按资产实际使用年限填列，年限不足可加列 |

## 四、v2 — 使用一次性扣除

> 第1年税法折旧 = ①初始投资额（全额一次性扣除），第2年起税法折旧 = 0
> 产生税会差异 → 纳税调减（第1年）/ 纳税调增（第2年起）→ 递延所得税

| 项目 | 计算公式 | 第1年 | 第2年 | 第3年 | 第4年 | 第5年 | … | 第N年 |
|------|---------|-------|-------|-------|-------|-------|---|-------|
| ① 初始投资额 | = v1① | | | | | | | |
| ② 增加的收入 | = v1② | | | | | | | |
| ③ 增加的变动付现成本 | = v1③ | | | | | | | |
| ④ 增加的固定付现成本 | = v1④ | | | | | | | |
| ⑤ 会计折旧 | = v1⑤ | | | | | | | |
| ⑥ 税法折旧 | **第1年=①，第2年起=0** | | | | | | | |
| ⑦ 税前利润 | ②−③−④−⑤ | | | | | | | |
| ⑧ 纳税调增(调减) | **⑤−⑥**（第1年为负=调减，第2年起为正=调增） | | | | | | | |
| ⑨ 应纳税所得额 | ⑦+⑧ | | | | | | | |
| ⑩ 当期应交所得税 | ⑨ × 所得税税率 | | | | | | | |
| ⑪ 净利润 | ⑦−⑩ | | | | | | | |
| ⑫ 营运资本占用 | = v1⑫ | | | | | | | |
| ⑬ 残值处置净收入 | = v1⑬（但注意：v2税法折旧已全额扣除，处置时税法净值为0，可能有处置收益纳税调增） | | | | | | | |
| ⑭ 营业现金流量 | ⑪+⑤ | | | | | | | |
| ⑮ 项目净现金流 | −①+⑭−⑫+⑬ | | | | | | | |

## 五、v1 vs v2 对比

### 现金流差异速算

> 两种方案唯一差异在所得税的缴纳时点，税负总额相同。

| 项目 | 公式 | 第1年 | 第2年 | … | 第N年 |
|------|------|-------|-------|---|-------|
| v1当期所得税 | v1⑩ | | | | |
| v2当期所得税 | v2⑩ | | | | |
| 所得税差异 | v1⑩ − v2⑩ | | | | |
| 所得税差异折现值 | 差异 / (1+r)^n | | | | |
| **NPV合计** | 各年折现值求和 | — | — | — | — |

**结论**：NPV合计 > 0 → v2（一次性扣除）更优；= 0 → 无差异；< 0 → v1更优（理论上不应出现，除非亏损抵扣受限）。

### 简化速算公式

若仅评估一次性扣除的时间价值收益：

```
第1年税盾收益 = ① × 所得税税率 / (1+r)^1

第2~N年税盾回吐 = 各年 (⑤ − 0) × 所得税税率 / (1+r)^n

净收益 = 第1年税盾收益 − 第2~N年税盾回吐现值
```

> 本质：提前确认折旧 = 利息-free的递延税款，收益 = 时间价值。

## 六、决策判断

### 何时选择一次性扣除（v2）

| 条件 | 说明 |
|------|------|
| ✅ 第1年有足够应纳税所得额 | 一次性扣除的税盾需要利润来吸收；亏损企业无税可抵，选v2无意义 |
| ✅ 折现率 > 0 | 资金有时间价值，早拿税盾永远优于晚拿 |
| ✅ 预期未来税率不下降 | 若未来税率大幅下降，提前确认税盾反而吃亏 |
| ✅ 不影响研发费用加计扣除基数 | 一次性扣除减少税法折旧→增加应纳税所得额，但不影响研发加计扣除（研发设备折旧单独计算） |

### 何时慎选或不选

| 情形 | 原因 |
|------|------|
| ⚠️ 当年亏损或微利 | 税盾无法充分使用，且可能占用以后年度利润 |
| ⚠️ 享受定期减免税 | 减免税期间税盾价值低，正常折旧将税盾递延至正常纳税年度更有利 |
| ⚠️ 预期未来税率上调 | 如果税率上升，晚确认税盾更值（但实践中罕见） |
| ⚠️ 高新/小微等优惠税率期间 | 优惠税率降低税盾价值，需对比优惠期内外税盾差异 |
| ⚠️ 资产可能提前处置 | 一次性扣除后资产税法净值为0，处置时全部对价为应税收益，可能触发大额纳税调增 |

### 递延所得税会计处理（提示）

选择v2后，第1年产生递延所得税负债（DTL），后续年度逐步转回：

```
第1年 DTL = (⑥_第1年 − ⑤_第1年) × 所得税税率
第n年 DTL余额 = 期初DTL − (⑤_n − ⑥_n) × 所得税税率
第N年末 DTL = 0（全部转回）
```

> 递延所得税不影响现金流，但影响资产负债表和利润表（所得税费用分拆为当期+递延）。

## 八、残值处置特殊说明

v2方案下资产税法净值为0（已全额扣除），处置时需注意：

| 处置情形 | v1（正常折旧） | v2（一次性扣除） |
|---------|--------------|----------------|
| 税法净值 | = ① − 累计税法折旧 | = 0 |
| 处置收益（税法） | 处置收入 − 税法净值 − 处置费用 | 处置收入 − 0 − 处置费用（全额计税） |
| 与v1的差异 | — | 多缴所得税 = 未折旧余额 × 税率（但已在第1年提前抵扣） |

> 两种方案下，资产全生命周期总税负相同。差异仅在缴纳时点。

## 九、实务提醒

1. **备查资料**：选择一次性扣除需留存购进发票、记账凭证等备查（无需备案，留存即可）
2. **部分享受**：同一批次购入的多台设备，可只对部分选择一次性扣除
3. **年度汇算**：在年度汇算清缴时通过申报表相关栏次填报，预缴时不强制享受
4. **与加计扣除的协调**：若设备同时用于研发，加计扣除以会计折旧为基数，与一次性扣除不冲突
5. **集团视角**：若母公司购入设备后租赁给子公司使用，需关注出租方一次性扣除与承租方加计扣除的协调
