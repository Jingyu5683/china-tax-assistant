# 所得税亏损弥补 · 估算框架

> 估算模板 v1.0 | 场景：企业以前年度亏损在后续年度的弥补顺序、期限和税盾价值测算
> 用途：①逐年跟踪可弥补亏损余额和到期年度 ②测算亏损吸收的节税价值 ③评估不同弥补策略的现金流影响

---

## 一、适用场景与政策依据

### 弥补期限规则

| 企业类型 | 弥补期限 | 参考来源 | 状态 |
|---------|---------|---------|------|
| 一般企业 | 5年 | 企税法第十八条 | 现行 |
| 高新技术企业 | 10年 | 财税〔2018〕76号 | 需核实延续 |
| 科技型中小企业 | 10年 | 财税〔2018〕76号 | 需核实延续 |
| 集成电路生产企业 | 10年 | 财税〔2018〕27号 | 需核实 |

> ⚠️ 弥补期限从亏损年度的下一年起算。如2021年亏损，5年弥补期至2026年。

### 核心政策

| 政策文号 | 内容要点 | 状态 |
|---------|---------|------|
| 企税法第十八条 | 亏损向后结转，最长5年 | 现行 |
| 财税〔2018〕76号 | 高新和科技型中小企业延长至10年 | 需核实延续 |
| 总局公告2018年第45号 | 10年弥补的资格条件和衔接 | 需核实 |
| 总局公告2010年第157号 | 查补税款不得弥补以前年度亏损 | 现行 |

## 四、税盾价值测算

### 4-1. 弥补节税额

| 项目 | 第1年 | 第2年 | 第3年 | … | 第N年 |
|------|-------|-------|-------|---|-------|
| 当年弥补亏损总额 | 来自3-2② | | | | |
| 节税额 | 弥补额 × 所得税税率 | | | | |
| 节税额折现值 | 节税额 / (1+r)^n | | | | |
| **累计节税折现值** | | | | | |

### 4-2. 亏损到期损失

| 项目 | 金额 |
|------|------|
| 各年度到期未弥补亏损合计 | |
| 损失的税盾价值 | 到期未弥补额 × 所得税税率 |
| 损失的税盾折现值 | 各年损失折现求和 |

### 4-3. 亏损价值评估

| 指标 | 计算 | 金额 |
|------|------|------|

## 五、弥补策略分析

### 5-1. 何时应主动创造利润吸收亏损

| 情形 | 策略 |
|------|------|
| 大额亏损即将到期（1-2年） | 评估是否有可递延的费用/损失可提前确认，释放应纳税所得额来吸收亏损 |
| 亏损期限较长（10年） | 不急于弥补，优先保留利润用于其他优惠（如减免税期） |
| 当年享受减免税 | 减免税期间弥补亏损的税盾价值低，考虑递延到正常纳税年度 |

### 5-2. 与税收优惠的协调

| 优惠类型 | 与亏损弥补的关系 |
|---------|----------------|
| 定期减免税（如三免三减半） | 减免税期间不急于弥补亏损，正常纳税年度弥补税盾价值更高 |
| 小微企业优惠 | 小微低税率期间弥补亏损税盾低，但需注意小微所得限额 |
| 高新15%税率 | 高新期间弥补按15%税率计算税盾，若未来可能取消高新资质则按25%算税盾，需对比 |
| 研发加计扣除 | 加计扣除减少应纳税所得额→可用于弥补亏损的利润减少→可能延缓亏损弥补 |

### 5-3. 预缴与汇算的弥补安排

| 项目 | 说明 |
|------|------|
| 预缴环节 | 预缴时可以选择不弥补以前年度亏损，按季度预缴 |
| 汇算环节 | 年度汇算时弥补以前年度亏损，多预缴的退税 |
| 实操建议 | 预缴不弥补 → 保留资金时间价值 → 汇算时一次性弥补并退税 |

## 六、特殊情形

### 6-1. 企业重组中的亏损弥补

| 重组类型 | 亏损处理 |
|---------|---------|
| 一般性税务处理 | 被合并企业亏损不得在合并企业弥补 |
| 特殊性税务处理 | 被合并企业亏损可由合并企业弥补，但有限额：可弥补额 = 被合并企业净资产公允价值 × 截至合并日国家发行的最长期国债利率 |
| 分立 | 一般性税务处理下亏损按资产比例分摊；特殊性税务处理下亏损由分立后的企业按资产比例继续弥补 |

### 6-2. 境外亏损

| 项目 | 说明 |
|------|------|
| 境外亏损 | 不得用境内所得弥补 |
| 境内外分别计算 | 境内亏损可用境外所得弥补，但弥补后境外所得不再享受境外税额抵免 |

### 6-3. 查补税款与亏损

| 项目 | 说明 |
|------|------|
| 查补所得 | 不得弥补以前年度亏损 |
| 调减亏损 | 以前年度亏损被调减的，相应减少可弥补余额 |

## 八、实务提醒

1. **亏损确认**：必须在年度汇算清缴时申报，未申报的亏损不得弥补
2. **弥补顺序**：FIFO（先到期的先用），不可自主选择弥补哪年亏损
3. **到期日**：到期年度的汇算清缴截止日前仍可弥补，逾期作废
4. **预缴策略**：预缴时可选择不弥补亏损，保留资金时间价值
5. **重组限制**：一般性税务处理下被合并企业亏损不得带入，需特别注意
6. **境外分离**：境内外亏损分别计算，不可交叉弥补
7. **资格变化**：高新/科小资格变化不影响已发生亏损的弥补期限（资格存续期间发生的亏损仍按10年）
