# CT-009 非货币性资产投资递延纳税测算

> 版本：v1.0 | 更新日期：2026-06-08
> 估算模板 — 给框架不给数值，具体税率/政策有效期由用户自行确认

---

## 一、适用场景

投资方以非货币性资产（固定资产/无形资产/股权/不动产等）对外投资，需测算递延纳税效果、增值税影响及退出风险。

**常见触发**：技术出资、设备入股、不动产增资、股权置换

---

## 二、核心计算框架

### 2-1. 非货币性资产转让所得

```
转让所得 = 评估公允价值 - 计税基础
```

### 2-2. 企业116号文递延纳税

**核心逻辑：分期均匀计入应纳税所得额**

```
每年确认转让所得 = 转让所得 ÷ 5
每年增加应纳税额 = 每年确认转让所得 × 适用税率
```

| 项目 | 说明 | 政策依据 |
|------|------|---------|
| 递延期限 | 不超过5年 | 财税[2014]116号 |
| 计入方式 | 分期均匀计入相应年度的应纳税所得额 | 116号第2条 |
| 取得股权计税基础 | 原计税基础 + 每年确认的转让所得（逐年调整） | 总局公告2015年第33号 |
| 递延中断 | 5年内注销/撤回/转让股权 → 未确认所得一次性计入 | 116号第3条 |

**计税基础逐年调整表**：

| 年份 | 确认所得 | 计税基础调整 | 累计计税基础 |
|------|---------|------------|------------|
| 投资时 | - | 原计税基础 | 原计税基础 |
| 第1年 | 所得÷5 | +所得÷5 | 原计税基础+所得÷5 |
| 第2年 | 所得÷5 | +所得÷5 | 原计税基础+所得×2/5 |
| ... | ... | ... | ... |
| 第5年 | 所得÷5 | +所得÷5 | 原计税基础+所得（=公允价值） |

### 2-3. 个人41号文递延纳税

**核心逻辑：分期缴纳应纳税额（与企业不同！）**

```
应纳税所得额 = 评估公允价值 - 计税基础
应纳税额 = 应纳税所得额 × 20%
每年缴纳税额 = 应纳税额 ÷ 5
```

| 项目 | 说明 | 政策依据 |
|------|------|---------|
| 递延期限 | 不超过5个公历年度 | 财税[2015]41号 |
| 缴纳方式 | 分期缴纳应纳税额 | 41号第1条 |
| 递延中断 | 5年内转让股权/收回投资 → 未缴税额一次性缴纳 | 41号第4条 |

### 2-4. 企业vs个人递延逻辑对比（关键差异）

| 维度 | 企业（116号文） | 个人（41号文） |
|------|---------------|--------------|
| 递延对象 | **应纳税所得额**（分期计入所得） | **应纳税额**（分期缴纳税款） |
| 每年影响 | 增加1/5所得，与其他所得合并计税 | 直接缴纳1/5税额 |
| 税率影响 | 可能因累计所得跨档影响边际税率 | 固定20%，无跨档问题 |
| 计税基础调整 | 逐年递增（33号公告） | 不调整（一次性确定） |
| 递延中断 | 未确认所得一次性计入当期 | 未缴税额一次性缴纳 |

### 2-5. 增值税处理

| 资产类型 | 增值税处理 | 政策依据 |
|---------|----------|---------|
| 技术/专利/软件著作权 | 免征（需合同认定+备查） | 财政部 税务总局公告2026年第10号 |
| 固定资产/设备 | 视同销售，一般13% | 增值税法 |
| 不动产 | 视同销售，一般9%/简易5% | 财政部 税务总局公告2026年第9号 |
| 股权 | 不征增值税（非增值税应税范围） | 增值税法 |

### 2-6. 与59号文不可叠加

同一笔非货币性资产投资转让所得，59号文特殊性税务处理和116号文递延纳税**不可叠加适用**，需择优选择：

| 选择 | 适用场景 |
|------|---------|
| 116号文递延 | 股权支付比例<85%，不满足59号文条件；或虽满足但递延5年更优 |
| 59号文特殊处理 | 股权支付≥85%，且暂不确认所得更优（计税基础不调整） |

### 2-7. NPV分析

```
即期纳税：一次性缴税T0
递延纳税：5年逐年缴税T1~T5

递延收益(NPV) = T0 - Σ(Ti / (1+r)^i)
```

## 三、决策判断

### 何时选择递延纳税（116号/41号）
- 转让增值额大，当期缴税现金流压力大
- 不满足59号文条件（股权支付比例不足等）
- 有明确的5年以上持有计划

### 何时选择59号文特殊处理
- 股权支付≥85%
- 完全递延（暂不确认任何所得）更优
- 不需要逐年调整计税基础

### 何时需谨慎
- 5年内有退出计划（触发递延中断，加速纳税）
- 评估值可能被税务机关质疑
- 企业116号文下每年确认所得可能推高边际税率
