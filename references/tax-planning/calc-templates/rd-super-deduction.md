# 研发费用加计扣除 · 估算框架

> 估算模板 v1.0 | 场景：企业研发费用加计扣除测算 + 高新/软件企业指标倒推
> 用途：①基于研发预算测算加计扣除节税额 ②倒推高新/软件企业资质维持的各项指标上下限

---

## 一、适用场景与政策依据

### 适用条件

| 条件 | 说明 |
|------|------|
| 主体 | 除负面清单行业（烟草、住宿餐饮、批发零售、娱乐等）外的居民企业 |
| 研发活动 | 为获得科学与技术新知识，或实质性改进技术/产品/工艺而进行的系统性活动 |
| 费用归集 | 按研发项目单独建账、准确归集 |
| 会计核算 | 必须设置研发支出辅助账 |

### 核心政策（需核实现行有效性）

| 政策文号 | 内容要点 | 状态 |
|---------|---------|------|
| 财税〔2015〕119号 | 加计扣除基本范围和负面清单 | 需核实 |
| 总局公告2017年第40号 | 加计扣除归集范围及口径细化 | 需核实 |
| 财税〔2023〕7号 | 将加计扣除比例统一提高至100%，作为制度性安排长期实施 | 需核实 |
| 总局公告2023年第11号 | 研发费用税前扣除及加计扣除政策执行口径 | 需核实 |
| 财税〔2023〕42号 | 集成电路企业和工业母机企业加计扣除120% | 需核实 |

> ⚠️ 加计扣除比例可能因行业/政策调整而变化，使用前确认现行比例。

---

## 二、符号约定

| 规则 | 说明 |
|------|------|
| 金额 | 均填**正数** |
| 费用类别 | 按总局公告2017年第40号规定的六大类+委托外部研发 |
| 加计扣除比例 | 由用户根据企业类型和政策确认后填入 |

## Part A：基于预算计算加计扣除金额

### A1. 研发费用归集表

| 费用类别 | 项目1 | 项目2 | … | 项目N | 合计 |
|---------|-------|-------|---|-------|------|

| ② 直接投入费用 | | | | | |
| ③ 折旧费用 | | | | | |
| ④ 无形资产摊销 | | | | | |
| ⑤ 新产品设计费等 | | | | | |
| ⑥ 其他相关费用 | | | | | |
| ⑦ 委托外部研发（境内） | | | | | |
| ⑧ 委托外部研发（境外） | | | | | |
| **可加计扣除费用合计** | | | | | |

### A2. 限额调整

#### A2-1 委托外部研发限额

| 项目 | 公式 | 金额 |
|------|------|------|
| 境内委托可计入额 | ⑦ × 80% | |
| 境外委托可计入额 | min(⑧ × 80%, 境内符合条件的研发费用 × 2/3) | |
| 委托调整额（调减） | (⑦ − ⑦×80%) + (⑧ − ⑧实际可计入额) | |

> 境外委托限额中的"境内符合条件的研发费用"= ①+②+③+④+⑤+⑥（不含委托部分）

#### A2-2 其他相关费用限额

| 项目 | 公式 | 金额 |
|------|------|------|
| 其他相关费用限额 | (①+②+③+④+⑤+⑦×80%+⑧实际可计入额) × 10% / (1−10%) | |
| 实际其他相关费用 | ⑥ | |
| 可加计扣除的其他相关费用 | min(⑥, 限额) | |
| 其他相关费用调整额（调减） | max(⑥ − 限额, 0) | |

> 10%限额计算公式说明：限额 = (其他五项费用之和 + 委托可计入) × 10%/(1−10%)，即限额占总费用的比例不超过10%

#### A2-3 特殊研发费用限额

| 项目 | 说明 | 金额 |
|------|------|------|
| 创意设计活动费用 | 多用途设计费需合理分摊，仅研发用途部分可加计 | |
| 政府补助冲减 | 作为不征税收入处理的政府补助对应的研发费用不得加计扣除 | |

### A3. 加计扣除计算

| 项目 | 公式 | 金额 |
|------|------|------|
| ⑨ 调整后可加计扣除研发费用 | 合计 − 委托调整额 − 其他相关费用调整额 − 政府补助冲减 | |
| ⑩ 加计扣除比例 | 用户确认（一般企业100%/集成电路和工业母机120%） | |
| ⑪ 加计扣除额 | ⑨ × ⑩ | |
| ⑫ 节税额 | ⑪ × 企业所得税税率 | |

### A4. 多年度跟踪（预算场景）

| 项目 | 第1年 | 第2年 | 第3年 | … |
|------|-------|-------|-------|---|
| 研发费用总额 | | | | |
| 加计扣除额 | | | | |
| 节税额 | | | | |
| 累计节税额 | | | | |
| 研发投入产出比 | 累计节税/累计研发投入 | | | |

### A5. 预缴享受测算

| 项目 | 说明 |
|------|------|
| 预缴享受时点 | 第3季度（或9月份）预缴时即可享受上半年的加计扣除 |
| 预缴可享受额 | 上半年符合条件研发费用 × 加计扣除比例 |
| 年度汇算调整 | 年度汇算时按全年数据调整，多退少补 |
| 选择不预缴享受 | 可在年度汇算时一次性享受，无滞纳金 |

## Part B：倒推高新/软件企业指标上下限

### B1. 高新技术企业指标倒推

> 输入：企业预计总收入/总人数/产品收入 → 输出：各项指标的最低/最高限值

#### B1-1 研发费用占比指标

**三档标准**（需核实现行政策）：

| 企业规模（近三年销售收入） | 最低研发费用占比 | 参考来源 |
|------------------------|----------------|---------|
| ≤ 5000万元 | ≥ 5% | 国科发火〔2016〕32号及后续修订 |
| 5000万元 ~ 2亿元 | ≥ 4% | |
| > 2亿元 | ≥ 3% | |

**倒推计算**：

| 项目 | 公式 | 金额 |
|------|------|------|
| 近三年销售收入总额 | 用户填入 | |
| 适用最低占比 | 对应上表 | |
| **三年研发费用最低合计** | 销售收入总额 × 最低占比 | |
| **年均研发费用最低** | 上述 / 3 | |

> 这是维持高新资质的**最低研发投入红线**，实际投入应留一定安全边际。

#### B1-2 科技人员占比指标

| 项目 | 公式 | 人数 |
|------|------|------|
| 企业职工总数 | 用户填入 | |
| 最低科技人员占比 | ≥ 10%（国科发火〔2023〕132号修订） | |
| **科技人员最低人数** | 职工总数 × 10%（向上取整） | |
| 科技人员上限 | 无上限，但需合理 | |

> 科技人员定义：直接从事研发和相关技术创新活动，及专门从事上述活动管理的，累计实际工作时间在183天以上的人员。

#### B1-3 高新技术产品/服务收入占比

| 项目 | 公式 | 金额 |
|------|------|------|
| 企业当年总收入 | 用户填入 | |
| 最低占比 | ≥ 60% | |
| **高新收入最低额** | 总收入 × 60% | |

#### B1-4 综合指标压力测试

| 指标 | 现有值 | 最低要求 | 差额 | 风险等级 |
|------|-------|---------|------|---------|
| 研发费用占比 | ___% | ≥___% | | ⬜安全 ⬜临界 ⬜不达标 |
| 科技人员占比 | ___% | ≥10% | | ⬜安全 ⬜临界 ⬜不达标 |
| 高新收入占比 | ___% | ≥60% | | ⬜安全 ⬜临界 ⬜不达标 |
| 成长性指标 | ___分 | — | | 另行评分 |

> 任何一项不达标即无法通过认定。临界 = 差额在1个百分点以内。

### B2. 软件企业指标倒推

> 软件企业认定分两套：①双软评估（软件行业协会）②享受税收优惠的软件企业（财税条件）
> 此处聚焦享受企业所得税优惠的指标条件。

**核心指标**（需核实现行政策）：

| 指标 | 要求 | 参考来源 |
|------|------|---------|
| 软件产品收入占比 | ≥ 50%（其中自主开发软件产品收入占比≥40%） | 财税〔2012〕27号及延续 |
| 研发费用占比 | ≥ 6%（境内研发费用≥60%） | |
| 研发人员占比 | ≥ 20% | |
| 主营业务拥有自主知识产权 | ≥ 1项 | |
| 软件产品质量 | 通过第三方检测 | |

**倒推计算**：

| 项目 | 公式 | 金额 |
|------|------|------|
| 企业预计总收入 | 用户填入 | |
| **自主软件收入最低额** | 总收入 × 40% | |
| **软件产品收入最低额** | 总收入 × 50% | |
| **研发费用最低额** | 总收入 × 6% | |
| **境内研发费用最低额** | 研发费用 × 60% | |
| **研发人员最低数** | 职工总数 × 20%（向上取整） | |

### B3. 加计扣除与高新/软件资质的交叉影响

| 交叉点 | 说明 |
|--------|------|
| 研发费用同一口径？ | 不完全一致。加计扣除口径 < 高新口径（高新含某些加计扣除不含的费用），但加计扣除口径更严格（负面清单等） |
| 加计扣除研发费用能否计入高新指标？ | 可以，但高新认定用的是"研究开发费用"口径，需按高新归集标准调整 |
| 委托外部研发 | 加计扣除按80%计入，高新认定按80%计入（实际发生额的80%），口径一致 |
| 其他相关费用 | 加计扣除有10%限额，高新认定无此限额，高新口径更宽 |
| 政府补助 | 作为不征税收入处理的政府补助对应费用：加计扣除不可、高新认定争议（实操中通常不计入） |

> ⚠️ 两套口径的差异意味着：加计扣除计算表不能直接用于高新申报，需做口径调整。

## 四、实务提醒

1. **辅助账必设**：未按规定设置研发支出辅助账的，不得享受加计扣除
2. **备查资料**：研发项目计划书、费用分配说明、研发人员考勤等，留存备查
3. **负面清单行业**：烟草制造、住宿餐饮、批发零售、房地产、租赁商务服务、娱乐业不得享受
4. **创意设计活动**：与研发活动难以区分的创意设计费用，需明确区分研发用途部分
5. **委托研发合同**：需经科技主管部门登记（境内），未登记不得加计扣除
6. **跨期项目**：研发项目跨年度的，费用按实际发生年度归集
7. **高新资质维护**：每年需关注指标是否仍在门槛以上，收入/人员变动可能影响达标
8. **口径差异**：加计扣除口径 ≠ 高新认定口径，两套归集不可简单替代
