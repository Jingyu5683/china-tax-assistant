# CT-010 不动产交易多税种协调测算

> 版本：v1.0 | 更新日期：2026-06-08
> 估算模板 — 给框架不给数值，具体税率/政策有效期由用户自行确认

---

## 一、适用场景

转让方出售/投资/划转不动产（商业/办公/工业/住宅/土地使用权），需测算增值税、土地增值税、契税、企业所得税/个人所得税、印花税等多税种协调下的总税负。

**常见触发**：不动产出售、不动产出资、企业分立/资产划转、旧房转让

---

## 二、核心计算框架

### 2-1. 增值税

| 计税方式 | 适用条件 | 税率 |
|---------|---------|------|
| 一般计税 | 2016.4.30后取得/一般纳税人 | 9%（销项-进项） |
| 简易征收 | 2016.4.30前取得/小规模纳税人 | 5%（差额或全额） |

```
一般计税：应纳增值税 = 销项税额 - 进项税额
  销项税额 = 转让收入 ÷ (1+9%) × 9%

简易征收：应纳增值税 = (转让收入 - 取得价) ÷ (1+5%) × 5%
  或全额：= 转让收入 ÷ (1+5%) × 5%
```

### 2-2. 土地增值税（最复杂、最大变量）

**增值额** = 转让收入 - 扣除项目

**扣除项目**：

| 扣除项 | 房企 | 非房企（开发） | 非房企（旧房） |
|--------|------|-------------|-------------|
| 取得土地使用权金额 | ✅ | ✅ | ✅ |
| 开发成本 | ✅ | ✅ | - |
| 开发费用 | ✅（限额） | ✅（限额） | - |
| 与转让相关的税金 | ✅ | ✅ | ✅ |
| 加计扣除20% | ✅（仅房企） | - | - |

**非房企旧房两种扣除方式**：

| 方式 | 计算方法 | 适用 |
|------|---------|------|
| 发票法 | 购房发票金额 × (1+5%×持有年数) | 有原始购房发票 |
| 评估法 | 重置成本 × 成新度折扣率 | 无发票/评估更优 |

**四级超率累进税率**：

| 增值率 | 税率 | 速算扣除系数 |
|--------|------|------------|
| ≤50% | 30% | 0% |
| 50%-100% | 40% | 5% |
| 100%-200% | 50% | 15% |
| >200% | 60% | 35% |

```
增值率 = 增值额 ÷ 扣除项目合计 × 100%
应纳土增税 = 增值额 × 适用税率 - 扣除项目合计 × 速算扣除系数
```

### 2-3. 契税（受让方缴纳）

```
契税 = 成交价格 × 3%-5%（各省自定）
```

| 免税情形 | 政策依据 |
|---------|---------|
| 企业改制重组 | 财税[2018]17号 |
| 公司内部分立/合并 | 17号文 |
| 同一投资主体内部划转 | 17号文 |

### 2-4. 企业所得税/个人所得税

```
转让所得 = 转让收入 - 资产净值 - 相关税金
企税 = 转让所得 × 25%（或高新15%）
个税 = 转让所得 × 20%
```

### 2-5. 印花税

```
印花税 = 转让收入 × 0.05%（产权转移书据）
```

### 2-6. 总税负计算

```
卖方税负 = 增值税 + 土增税 + 企税/个税 + 印花税
买方税负 = 契税 + 印花税
总税负 = 卖方税负 + 买方税负
```

## 三、增值税与土增税联动分析

增值税计税方式的选择直接影响土增税：

| 维度 | 一般计税9% | 简易征收5% |
|------|-----------|-----------|
| 增值税额 | 可能较高（但有进项抵扣） | 可能较低 |
| 土增税转让收入 | 不含税收入（收入-销项税） | 不含税收入（收入-增值税） |
| 土增税税金扣除 | 可扣除增值税及附加 | 可扣除增值税及附加 |
| 综合影响 | 需逐项测算 | 需逐项测算 |

**关键结论**：增值税选择不能只看增值税本身，必须结合土增税综合测算。

## 四、决策判断

### 何时选择简易征收
- 2016.4.30前取得
- 取得成本低，差额征税税额低
- 综合考虑土增税后总税负更低

### 何时选择一般计税
- 进项税额较大
- 增值额不高，土增税档位低
- 综合测算更优

### 何时适用重组免税
- 非房企企业改制重组（57号文免土增税）
- 同一投资主体内部划转
- 需满足17号文/57号文条件

### 何时需谨慎
- 增值率高（>100%），土增税税率跳档
- 股权转让间接转让不动产（穿透风险）
- 关联方低价转让（核定风险）
