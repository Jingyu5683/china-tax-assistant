# 企业分红/利润分配 税务筹划引导

> 试点场景一：高频、多层复杂（居民/非居民/个税代扣）、政策明确但有细节陷阱。
> 通用规则（四步流程定义、五模块说明、合规等级标注、合规声明、路由逻辑）见 `tax-planning-framework.md`，本文档只写本场景的差异化内容。

## 一、第一层：场景专用内容

### Step 1：明确业务实质（分红场景专用提问清单）

| 引导维度 | 选项 |
|---------|------|
| 分配主体 | 居民企业 / 非居民企业 / 合伙企业 / 个人独资企业 |
| 接收方性质 | 居民企业股东 / 非居民企业股东 / 个人股东 / 合伙企业股东 |
| 分配标的 | 利润分红 / 盈余公积转增 / 撤资 / 减资 |
| 是否跨境 | 境内分配 / 境外分配（涉及外汇/协定） |
| 是否关联方 | 是 / 否 |
| 时间要素 | 当年利润 / 以前年度未分配利润 / 跨年分配 |
| 核心诉求 | 降低税负 / 合规确认 / 跨境资金安排 |

### Step 2：适用政策/实务框架

**适用税种**：企业所得税（居民/非居民）、个人所得税（个人股东）、预提所得税（非居民企业股东）。分红不征增值税；可能涉及印花税。

**核心政策依据**：

| 政策 | 文号 | 关键条款 | 效力层级 |
|------|------|---------|---------|
| 企业所得税法 | 主席令63号 | 第26条（居民企业之间股息红利免税）、第37条（源泉扣缴） | P0 |
| 企业所得税法实施条例 | 国务院令512号 | 第83条（免税条件）、第91条（非居民减按10%） | P0 |
| 国家税务总局公告2017年第37号 | 总局公告2017年第37号 | 非居民企业所得税源泉扣缴有关问题（扣缴义务发生时间、外币折算等） | P0 |
| 国家税务总局公告2019年第35号 | 总局公告2019年第35号 | 非居民纳税人享受税收协定待遇管理办法 | P0 |
| 内地与香港特别行政区关于对所得避免双重征税和防止偷漏税的安排 | 国税函[2006]884号（转发文件） | 第10条（股息税率） | P0 |

**合规等级标注**：

| 情形 | 合规等级 | 标注 |
|------|------|------|
| 居民企业之间股息红利免税（符合条件） | 🟢 明确支持 | [合规-明确] |
| 非居民企业分红适用税收协定限制税率 | 🟡 存在争议 | [合规-争议]（需税务备案/审批） |
| 通过复杂架构规避预提所得税 | 🔴 高风险 | [合规-高风险] |

### Step 3：误用风险提示（分红场景常见误用）

| 误用表现 | 为什么错 | 正确理解 |
|---------|---------|---------|
| 认为所有股息红利都免税 | 忽略"符合条件"的前提（持股期限/损益弥补等） | 只有居民企业直接投资于其他居民企业取得的股息红利，且持股期限满12个月的，才能免税 |
| 非居民企业分红一律按10%预提 | 忽略税收协定可能提供更优惠税率 | 需要查阅具体税收协定，可能适用5%/7%等优惠税率 |
| 个人股东分红按20%税率纳税，没有筹划空间 | 忽略税收优惠（如创投企业/中小高新技术企业） | 符合条件的创投企业/中小高新技术企业，个人合伙人可能享受优惠 |
| 分红不涉及增值税 | 正确，但忽略附加税费 | 分红本身不征增值税，但企业所得税/个人所得税是主税 |

## 二、第二层：场景专用内容

### 模块A：政策依据补全（分红场景）

**示例方案**："我司（居民企业）拟向境外母公司（新加坡居民企业）分红500万，母公司直接持股满2年，拟申请适用税收协定5%限制税率。"

| 关键步骤 | 法规依据 | 条款原文或要点摘录 |
|---------|---------|----------------|
| 1. 判断母公司是否为新加坡税收居民 | 《内地新加坡税收协定》 | 第4条（居民） |
| 2. 判断是否符合股息条款受益所有人条件 | 国家税务总局公告2018年第9号 | 受益所有人判断标准 |
| 3. 判断是否可以适用5%限制税率 | 《内地新加坡税收协定》 | 第10条（股息）第2款 |
| 4. 判断是否需要源泉扣缴 | 企业所得税法 | 第37条（源泉扣缴） |
| 5. 判断扣缴义务发生时间 | 国家税务总局公告2017年第37号 | 第7条（扣缴义务发生时间） |

---

### 模块B：落地细节补充（分红场景）

| 维度 | 补充内容 |
|------|---------|
| 备查资料 | 股东会决议/利润分配方案/境外母公司税收居民身份证明/受益所有人声明/合同/支付凭证 |
| 申报操作 | 扣缴企业所得税报告表（关联业务往来报告表）/ 中华人民共和国税收居民身份证明申请表（如需要） |
| 备案 vs 备查 | 税收协定待遇备案（如需要）/ 其他资料备查 |
| 时点要求 | 支付款项时代扣代缴 / 到期应支付款项时扣缴 |
| 会计处理 | 借：利润分配-应付股利 贷：应付股利-境外母公司 / 借：应付股利-境外母公司 贷：银行存款 应交税费-应交企业所得税 |
| 后续跟踪 | 是否需要后续调整/补充备案 |

---

### 模块C：风险遗漏排查（分红场景）

- [ ] 各税种是否全覆盖（企业所得税/个人所得税/预提所得税/印花税等）
- [ ] 反避税条款是否触发（受益所有人/一般反避税条款）
- [ ] 税收优惠的维持条件（如适用优惠，后续是否需要持续满足某些条件）
- [ ] 申报口径的地域差异（是否有各地执行口径不统一的风险）
- [ ] 时效风险（追溯期、补税时效等）

---

### 模块D：交叉影响分析（分红场景）

| 分析维度 | 关注点 |
|---------|--------|
| 税种间影响 | 分红不征增值税，但可能涉及印花税 |
| 会计与税务差异 | 会计确认与税务处理不一致时的递延税影响 |
| 业务连续性 | 本次分红对后续期间/后续交易的影响（如影响企业留存收益/资产负债率等） |
| 信息披露 | 是否需要在财报/附注中披露（关联方交易/重大事项） |
| 关联交易 | 是否影响转让定价文档/国别报告义务 |

```
1. 方案摘要

2. 方案骨架

   - 步骤5：{{子公司}}办理协定待遇备案（如需要）
   - 步骤6：{{子公司}}进行对外支付税务备案（如需要）
   - 步骤7：{{母公司}}收到{{股息}}（税后净额）

3. 关键判断节点
   - [{{母公司}}是否为{{国家}}税收居民？] → 《内地{{国家}}税收协定》第4条
   - [{{母公司}}是否符合受益所有人条件？] → 国家税务总局公告2018年第9号
   - [{{股息}}是否符合协定股息定义？] → 《内地{{国家}}税收协定》第10条

4. 差异点清单（复用时必改项）
   - {{金额}}：根据实际分配金额
   - {{国家}}：影响协定适用，需查对应协定条款
   - {{税率}}：根据具体协定条款确定
   - {{地域口径}}：需确认主管税务局态度
```
