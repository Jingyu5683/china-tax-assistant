# 股权转让 税务筹划引导

> 试点场景四：最高频场景，企税+个税+预提税交织，关联方定价/核定征收/递延纳税等实操陷阱多。
> 通用规则（四步流程定义、五模块说明、合规等级标注、合规声明、路由逻辑）见 `tax-planning-framework.md`，本文档只写本场景的差异化内容。

| 引导维度 | 选项 |

| 受让方性质 | 居民企业 / 非居民企业 / 个人 |

| 是否关联方 | 是（→追问关联关系类型） / 否 |
| 是否跨境 | 纯境内 / 境外转让境内企业股权 / 境内转让境外企业股权 / 间接转让 |

### Step 2：适用政策/实务框架

**适用税种**：企业所得税（居民/非居民）、个人所得税（个人股东）、预提所得税（非居民企业间接转让）、印花税（产权转移书据）、增值税（上市公司股票转让）。

**核心政策依据**：

| 政策 | 文号 | 关键条款 | 效力层级 |
|------|------|---------|---------|
| 企业所得税法 | 主席令63号 | 第6条（转让财产所得）、第37条（源泉扣缴） | P0 |
| 企业所得税法实施条例 | 国务院令512号 | 第16条（股权转让所得=转让收入-股权计税基础） | P0 |
| 个人所得税法 | 主席令第9号 | 第6条（财产转让所得20%）、第9条（反避税条款） | P0 |
| 国家税务总局公告2014年第67号 | 总局公告2014年第67号 | 个人股权转让个人所得税管理办法（计税依据、核定征收） | P0 |
| 国家税务总局公告2017年第37号 | 总局公告2017年第37号 | 非居民企业所得税源泉扣缴 | P0 |
| 国家税务总局公告2015年第7号 | 总局公告2015年第7号 | 非居民企业间接转让财产企业所得税 | P0 |
| 财税[2009]59号 | 财税[2009]59号 | 特殊性税务处理（股权收购适用） | P0 |
| 增值税法 | 中华人民共和国主席令第十六号 | 上市公司股票转让适用增值税（金融商品转让） | P0 |
| 财政部 税务总局公告2026年第9号 | 财政部 税务总局公告2026年第9号 | 附件2（金融商品转让范围界定） | P0 |

**合规等级标注**：

| 情形 | 合规等级 | 标注 |
|------|------|------|
| 个人按公允价值转让非上市公司股权，如实申报个税 | 🟢 明确支持 | [合规-明确] |
| 非居民企业直接转让境内企业股权，适用源泉扣缴 | 🟢 明确支持 | [合规-明确] |
| 关联方之间低价转让股权，主张"合理理由" | 🟡 存在争议 | [合规-争议]（税务机关可能核定征收） |
| 通过境外SPV间接转让境内企业股权规避预提税 | 🔴 高风险 | [合规-高风险]（7号公告穿透） |
| 个人股权转让申报计税价格明显偏低且无正当理由 | 🔴 高风险 | [合规-高风险]（67号公告核定征收） |

### Step 3：误用风险提示（股权转让场景常见误用）

| 误用表现 | 为什么错 | 正确理解 |
|---------|---------|---------|
| 认为股权转让只涉及企业所得税或个人所得税 | 忽略多税种交叉 | 可能同时涉及企税/个税/预提税/印花税/增值税（上市公司股票） |
| 认为个人股权转让按20%交税就够了 | 忽略67号公告的核定征收规则 | 计税价格偏低且无正当理由的，税务机关有权核定征收 |
| 认为非居民间接转让境内股权不在中国纳税 | 忽略7号公告的穿透规则 | 非居民企业通过境外SPV间接转让境内企业股权，若不具有合理商业目的，可能被穿透征税 |
| 认为对赌协议中的补偿款可以冲减股权转让收入 | 忽略对赌补偿的税务定性争议 | 对赌补偿款的税务处理尚无统一规定，各地口径不一，可能被认定为新的交易而非原交易调整 |
| 认为亏损企业股权可以零元转让不产生税负 | 忽略净资产和评估价值 | 即使亏损，若企业有不动产/无形资产等增值资产，税务机关可能按净资产核定 |
| 上市公司股票转让只涉及印花税 | 忽略增值税 | 个人转让上市公司股票免征增值税，但企业转让需按金融商品转让缴纳增值税 |

## 二、第二层：场景专用内容

### 模块A：政策依据补全（股权转让场景）

**示例方案**："我司（居民企业A）拟将其持有的B公司（非上市居民企业）30%股权转让给C公司（关联方），转让对价5000万元，原始出资1000万元。"

| 关键步骤 | 法规依据 | 条款原文或要点摘录 |
|---------|---------|----------------|
| 1. 确认股权转让所得 | 企业所得税法实施条例第16条 | 股权转让所得=转让收入-股权计税基础 |
| 2. 确认转让收入 | 国家税务总局公告2010年第19号 | 转让收入包括现金+非现金资产+权益 |
| 3. 确认计税基础 | 企业所得税法实施条例第56条 | 历史成本原则，不得调整评估增值 |
| 4. 判断是否适用特殊性税务处理 | 财税[2009]59号 | 股权收购≥50%+股权支付≥85%+其他条件 |
| 5. 判断关联交易定价是否合规 | 企业所得税法第41条 | 独立交易原则 |
| 6. 判断是否触发预提税 | 国家税务总局公告2017年第37号 | 非居民企业转让境内企业股权适用源泉扣缴 |

---

### 模块B：落地细节补充（股权转让场景）

| 维度 | 补充内容 |
|------|---------|
| 备查资料 | 股权转让协议/股东会决议/标的企业章程/出资证明/评估报告（如需）/关联交易定价合理性说明/对赌协议（如有） |
| 申报操作 | 企税：年度纳税申报表相关行次/个税：扣缴义务人申报或自行申报（67号公告）/预提税：源泉扣缴申报 |
| 备案 vs 备查 | 特殊性税务处理需备案/个人股权转让个税需向主管税务机关报告/非居民间接转让需向税务机关报告（7号公告） |
| 时点要求 | 协议生效且完成股权变更手续时确认收入/分期付款按合同约定日期确认 |
| 会计处理 | 借：银行存款/长期股权投资 贷：长期股权投资-成本 投资收益 |
| 后续跟踪 | 对赌条件达成情况/分期收款确认/特殊性税务处理后续12个月跟踪 |

---

### 模块C：风险遗漏排查（股权转让场景）

- [ ] 各税种是否全覆盖（企税/个税/预提税/印花税/增值税）
- [ ] 非居民间接转让是否触发7号公告穿透
- [ ] 关联方定价是否符合独立交易原则（是否需准备同期资料）
- [ ] 个人股权转让的计税依据是否被核定（67号公告六种核定情形）
- [ ] 对赌条款的税务影响是否分析到位
- [ ] 标的企业是否有未分配利润/盈余公积（可能影响价格合理性判断）
- [ ] 亏损企业转让是否仍需按净资产核定
- [ ] 分期收款/股权支付对收入确认时点的影响
- [ ] 申报口径的地域差异（各地对"正当理由"/"合理商业目的"的认定标准）

---

### 模块D：交叉影响分析（股权转让场景）

| 分析维度 | 关注点 |
|---------|--------|
| 税种间影响 | 企税/个税/预提税/印花税/增值税各自独立计算，但转让定价一致性是关键 |
| 会计与税务差异 | 会计按公允价值确认 vs 税务按计税基础计算，产生递延所得税 |
| 业务连续性 | 股权转让后是否触发对赌条件/竞业限制/管理权变更等后续影响 |
| 信息披露 | 重大股权转让是否需在财报/临时公告中披露（上市公司/新三板） |
| 关联交易 | 是否影响转让定价文档/国别报告义务/受控外国企业规则 |

### 模块E：方案蒸馏归档（股权转让场景）

```
1. 方案摘要
   - 场景类型：股权转让
   - 适用标签：居民企业 / 非居民 / 个人 / 关联交易 / 跨境 / 特殊性税务处理
   - 核心路径：{{转让方}}将持有的{{标的企业}}{{持股比例}}%股权转让给{{受让方}}，
         对价{{金额}}万元（{{对价形式}}），转让所得{{金额}}万元

2. 方案骨架
   - 步骤1：确认{{转让方}}主体性质（居民企业/非居民/个人）
   - 步骤2：确认{{标的股权}}计税基础
   - 步骤3：确认{{转让对价}}是否公允（关联方需关注独立交易原则）
   - 步骤4：计算{{股权转让所得}}及各税种税额
   - 步骤5：判断是否适用特殊性税务处理（如符合条件）
   - 步骤6：办理税务申报（企税/个税/预提税/印花税）
   - 步骤7：跟踪后续事项（对赌/分期/特殊性税务处理维持条件）

3. 关键判断节点
   - [{{转让对价}}是否公允？] → 关联方适用独立交易原则，非关联方可参考评估值
   - [是否适用特殊性税务处理？] → 财税[2009]59号五项条件
   - [是否触发7号公告？] → 非居民间接转让需判断合理商业目的
   - [个人股权转让计税依据是否被核定？] → 67号公告六种情形

4. 差异点清单（复用时必改项）
   - {{转让方}}：居民企业/非居民/个人，决定适用税种和税率
   - {{持股比例}}：影响是否构成控制/是否适用特殊性税务处理
   - {{对价形式}}：现金/股权/混合，影响收入确认和税务处理方式
   - {{关联关系}}：影响定价合规要求和同期资料义务
   - {{地域口径}}：各地对"正当理由"/核定征收的执行标准不同
```
