# 不动产交易 税务筹划引导

> 试点场景六：多税种协调（增值税+土增税+契税+企税+印花税），土增税清算复杂，实务中高频且陷阱密集。
> 通用规则（四步流程定义、五模块说明、合规等级标注、合规声明、路由逻辑）见 `tax-planning-framework.md`，本文档只写本场景的差异化内容。

### Step 2：适用政策/实务框架

**适用税种**：增值税及附加（销售不动产/土地使用权）、土地增值税（房企清算/非房企计算）、契税（受让方缴纳）、企业所得税/个人所得税（转让所得）、印花税（产权转移书据）、房产税/城镇土地使用税（持有期间）。

**核心政策依据**：

| 政策 | 文号 | 关键条款 | 效力层级 |
|------|------|---------|---------|
| 增值税法 | 中华人民共和国主席令第十六号 | 销售不动产/土地使用权适用增值税 | P0 |
| 财政部 税务总局公告2026年第9号 | 财政部 税务总局公告2026年第9号 | 附件2（不动产销售范围界定/税率9%/简易征收5%） | P0 |
| 土地增值税法 | 全国人大常委会通过 | 转让国有土地使用权/地上建筑物取得增值额纳税 | P0 |
| 土地增值税暂行条例 | 国务院令第138号 | 四级超率累进税率30%-60% | P0 |
| 财税[2006]21号 | 财税[2006]21号 | 土增税扣除项目/清算条件 | P0 |
| 国家税务总局公告2016年第70号 | 总局公告2016年第70号 | 土增税清算管理规程 | P0 |
| 契税法 | 主席令第52号 | 3%-5%税率，受让方缴纳 | P0 |
| 企业所得税法 | 主席令63号 | 第6条（转让财产所得） | P0 |
| 个人所得税法 | 主席令第9号 | 第6条（财产转让所得20%） | P0 |
| 财税[2018]17号 | 财税[2018]17号 | 企业改制重组契税免征政策 | P0 |
| 财税[2018]57号 | 财税[2018]57号 | 企业改制重组土地增值税免征政策（非房企） | P0 |

**合规等级标注**：

| 情形 | 合规等级 | 标注 |
|------|------|------|
| 房企按预售+清算程序缴纳土增税 | 🟢 明确支持 | [合规-明确] |
| 非房企转让旧房，按评估价+重置成本确认扣除 | 🟢 明确支持 | [合规-明确] |
| 通过企业股权转让间接转让不动产规避土增税 | 🟡 存在争议 | [合规-争议]（各地执行口径不一，部分地区穿透征收） |
| 关联方之间低价转让不动产主张"合理商业目的" | 🟡 存在争议 | [合规-争议]（税务机关可能核定征收） |
| 拆分交易（如将装修/设备与房产拆分）降低土增税 | 🔴 高风险 | [合规-高风险]（可能被合并计税） |

### Step 3：误用风险提示（不动产交易场景常见误用）

| 误用表现 | 为什么错 | 正确理解 |
|---------|---------|---------|
| 认为不动产交易只涉及增值税和契税 | 忽略土增税是最大变量 | 土增税采用四级超率累进税率（30%-60%），往往是整体税负中最大的部分 |
| 认为非房企转让不动产不涉及土增税 | 忽略非房企也需缴纳 | 非房地产开发企业转让不动产同样需要缴纳土地增值税，只是计算方式不同（可按评估价或发票金额扣除） |
| 认为通过转让公司股权可以规避土增税 | 忽略穿透风险 | 以转让持有不动产的公司股权方式间接转让不动产，部分地区税务机关可能穿透征收土增税 |
| 认为个人转让住房一定免土增税 | 忽略条件限制 | 个人转让住房免土增税仅适用于居住用住宅，非住宅（商铺/办公）不适用 |
| 认为资产重组中的不动产转让一定免税 | 忽略免税条件 | 57号文免土增税仅适用于非房企的企业改制重组，且需满足特定条件；房企不适用 |
| 认为增值税可以选择简易征收就一定划算 | 忽略土增税联动 | 增值税简易征收5%看似低，但增值税不能作为土增税扣除项（一般计税的进项税额不影响销售额），需综合计算 |
| 认为土增税清算后就没有后续风险 | 忽略二次清算可能 | 项目全部完工后可能需要二次清算，前期预缴不足的需补缴+滞纳金 |

## 二、第二层：场景专用内容

### 模块A：政策依据补全（不动产交易场景）

**示例方案**："我司（非房地产开发企业）拟将一栋商业办公楼（2018年购入，购入价3000万元，目前评估价8000万元）转让给关联方D公司。"

| 关键步骤 | 法规依据 | 条款原文或要点摘录 |
|---------|---------|----------------|
| 1. 确认增值税计税方式 | 财政部 税务总局公告2026年第9号 | 2016年4月30日前取得可简易征收5%/否则一般计税9% |
| 2. 计算土增税扣除项目 | 土地增值税暂行条例第6条 | 取得土地使用权金额+开发成本+开发费用+转让环节税金+20%加计扣除（仅房企） |
| 3. 确认非房企旧房扣除方式 | 财税[2006]21号 | 可凭购房发票按发票金额+年利率5%计算扣除/或按评估重置成本确认 |
| 4. 计算土增税 | 土地增值税暂行条例第7条 | 增值额=转让收入-扣除项目→四级超率累进税率 |
| 5. 确认契税 | 契税法 | 受让方按成交价格3%-5%缴纳 |
| 6. 确认是否适用重组免税 | 财税[2018]57号/财税[2018]17号 | 企业改制重组免土增税/契税（需满足条件） |

---

### 模块B：落地细节补充（不动产交易场景）

| 维度 | 补充内容 |
|------|---------|
| 备查资料 | 不动产权证/购入发票或合同/评估报告/转让协议/土增税清算表（房企）/契税完税凭证 |
| 申报操作 | 增值税：按月/季申报/土增税：房企预售时预缴+项目竣工后清算，非房企转让时申报/契税：纳税义务发生后10日内 |
| 备案 vs 备查 | 重组免税需备案/土增税清算需报送清算资料/契税减免需备案 |
| 时点要求 | 增值税纳税义务发生时间（合同约定/产权变更）/契税纳税义务发生时间为纳税人签订合同之日/土增税清算条件触发时 |
| 会计处理 | 借：银行存款/固定资产清理 累计折旧 贷：固定资产 应交税费-应交增值税 资产处置收益 |
| 后续跟踪 | 土增税多退少补/契税完税/房产税变更（持有期间纳税义务转移） |

### 模块C：风险遗漏排查（不动产交易场景）

- [ ] 各税种是否全覆盖（增值税+附加/土增税/契税/企税或个税/印花税/房产税变更）
- [ ] 增值税一般计税 vs 简易征收的选择是否综合土增税影响
- [ ] 土增税扣除项目是否完整（尤其加计扣除仅限房企）
- [ ] 非房企旧房扣除方式是否选择最优（发票法 vs 评估法）
- [ ] 股权转让间接转让不动产的穿透风险
- [ ] 关联交易定价是否公允
- [ ] 重组免税是否满足条件（57号文/17号文）
- [ ] 法拍/司法执行的特殊税务处理
- [ ] 房产税/城镇土地使用税的纳税义务转移
- [ ] 个人转让住宅的增值税/个税免税条件是否满足
- [ ] 申报口径的地域差异（各地对土增税清算时点/扣除项目的认定）

---

### 模块D：交叉影响分析（不动产交易场景）

| 分析维度 | 关注点 |
|---------|--------|
| 税种间影响 | 增值税的选择影响土增税扣除（一般计税销项税额可抵扣，但影响转让收入口径）/契税与土增税对"成交价格"的认定可能不一致 |
| 会计与税务差异 | 会计按账面价值确认处置损益 vs 税务按公允价值计算各税种，差异大 |
| 与重组场景交叉 | 资产重组中不动产转让可能适用57号文免土增税+17号文免契税，但条件严格 |
| 与非货币性资产投资交叉 | 不动产出资视同销售缴纳各税，同时触发契税（受让方） |
| 业务连续性 | 不动产转让后承租回租/售后回租的增值税和房产税影响 |
| 信息披露 | 重大资产处置需在财报/临时公告中披露 |

```
2. 方案骨架
   - 步骤1：确认{{不动产类型}}及产权状况
   - 步骤2：确认增值税计税方式（一般9%/简易5%）

   - 步骤4：确认契税（受让方3%-5%）
   - 步骤5：确认是否适用重组免税（57号文/17号文）
   - 步骤6：综合计算各税种税额及总税负
   - 步骤7：办理各税种申报及缴款

3. 关键判断节点
   - [增值税一般计税还是简易征收？] → 取得时间/纳税人类型/综合土增税影响
   - [土增税扣除方式？] → 房企开发成本扣除/非房企旧房发票法vs评估法
   - [是否适用重组免税？] → 57号文（非房企改制重组免土增税）/17号文（免契税）
   - [是否被穿透征收？] → 股权转让间接转让不动产的各地执行口径

4. 差异点清单（复用时必改项）
   - {{不动产类型}}：住宅/商业/工业，影响增值税/土增税/契税税率及优惠
   - {{取得方式}}：自建/外购/投资取得，影响增值税计税方式和土增税扣除
   - {{转让方}}：房企/非房企/个人，决定土增税清算vs计算方式
   - {{地域口径}}：各地对土增税清算/扣除/穿透征收的标准差异极大
```
