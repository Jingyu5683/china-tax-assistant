# 资产/股权重组 税务筹划引导

> 试点场景二：场景多样、一般性税务处理 vs 特殊性税务处理决策树清晰。
> 通用规则（四步流程定义、五模块说明、合规等级标注、合规声明、路由逻辑）见 `tax-planning-framework.md`，本文档只写本场景的差异化内容。

## 一、第一层：场景专用内容

### Step 1：明确业务实质（重组场景专用提问清单）

| 引导维度 | 选项 |
|---------|------|
| 重组类型 | 吸收合并 / 新设合并 / 股权收购 / 资产收购 / 分立 / 其他 |
| 主体性质 | 居民企业 / 非居民企业 / 个人 / 合伙企业 |
| 交易对价 | 股权支付 / 非股权支付 / 混合支付 |
| 是否跨境 | 境内重组 / 境外重组（涉及非居民企业） |
| 是否关联方 | 是 / 否 |
| 时间要素 | 当年发生 / 跨年 / 涉及以前年度？ |
| 核心诉求 | 降低税负 / 合规确认 / 争议应对 / 申报操作？ |

---

### Step 2：适用政策/实务框架

**适用税种**：企业所得税（一般税务处理 vs 特殊性税务处理）、增值税（资产重组不征增值税）、印花税（产权转移书据）、契税（土地/房屋权属转移）、土地增值税（房地产转移）。

**核心政策依据**：

| 政策 | 文号 | 关键条款 | 效力层级 |
|------|------|---------|---------|
| 财税[2009]59号 | 财税[2009]59号 | 特殊性税务处理条件 | P0 |
| 财税[2014]109号 | 财税[2014]109号 | 100%直接控制居民企业之间资产/股权划转 | P0 |
| 企业所得税法 | 主席令63号 | 第20条（企业重组税务处理） | P0 |
| 国家税务总局公告2015年第40号 | 总局公告2015年第40号 | 划转具体操作 | P0 |

**合规等级标注**：

| 情形 | 合规等级 | 标注 |
|------|------|------|
| 符合条件的一般税务处理（按公允价值转让） | 🟢 明确支持 | [合规-明确] |
| 适用特殊性税务处理（递延纳税） | 🟡 存在争议 | [合规-争议]（需税务机关确认） |
| 通过复杂架构规避应纳税额 | 🔴 高风险 | [合规-高风险] |

---

### Step 3：误用风险提示（重组场景常见误用）

| 误用表现 | 为什么错 | 正确理解 |
|---------|---------|---------|
| 认为所有重组都可以适用特殊性税务处理 | 忽略"符合条件"的前提（合理商业目的/权益连续性/经营连续性等） | 特殊性税务处理有严格条件，需要同时满足 |
| 认为特殊性税务处理一定能降低税负 | 忽略递延纳税的含义（以后年度补税） | 特殊性税务处理是递延纳税，不是免税；需要综合考虑前后置税负 |
| 认为划转（109号）可以随意适用 | 忽略"100%直接控制居民企业之间"的前提 | 划转只适用于100%直接控制居民企业之间的资产/股权划转 |

## 二、第二层：场景专用内容

### 模块A：政策依据补全（重组场景）

**示例方案**："A公司（母公司）拟将其持有的B公司（子公司）100%股权划转至C公司（同一控制下兄弟公司），拟适用特殊性税务处理。"

| 关键步骤 | 法规依据 | 条款原文或要点摘录 |
|---------|---------|----------------|
| 1. 判断是否属于企业重组 | 财税[2009]59号 | 第一条（企业重组定义及类型） |
| 2. 判断是否符合特殊性税务处理条件 | 财税[2009]59号 | 第五条（五个条件：合理商业目的/被收购股权比例≥50%/股权支付比例≥85%/经营连续性/权益连续性） |
| 3. 判断是否适用100%直接控制划转 | 财税[2014]109号 | 第一条（100%直接控制居民企业之间划转） |
| 4. 判断划转的具体税务处理方式 | 国家税务总局公告2015年第40号 | 根据划转方式选择适用不同条款 |
| 5. 判断是否需要税务机关确认 | 财税[2009]59号 | 第十一条（备案管理） |

---

### 模块B：落地细节补充（重组场景）

| 维度 | 补充内容 |
|------|---------|
| 备查资料 | 重组协议/资产评估报告/股权结构图/合理商业目的说明/经营连续性承诺/权益连续性说明 |
| 申报操作 | 企业重组所得税特殊性税务处理备案表/年度纳税申报表相关行次 |
| 备案 vs 备查 | 特殊性税务处理需向主管税务机关备案（年度汇算清缴时） |
| 时点要求 | 重组完成日起连续12个月内不得改变重组资产实质性经营活动 |
| 会计处理 | 同一控制下合并/非同一控制下合并的会计处理差异 |
| 后续跟踪 | 12个月经营连续性跟踪/36个月权益连续性跟踪 |

---

### 模块C：风险遗漏排查（重组场景）

- [ ] 各税种是否全覆盖（企业所得税/增值税/印花税/契税/土地增值税等）
- [ ] 反避税条款是否触发（一般反避税条款/不合理商业目的）
- [ ] 特殊性税务处理的后续维持条件（12个月经营连续性/36个月权益连续性）
- [ ] 申报口径的地域差异（各地对"合理商业目的"的认定标准）
- [ ] 时效风险（后续期间补税时效等）

---

### 模块D：交叉影响分析（重组场景）

| 分析维度 | 关注点 |
|---------|--------|
| 税种间影响 | 企税递延纳税对增值税/印花税/契税的影响（增值税和印花税不递延） |
| 会计与税务差异 | 会计按公允价值计量 vs 税务按原计税基础递延，产生递延所得税负债 |
| 业务连续性 | 重组后12个月内经营变化可能导致补税 |
| 信息披露 | 重大资产重组需在财报/临时公告中披露 |
| 关联交易 | 重组是否影响转让定价文档/国别报告义务 |

### 模块E：方案蒸馏归档（重组场景）

```
1. 方案摘要
   - 场景类型：资产/股权重组
   - 适用标签：居民企业 / 同一控制 / 跨境 / 特殊性税务处理
   - 核心路径：{{出让方}}将{{标的类型}}划转/转让给{{受让方}}，
         按{{税务处理方式}}处理，计税基础为{{原值/公允价值}}

2. 方案骨架
   - 步骤1：确认重组类型及适用政策（59号/109号）
   - 步骤2：判断是否符合特殊性税务处理条件
   - 步骤3：计算递延纳税金额/确认计税基础
   - 步骤4：办理特殊性税务处理备案
   - 步骤5：处理其他税种（增值税/印花税/契税/土地增值税）
   - 步骤6：跟踪12个月经营连续性+36个月权益连续性

3. 关键判断节点
   - [是否符合合理商业目的？] → 主管税务机关认定
   - [股权支付比例是否≥85%？] → 财税[2009]59号第五条
   - [是否为100%直接控制？] → 财税[2014]109号

4. 差异点清单（复用时必改项）
   - {{重组类型}}：不同类型适用不同条款
   - {{标的类型}}：资产 vs 股权，涉及税种不同
   - {{税务处理方式}}：一般性 vs 特殊性
   - {{地域口径}}：各地对"合理商业目的"认定标准不同
```
