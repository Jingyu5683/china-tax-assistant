### Step 2：适用政策/实务框架

**适用税种**：企业所得税（技术转让所得减免）、增值税（技术转让/开发免税）、个人所得税（个人技术转让）、印花税（技术合同）、预提所得税（非居民企业技术许可）。

**核心政策依据**：

| 政策 | 文号 | 关键条款 | 效力层级 |
|------|------|---------|---------|
| 企业所得税法 | 主席令63号 | 第27条（符合条件的技术转让所得减免） | P0 |
| 企业所得税法实施条例 | 国务院令512号 | 第90条（技术转让所得减免条件） | P0 |
| 财税[2010]111号 | 财税[2010]111号 | 技术转让范围/条件 | P0 |
| 财税[2013]62号 | 财税[2013]62号 | 技术转让所得计算 | P0 |
| 国税函[2009]212号 | 国税函[2009]212号 | 技术转让所得减免管理 | P0 |
| 增值税法 | 中华人民共和国主席令第十六号 | 第二十四条（免征增值税项目） | P0 |
| 财政部 税务总局公告2026年第10号 | 财政部 税务总局公告2026年第10号 | 第二条第（二）款第2项（技术转让/开发免征增值税，至2027.12.31） | P0 |
| 财政部 税务总局公告2026年第9号 | 财政部 税务总局公告2026年第9号 | 附件2《销售服务、无形资产、不动产注释》（界定"技术"和"研发服务"范围） | P0 |

**合规等级标注**：

| 情形 | 合规等级 | 标注 |
|------|------|------|
| 符合条件的技术转让所得减免（居民企业，年度500万以内免税） | 🟢 明确支持 | [合规-明确] |
| 技术转让增值税免税（合同需经省级科技/工信主管部门认定并报税务机关备查） | 🟡 存在争议 | [合规-争议]（认定/备查口径各地不一） |
| 关联方技术转让规避限制 | 🔴 高风险 | [合规-高风险] |

### Step 3：误用风险提示（技术转让场景常见误用）

| 误用表现 | 为什么错 | 正确理解 |
|---------|---------|---------|
| 认为所有技术转让都可以减免企业所得税 | 忽略"符合条件的"前提（需经省级以上科技部门认定） | 只有符合条件的技术转让所得，才能享受减免优惠 |
| 认为技术转让增值税一律免税 | 忽略"技术开发/转让合同需经省级科技/工信主管部门认定并报主管税务机关备查"的前提 | 技术开发/转让合同须持书面合同到省级科技、工信主管部门认定，并持认定文件报主管税务机关备查，才能享受增值税免税（财政部 税务总局公告2026年第10号） |
| 认为技术转让所得减免没有金额限制 | 忽略"年度500万以内免税"的限制 | 技术转让所得，年度500万以内免税，超过部分减半征收 |
| 认为关联方技术转让也可以享受减免 | 忽略"独立交易原则"的要求 | 关联方技术转让需符合独立交易原则，否则可能被调整 |

## 二、第二层：场景专用内容

### 模块A：政策依据补全（技术转让场景）

**示例方案**："我司（居民企业）拟向关联方转让一项专利技术，技术转让所得预计800万元，拟申请企业所得税减免。"

| 关键步骤 | 法规依据 | 条款原文或要点摘录 |
|---------|---------|----------------|
| 1. 确认技术是否属于减免范围 | 财税[2010]111号 | 专利技术/计算机软件著作权/集成电路布图设计/植物新品种/生物医药新品种 |
| 2. 确认主体是否为居民企业 | 企业所得税法 | 第27条（仅居民企业适用） |
| 3. 计算技术转让所得 | 财税[2013]62号 | 技术转让收入 - 技术转让成本 - 相关税费 |
| 4. 判断是否满足500万门槛 | 企业所得税法实施条例 | 第90条（500万以内免税，超过部分减半） |
| 5. 判断关联方交易定价是否合规 | 企业所得税法 | 第41条（独立交易原则） |

---

### 模块B：落地细节补充（技术转让场景）

| 维度 | 补充内容 |
|------|---------|
| 备查资料 | 技术转让合同/省级科技部门认定文件/技术成果证明（专利证书等）/所得计算表/关联方定价合理性说明 |
| 申报操作 | 企业所得税年度纳税申报表相关行次填报减免金额 |
| 备案 vs 备查 | 企业所得税减免采取备查制；增值税免税需省级科技/工信主管部门认定+报税务机关备查 |
| 时点要求 | 技术转让完成年度汇算清缴时享受减免 |
| 会计处理 | 技术转让收入确认/无形资产核销/递延收益处理 |
| 后续跟踪 | 如分期收款，需按期确认收入和所得 |

---

### 模块C：风险遗漏排查（技术转让场景）

- [ ] 各税种是否全覆盖（企业所得税/增值税/个人所得税/印花税/预提所得税等）
- [ ] 反避税条款是否触发（独立交易原则/一般反避税条款）
- [ ] 税收优惠的维持条件（后续是否需持续满足某些条件，如科技部门定期复查）
- [ ] 申报口径的地域差异（是否有各地执行口径不统一的风险）
- [ ] 时效风险（追溯期、补税时效等）

---

### 模块D：交叉影响分析（技术转让场景）

| 分析维度 | 关注点 |
|---------|--------|
| 税种间影响 | 企税减免与增值税免税各自独立，互不影响 |
| 会计与税务差异 | 会计确认与税务处理不一致时的递延税影响 |
| 业务连续性 | 本次技术转让对后续期间/后续交易的影响（如后续技术改进/再许可） |
| 信息披露 | 是否需在财报/附注中披露（重大技术转让/关联交易） |
| 关联交易 | 是否影响转让定价文档/国别报告义务（如涉及关联方） |

---

```
1. 方案摘要
   - 场景类型：技术转让/许可
   - 适用标签：居民企业 / 非居民 / 关联交易 / 跨境 / 技术转让所得减免
   - 核心路径：{{转让方}}向{{受让方}}转让/许可{{技术类型}}，
         享受技术转让所得减免（企业所得税）/ 增值税免税

2. 方案骨架
   - 步骤1：确认{{技术类型}}是否符合条件（财税[2010]111号）
   - 步骤2：确认{{转让方}}为居民企业
   - 步骤3：计算{{技术转让所得}}
   - 步骤4：享受企业所得税减免（500万以内免税，超过部分减半征收）
   - 步骤5：办理企业所得税减免备查
   - 步骤6：办理增值税免税合同认定+备查
   - 步骤7：{{受让方}}支付（如涉及非居民，需扣缴预提所得税）

3. 关键判断节点
   - [{{技术类型}}是否符合条件？] → 财税[2010]111号
   - [{{转让方}}是否为居民企业？] → 企业所得税法第27条
   - [{{技术转让所得}}计算是否正确？] → 财税[2013]62号

4. 差异点清单（复用时必改项）
   - {{技术类型}}：根据实际技术类型
   - {{转让方}}：影响减免适用，需确认是否为居民企业
   - {{受让方}}：如为关联方，需关注独立交易原则
   - {{地域口径}}：需确认主管税务局态度
```
