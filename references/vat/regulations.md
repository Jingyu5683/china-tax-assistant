## 二、增值税法核心条款

### 2.1 纳税人

- **一般纳税人**：实行登记制度，适用一般计税方法（销项税额 - 进项税额）
- **小规模纳税人**：年应征增值税销售额未超过500万元；会计核算健全的可申请登记为一般纳税人

### 2.2 税率（增值税法第十条）

| 税率 | 适用范围 |
|------|---------|
| **13%** | 销售货物、加工修理修配服务、有形动产租赁服务、进口货物（除适用低税率的） |
| **9%** | 交通运输、邮政、基础电信、建筑、不动产租赁服务、转让土地使用权、销售不动产；以及农产品、食用植物油、食用盐、自来水、暖气、冷气、热水、煤气、天然气、图书、报纸、杂志、饲料、农药、农机等 |
| **6%** | 销售服务、无形资产（除适用低税率的） |
| **0%** | 出口货物；境内单位和个人跨境销售国务院规定范围内的服务、无形资产 |
| **3%** | 简易计税方法（小规模纳税人） |

### 2.3 征收率（增值税法第十一条）

| 征收率 | 适用范围 |
|--------|---------|
| **3%** | 小规模纳税人简易计税 |

### 2.4 应纳税额计算

**一般计税方法**：
```
应纳税额 = 当期销项税额 - 当期进项税额
```

**简易计税方法**：
```
应纳税额 = 当期销售额 × 征收率
```

**进项税额不得抵扣项目**（增值税法第二十二条）：
1. 适用简易计税方法计税项目对应的进项税额
2. 免征增值税项目对应的进项税额
3. 非正常损失项目对应的进项税额
4. 购进并用于集体福利或者个人消费的货物、服务对应的进项税额
5. 购进并直接用于消费的餐饮服务、居民日常服务和娱乐服务对应的进项税额
6. 购进贷款服务的利息支出及相关费用（不得抵扣进项）

### 2.5 起征点（增值税法第二十三条）

- 小规模纳税人起征点：
  - **月销售额10万元以下（含）**或**季度30万元以下（含）**免征增值税
  - 达到起征点的，全额计算缴纳
- 自然人按次纳税：**每次（日）销售额500元以下免征**
- 起征点标准由国务院规定，报全国人大常委会备案

**【时效提醒】** 2026年第4号公告延续上述标准，具体以联网检索最新规定为准

### 2.6 免税项目（增值税法第二十四条）

1. 农业生产者销售的自产农产品
2. 医疗机构提供的医疗服务
3. 古旧图书，自然人销售自己使用过的物品
4. 直接用于科学研究、科学试验和教学的进口仪器、设备
5. 外国政府、国际组织无偿援助的进口物资和设备
6. 残疾人组织进口供残疾人专用的物品，残疾人个人提供的服务
7. 托儿所、幼儿园、养老机构、残疾人服务机构提供的育养服务，婚姻介绍服务，殡葬服务
8. 学校提供的学历教育服务，学生勤工俭学
9. 纪念馆、博物馆、文化馆、文物保护单位、美术馆、展览馆、书画院、图书馆门票收入，宗教场所门票收入

## 三、实施条例要点

### 3.1 进项税额抵扣凭证（第十一条）

增值税扣税凭证包括：
1. 增值税专用发票
2. 海关进口增值税专用缴款书
3. 完税凭证（境外购进服务、无形资产、不动产）
4. 农产品收购发票、农产品销售发票
5. 其他具有进项税额抵扣功能的扣税凭证

### 3.2 长期资产进项税额抵扣（第二十五条）

| 情形 | 处理方式 |
|------|---------|
| 原值≤500万元的单项长期资产 | 可全额抵扣进项税额 |
| 原值>500万元的单项长期资产 | 购进时全额抵扣，使用混合用途期间逐年调整不得抵扣进项 |

【延伸阅读】详见《长期资产进项税额抵扣暂行办法》（财政部 税务总局公告2026年第15号）

### 3.3 非正常损失认定（第十九条）

非正常损失包括：
- 因管理不善造成货物被盗、丢失、霉烂变质
- 因违反法律法规造成货物或者不动产被依法没收、销毁、拆除

## 四、专项公告要点

### 4.1 进项税额抵扣公告（2026年第13号）

#### 旅客运输服务抵扣：

| 凭证类型 | 抵扣方式 |
|---------|---------|
| 铁路电子客票 | 发票上列明或包含的增值税税额 |
| 航空运输电子客票行程单 | 发票上列明或包含的增值税税额 |
| 其他公路、水路客票 | 票面金额 ÷（1+3%）× 3% |

#### 通行费抵扣：

| 凭证类型 | 抵扣方式 |
|---------|---------|
| 收费公路通行费增值税电子普通发票 | 发票上列明的增值税税额 |
| 桥、闸通行费发票 | 通行费金额 ÷（1+5%）× 5% |

#### 不得抵扣进项税额计算（第二十四条）

当购进货物、服务用于简易计税、免税和不得抵扣非应税交易无法划分时：
```
不得抵扣的进项税额 = 当期无法划分的全部进项税额 ×（当期简易计税方法计税项目销售额 + 免征增值税项目销售额 + 不得抵扣非应税交易销售额）÷ 当期全部销售额
```

### 4.2 销售额计算口径公告（2026年第12号）

差额计税项目（以扣除相关价款后的余额计算销售额）：

| 项目 | 扣除内容 |
|------|---------|
| 金融商品转让 | 买入价（可选择加权平均法或移动加权平均法，36个月内不得变更） |
| 客运场站服务 | 支付给承运方的运费 |
| 航空运输服务 | 代售其他航空公司客票而代收转付的价款 |
| 机票代理服务 | 向航空运输企业支付的境内机票净结算款和相关费用 |
| 境外考试代理 | 支付给境外单位的考试费 |
| 签证代理服务 | 代为支付的签证费、认证费 |
| 进口免税货物代理 | 代为支付的货款 |

【注意】扣除价款取得的扣税凭证，进项税额不得抵扣

### 4.3 起征点征管公告（2026年第4号）

#### 自然人按次纳税：
- 达到起征点的，向主管税务机关申请代开发票时征收
- 有扣缴义务人的，由扣缴义务人申报缴纳
- 本年度发生尚未缴纳增值税的应税交易，次年6月30日前申报

#### 小规模纳税人1%征收率：
- 适用1%征收率政策的，应开具1%征收率的增值税发票
- 可选择全部或部分应税交易放弃减税并开具增值税专用发票

## 五、税率适用规则

### 5.1 两项以上应税交易涉及不同税率（增值税法第十二条）

分别核算适用不同税率的销售额；未分别核算的，**从高适用税率**

### 5.2 一项应税交易涉及两个以上税率（增值税法第十三条）

按照**应税交易的主要业务**适用税率

### 5.3 混合销售（实施条例第十条）

同时符合以下条件，适用主要业务的税率：
1. 包含两个以上涉及不同税率、征收率的业务
2. 业务之间具有明显的主附关系
